# 05 — Принятые решения и трактовки (металлопрокат)

> Имеют приоритет над общими рассуждениями и общими формулировками чек-листов 01–04. Дополнять после каждой нетиповой проверки: «Ситуация → Решение → Основание → Где возникло».
> Решения разделов «Общие», «Классификация отсутствующих результатов» и «Химсостав» перенесены из проектов «Трубы» (файл 09) и «Фитинги и Фланцы» (файл 08) — там они приняты; здесь применяются к прокату. Раздел «Открытые вопросы» — трактовки, применённые при первой проверке проката, ещё не утверждённые.

## Общие
- **Ударная вязкость — сначала требование заказа / КД / ТТ** (решение от 25.09.2026):
  - Если в условном обозначении (категория), заказе, КД или ТТ задано требование к ударной вязкости (вид KCU или KCV, температура, норма), проверять **только по этому требованию**: есть ли результат именно этого вида при этой температуре и выполняется ли норма. Ударную вязкость других видов и температур не требовать и в Акт не выносить.
  - Результат другого вида или при другой температуре (например, KCU при −20 °С вместо KCV при −40 °С) требование не подтверждает: «Не подтверждено», в Акт как требование представить результат по заказу. Пересчёт KCU ↔ KCV не допускается.
  - Если требования к ударной вязкости нет — проверять по общему правилу стандарта.
  - В справке указывать источник требования: «по заказу — категория N …», «по КД …» или «по ГОСТ …».
- **Показатель, для которого нет нормы при этом виде / температуре** — принимается как данные, с нормой не сравнивается: «Не оценивается», в Акт не идёт.
- Объём проверки — строго номенклатура из задания.
- Нормы берутся только из приложенных текстов стандартов.
- Испытания, которые НД проводит «по требованию заказчика» / «по согласованию», требуются только если они есть в заказе (в том числе в условном обозначении), КД или ТТ.
- **Требование заказа / КД (ТТ)** — всегда **отдельная строка Акта**, даже если по другому основанию уже есть несоответствие.

## Классификация отсутствующих результатов
- Результат **обязательного** (или заказанного) испытания в сертификате отсутствует → «Не подтверждено» (неопределённость): в Акт — требование представить результат, без вывода «не соответствует» по существу.
- «Не соответствует» — при фактическом значении за нормой или при прямом расхождении с заказом (другая категория, группа поверхности, марка, состояние поставки, точность).
- Прямая запись, что обязательное испытание не проводилось, без основания для освобождения → «Не соответствует».

## Химсостав
- **Вид анализа в сертификате (ковшевая проба / готовая продукция) не указан** — не замечание и не требование в Акт; сравнивать с нормой марки. Допускаемые отклонения для готовой продукции (п. 4.8, табл. 2 ГОСТ 380; п. 5.2, табл. 3 ГОСТ 1050; п. 5.1.2, табл. 8 ГОСТ 19281; табл. 3 ГОСТ 4543; п. 6.2, табл. 2 ГОСТ 5632) применять **только если в сертификате прямо указано, что это анализ готовой продукции**. Значение выше нормы без такой пометки — «Не соответствует», в Акт. (Решение от 26.09.2026.)
- **Азот для сталей по ГОСТ 1050-2013** (решение от 26.09.2026):
  - N не указан и нет ни Al, ни азотосвязывающих элементов → «Не подтверждено», в Акт как требование представить N (или Al / азотосвязывающие элементы) и способ выплавки.
  - N указан, способ выплавки не указан: N ≤ 0,006 % (лист, лента) / ≤ 0,008 % (прочая продукция) — «Соответствует» при любом способе; выше, но ≤ 0,012 % — «Не подтверждено», в Акт как требование указать способ выплавки (п. 8.1.1 ГОСТ 1050); N > 0,012 % — «Не соответствует».
  - N выше предела для указанного способа выплавки → «Не соответствует», в Акт.
- Для сталей по ГОСТ 380: Cr, Ni, Cu, As, N допускается не определять при гарантии изготовителя (п. 5.3 ГОСТ 380).
- Пересчёт кгс/мм² → Н/мм² — по коэффициенту 9,80665.

## Документ о качестве
- Текста ГОСТ 7566 в проекте нет. Требования к составу документа проверяются только по дополнительным сведениям из НД на прокат (файл 01, раздел 4.2). Копия, заверенная посредником, — замечание; копия без заверения или с расхождением количества — неопределённость, в Акт как требование оригинала / заверенной копии.

## Открытые вопросы (требуют решения)
Применены при проверке 20.11.2026 (сертификат № 0000-5141.1.2 АО «Металлургический завод «Петросталь», круг 180, 09Г2С, плавка 70 406). До решения — применять так, как описано, и выносить в раздел «Допущения» Справки.

1. **Категория в сертификате отличается от заказанной** (в заказе 9 — KCV при −40 °С; в сертификате 10 — KCU при −20 °С и после старения; KCV нет). Применено: «Не подтверждено», одна строка Акта — требование представить KCV при −40 °С по плавке. Основание: табл. 4, п. 5.2.1.5, табл. 11 и примечание 1 к ней, п. 6.3.1 ГОСТ 19281-2014. Для 09Г2С класса 265 размером св. 100 до 250 мм в табл. 11 в графе KCV −40 °С стоит «+» — результат обязателен в документе, но нормы нет; поэтому «Не подтверждено», а не «Не соответствует».
2. **Группа качества поверхности в сертификате отличается от заказанной** (2ГП вместо 3ГП). Применено: «НЕ СООТВЕТСТВУЕТ», строка Акта по требованию заказа (п. 5.1.6 ГОСТ 19281-2014 → ГОСТ 535). Текста ГОСТ 535 в проекте нет — нормы групп не приводились. Для стали по ГОСТ 1050 группы 2ГП / 3ГП описаны в п. 7.1.8–7.1.10 ГОСТ 1050-2013 — для ГОСТ 19281 их не применять. Решить: достаточно ли подтверждения группы письмом изготовителя или нужен переоформленный сертификат.
3. **Состояние поставки не указано** (графа «Термообработка» пустая, в заказе не оговорено). Применено: «Не подтверждено», строка Акта — требование указать (п. 5.1.4 ГОСТ 19281-2014). Решить: оставлять в Акте или переводить в замечание.
4. **Химсостав по табл. 1 и табл. 7 ГОСТ 19281-2014 расходится** (Si 0,610 % при 09Г2С: табл. 7 — 0,50–0,80 %, табл. 1 для класса 265 — не более 0,60 %). Применено: в заказе указана марка → табл. 7; превышение по табл. 1 — только в справке, в Акт не включено. Решить: правильно ли считать, что указание марки в обозначении всегда означает исполнение по п. 5.2.
5. **Смена редакции ГОСТ 19281** (ГОСТ 19281-2025 вводится с 01.12.2026 по каталогу meganorm.ru; текста в проекте нет). Решить: как оценивать сертификаты, выданные после 01.12.2026 со ссылкой на ГОСТ 19281-2014, и прокат, заказанный по одной редакции, а поставленный по другой.
6. **Применимость ТР ТС к прокату как самостоятельной продукции** — в проекте не проверяется; при необходимости — вопрос в проект «Применимость ТР ТС» (`tr-ts-applicability`).
