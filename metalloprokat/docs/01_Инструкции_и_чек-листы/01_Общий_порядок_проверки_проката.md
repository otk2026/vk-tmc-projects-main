# 01 — Общий порядок проверки документов о качестве на металлопрокат
**Применяется к любому прокату вместе с чек-листом по виду проката (02 — сортовой, 03 — листовой)**

> Нормы брать только из приложенных текстов НД (`docs/03_…`, `docs/04_…`, `docs/05_…`) и сверять по PDF в `originals/`. Пункты ниже сверены с текстами ГОСТ 19281-2014 (Изм. № 1), ГОСТ 1050-2013, ГОСТ 4543-2016, ГОСТ 14637-2024, ГОСТ 1577-2022, ГОСТ 5520-2017, ГОСТ 2590-2006, ГОСТ 19903-2015.
> Текстов ГОСТ 7566 (приёмка, маркировка, документ о качестве на металлопродукцию), ГОСТ 535 (сортовой прокат из углеродистой стали обыкновенного качества), ГОСТ 2591, 2879, 103 (сортамент квадрата, шестигранника, полосы) в проекте **нет** — нормы по ним не приводить, вывод по существу не делать.

## 1. Какие документы нужны для проверки
| Документ | Зачем |
|---|---|
| Сертификат (документ о качестве) на каждую партию / плавку | Основной объект проверки |
| Номенклатура / заказ / спецификация с полным условным обозначением | Определяет исполнение: НД, точность, категорию, группу поверхности, состояние поставки, ГС, УЗК |
| Накладная / УПД | Привязка сертификата к поставке: количество, плавка |
| КД, карта входного контроля, ТТ заказчика | Дополнительные требования |
| Тексты НД на сортамент и на прокат (с годом редакции) | Первоисточник норм |

Без номенклатуры с условным обозначением нельзя оценить требования «по требованию заказчика» — такие пункты оцениваются как «Не подтверждено (требуется заказ / спецификация)».

## 2. Расшифровка условного обозначения (до всех проверок)
Условное обозначение проката — дробь: в числителе — вид, точность и размер по НД на сортамент; в знаменателе — характеристики по НД на прокат (технические условия). Примеры условных обозначений — приложение Г ГОСТ 19281-2014 (сверено по скану, стр. 53–54), приложение А ГОСТ 14637-2024, приложение А ГОСТ 1577-2022, п. 7.4 и приложение А ГОСТ 5520-2017.

| Составляющая | Где в обозначении | Что означает | Какой НД |
|---|---|---|---|
| Точность прокатки (сортовой) | числитель: А1, Б1, В1 … | предельные отклонения по диаметру / стороне | табл. 1 ГОСТ 2590-2006 |
| Класс кривизны (сортовой) | числитель: I, II, III, IV | допустимая кривизна, % длины | табл. 4 ГОСТ 2590-2006 |
| Длина (сортовой) | числитель: МД, КД, НД, ОД, НМД … | мерная, кратная, немерная, в мотках | п. 2.1, 2.7 ГОСТ 2590-2006 |
| Точность по толщине, плоскостность, кромка (лист) | числитель: А / Б; ПО / ПВ / ПУ / ПН; О / НО | предельные отклонения и форма листа | п. 2.1, табл. 3, 4, 8 ГОСТ 19903-2015 |
| Размер | числитель | диаметр / сторона / толщина × ширина × длина | НД на сортамент |
| Класс прочности или марка стали | знаменатель | нормы растяжения и химсостава | НД на прокат |
| Категория | знаменатель, число после класса / марки | вид и температура испытания на ударный изгиб | табл. 4 ГОСТ 19281-2014; табл. 1 ГОСТ 14637-2024; табл. 4, 5 ГОСТ 5520-2017; ГОСТ 1577-2022 |
| Группа качества поверхности (сортовой) | знаменатель: 1ГП, 2ГП, 3ГП | допустимые дефекты и зачистка | п. 5.1.6 ГОСТ 19281-2014 → ГОСТ 535 (текста нет); п. 7.1.8–7.1.10 ГОСТ 1050-2013; п. 7.1.3 ГОСТ 4543-2016 |
| Состояние поставки | знаменатель: ГК, Н, ТО, КП, ОТ … | горячекатаное, нормализованное и т. д. | п. 5.1.4 ГОСТ 19281-2014; п. 7.1.6 ГОСТ 14637-2024; п. 7.1.5 ГОСТ 4543-2016 и др. |
| Дополнительные требования | знаменатель или текст заказа: ГС, УЗК, Z, ссылки на приложения (Б.1 …) | заказанные испытания | НД на прокат |

Каждая составляющая — отдельный пункт проверки в разделе 2 Справки ПК. Составляющая, которой нет в обозначении, — исполнение по выбору изготовителя (базовое), если НД не требует иного.

## 3. Идентификация (блокирующий шаг)
Сверь сертификат с поставкой, заказом и КД по всем признакам сразу: вид проката, размер, НД на сортамент и на прокат (с годом), марка стали / класс прочности, плавка (партия), количество (шт., т), грузополучатель / заказчик. Расхождение по одному признаку — повод проверить остальные. Сертификат на другой размер, марку или плавку означает, что документа о качестве на поставку фактически нет.

## 4. Документ о качестве

### 4.1 Вид документа и общий состав
- Для листового проката — документ вида **3.1 или 3.2**, оформленный по ГОСТ 7566 (п. 8.3 ГОСТ 14637-2024; п. 8.3 ГОСТ 1577-2022). Для проката по ГОСТ 19281-2014, ГОСТ 1050-2013, ГОСТ 4543-2016, ГОСТ 5520-2017 — документ о качестве по ГОСТ 7566 (п. 6.3 ГОСТ 19281; п. 8.1.1 ГОСТ 1050; п. 8.3 ГОСТ 4543; п. 8.3 ГОСТ 5520).
- Общий состав документа по ГОСТ 7566 проверить нельзя — текста нет в проекте. Проверяются **дополнительные сведения**, которые требует НД на прокат (п. 4.2).

### 4.2 Дополнительные сведения по НД на прокат (проверять по приложенному тексту)
| НД | Пункт | Что дополнительно указывают в документе о качестве |
|---|---|---|

### 4.3 Оригинал и копии
- Требования к копиям документа о качестве установлены ГОСТ 7566 — текста нет в проекте. Копию, заверенную посредником, оценивать как **замечание** (жёлтый): указать, кем заверена и что привязка к поставке подтверждается накладной и маркировкой. Вывод «документ недействителен» не делать.
- Копия без печати / подписи, с исправлениями, с количеством больше или меньше поставки без пояснений — неопределённость: в Акт — требование оригинала или заверенной копии с указанием поставленного количества.

## 5. Партия
- Правила комплектования партии — по НД на прокат: п. 6.2 ГОСТ 19281-2014 (стр. 39); п. 8.1 ГОСТ 1050-2013; п. 8.2 ГОСТ 14637-2024; п. 8.2 ГОСТ 5520-2017; п. 8.2 ГОСТ 1577-2022.
- Проверь: одна марка / класс, одна плавка (или правила для нескольких плавок), один размер, один режим термообработки; номер плавки указан.
- При партии из нескольких плавок химсостав и механические свойства — по каждой плавке (п. 8.3.1 ГОСТ 14637; п. 8.2.1 ГОСТ 1050 и аналогичные).

## 6. Маркировка (при ВИК)
- Маркировка и упаковка проката — по ГОСТ 7566 (п. 5.5 ГОСТ 19281-2014; п. 7.2 ГОСТ 14637-2024; п. 10.1 ГОСТ 5520-2017; п. 10.1 ГОСТ 1050-2013). Текста ГОСТ 7566 нет — проверять только связь «бирка / клеймо — сертификат» по номеру плавки и сертификата.
- Несовпадение плавки на бирке с сертификатом — браковочный признак идентификации (п. 3).

## 7. Проверка происхождения данных (обязательный раздел)

Наличие цифры в сертификате не равнозначно её подтверждению. Отвечай на вопрос: откуда взято каждое значение.

| Признак | Как трактовать |
|---|---|
| Химсостав дан диапазоном или совпадает с нормами марки | Это нормы, а не фактический анализ. Химсостав не подтверждён |
| Механические свойства точно равны нормативным минимумам таблицы НД | Возможна подстановка норм. Требовать протокол испытаний |
| Одинаковые значения у разных плавок / партий | Признак переноса данных. Требовать протоколы по каждой плавке |
| Ударная вязкость — одно значение там, где НД требует два или три образца (п. 7.9 ГОСТ 19281; п. 9.4 ГОСТ 5520) | Не соответствует методу; проверить допускаемое снижение на одном образце |
| Результат другого вида или при другой температуре, чем заказанная категория (KCU вместо KCV, −20 °С вместо −40 °С) | Требование категории не подтверждено (файл 05). Пересчёт KCU ↔ KCV не допускается |
| Значения в кгс/мм² или пересчитаны с коэффициентом 10 | Пересчитать по 9,80665; браковочный признак — только если после корректного пересчёта ниже нормы |
| Механические свойства по ГОСТ 1050-2013 без указания, что образцы нормализованы (п. 7.1.17, 9.12.1) | Уточнить состояние образцов; нормы табл. 4 относятся к нормализованным образцам |
| «Гарантируется», «соответствует ГОСТ» без значений там, где НД требует результат | Не подтверждение. Исключение — где НД прямо допускает гарантию изготовителя (например, изгиб — п. 5.1.9 ГОСТ 19281-2014) |
| «УЗК 100 %, годен» без НД, класса / группы и норм оценки | Не подтверждение — требовать НД (ГОСТ 21120 для сортового, ГОСТ 22727 для листа), класс / группу качества, реквизиты протокола |
