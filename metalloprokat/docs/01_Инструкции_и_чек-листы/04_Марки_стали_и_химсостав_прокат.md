# 04 — Марки стали и химический состав проката: как проверять
**ГОСТ 380-2005, ГОСТ 1050-2013, ГОСТ 4543-2016, ГОСТ 19281-2014, ГОСТ 5632-2014 / ГОСТ 5949-2018**

> Нормы конкретной марки — брать из таблиц приложенного стандарта; здесь — где искать и как применять. Основано на файле 07 проектов «Трубы» и «Фитинги и Фланцы» с дополнениями для проката.

## 1. Общий порядок
1. Определи НД на прокат и по нему — НД на сталь (для ГОСТ 14637 — ГОСТ 380; для ГОСТ 1577 — ГОСТ 1050 и ГОСТ 4543 (п. 7.1 ГОСТ 1577-2022; марки 08Ю, 60Г, 65 и др. — по тексту п. 7.1); для ГОСТ 19281 — сам ГОСТ 19281 и т. д.).
2. Определи исполнение: по классу прочности или по марке стали (для ГОСТ 19281 — табл. 1 или табл. 7, см. раздел 4).
3. Возьми нормы по **ковшевой пробе** из таблицы НД.
4. Сравни с **фактическим анализом плавки** в сертификате. Диапазон или нормы вместо цифр — химсостав не подтверждён (файл 01, раздел 7).
5. Допускаемые отклонения в готовом прокате применяй **только если в сертификате прямо указано, что это анализ готовой продукции**. Вид анализа не указан — сравнивай с нормой марки; уточнять вид анализа не требуется (файл 05).
6. Проверь элементы, которые НД ограничивает дополнительно (Cr, Ni, Cu, As, N, Al, Ti, Nb), и есть ли право их не определять.
7. При партии из нескольких плавок — анализ по каждой плавке.

## 2. ГОСТ 380-2005 — углеродистая сталь обыкновенного качества (для ГОСТ 14637, ГОСТ 535)
- Химсостав по ковшевой пробе — **табл. 1** (п. 4.1).
- **П. 4.2:** допускается сталь без ограничения нижнего предела C и Mn при обеспечении механических свойств (кроме судо- и вагоностроения); в Ст2кп, Ст3кп, Ст4кп для сортового и фасонного проката — Si до 0,07 %.
- П. 4.3: при раскислении без Si в полуспокойной стали — Si менее 0,05 %; способ раскисления указывают в документе о качестве.
- **П. 4.4:** Cr, Ni, Cu — не более 0,30 % каждого (кроме Ст0); при скрап-процессе — Cu до 0,40 %, Cr и Ni до 0,35 %, при этом в Ст3 — C не более 0,20 %.
- **П. 4.5:** S ≤ 0,050 %, P ≤ 0,040 % (кроме Ст0).
- **П. 4.6:** N ≤ 0,012 % (электропечь) / 0,010 % (мартен, конвертер); до 0,013 % — при снижении P.
- **П. 4.7:** As ≤ 0,080 % (кроме Ст0).
- **Отклонения в готовой продукции — п. 4.8, табл. 2.**
- **П. 5.3:** Cr, Ni, Cu, As, N (в кипящей стали — и Si) **допускается не определять** при гарантии изготовителя → их отсутствие в сертификате не является нарушением.
- ГОСТ 14637-2024, п. 7.1.1.4: по требованию заказчика S ≤ 0,040 %, P ≤ 0,030 % для категорий 1–5 — проверять, только если заказано.

## 3. ГОСТ 1050-2013 — нелегированная качественная сталь (08, 10, 15, 20, 35, 45 …)
- Химсостав по ковшевой пробе — **табл. 1 и 2** (п. 5.1).
- **П. 5.1.1:** N — не более 0,006 / 0,008 % (конвертер без внепечной обработки), 0,010 % (с внепечной), 0,012 % (электропечь); не нормируется при достаточном Al или азотосвязывающих элементах — порядок оценки в файле 05.
- Пп. 5.1.5–5.1.6: допускается снижение нижнего предела отдельных элементов при выполнении требований к механическим свойствам.
- П. 5.1.7: при выплавке с ломом — остаточные элементы до 0,40 % каждого с указанием фактических значений в документе о качестве.
- **П. 5.1.8:** As ≤ 0,08 % (марки табл. 1).
- **Отклонения в металлопродукции — п. 5.2, табл. 3.**
- **П. 8.1.1:** в документе о качестве — способ выплавки и внепечная обработка для конвертерной стали.

## 4. ГОСТ 19281-2014 — прокат повышенной прочности (09Г2С, 10ХСНД, 17Г1С …)
- **Базовое исполнение (п. 5.1):** химсостав по классу прочности — **табл. 1** (п. 5.1.1, стр. 10); As ≤ 0,08 % (п. 5.1.1.1); примечание к табл. 1 — Al ≤ 0,05 %, Ti ≤ 0,04 %, Nb ≤ 0,05 %.
- **Исполнение с маркой стали (п. 5.2.1):** химсостав — **табл. 7** (п. 5.2.1.1, стр. 18–23) и примечания к ней (стр. 24): As ≤ 0,08 %; N без внепечной обработки ≤ 0,008 %, с внепечной ≤ 0,010 %, до 0,012 % — при выполнении норм ударной вязкости после механического старения независимо от категории; 09Г2, 09Г2-1, 09Г2С, 09Г2С-1, 10ХСНД раскисляют Al 0,02–0,06 % с указанием фактического Al в документе; микролегирование Al ≤ 0,05 %, Ti ≤ 0,04 %, Nb ≤ 0,05 % — с указанием в документе.
- **Отклонения в продукции — п. 5.1.2, табл. 8** (стр. 24–25; кроме N, отклонение по N — только для классов 265–325); для элементов, ограниченных только сверху, — только плюсовые.
- **Выбор таблицы.** Если в заказе указана марка (например, «265-9-09Г2С»), применяется табл. 7. Табл. 1 (по классу) — если марка не указана. Нормы табл. 1 и табл. 7 для одной марки могут расходиться (пример: класс 265 — Si ≤ 0,60 %, 09Г2С по табл. 7 — Si 0,50–0,80 %). Если вывод зависит от таблицы — показать оба варианта (файл 05, открытые вопросы).
- **Углеродный эквивалент** — формула п. 7.2 (файл 08); ограничение — п. 5.2.1.2 (стр. 25): 0,43 % для классов 265–325, 0,46 % — 345–375, 0,48 % — 390, 0,51 % — 440, **только для продукции с гарантией свариваемости (ГС)**. Без ГС в заказе Сэкв не нормируется.

## 5. ГОСТ 4543-2016 — конструкционная легированная сталь (20Х, 40Х, 30ХГСА …)
- Химсостав по ковшевой пробе — **табл. 1** (п. 7.1.2); P, S и остаточные Cu, Ni, Cr — **табл. 2**; отклонения в продукции — **табл. 3**.
- Сведения о выплавке, внепечной обработке, Al и азотосвязывающих элементах (если N не нормируют), остаточных элементах — в документе о качестве по п. 8.3.
- Суженные пределы и другие ограничения — только по заказу (п. 7.2.1–7.2.26).

## 6. ГОСТ 5632-2014 / ГОСТ 5949-2018 — нержавеющие стали и сплавы
- Марки и химсостав по маркировочному анализу — **табл. 1** ГОСТ 5632-2014 (п. 6.1); отклонения в готовой продукции — п. 6.2, табл. 2.
- Остаточные элементы: Ti ≤ 0,20 % в не легированных Ti (с исключениями, п. 6.3); Cu ≤ 0,30 % в не легированных Cu, кроме аустенитных (п. 6.4); Ni, W, V, Mo — пп. 6.5–6.9.
- Сортовой прокат из нержавеющих сталей — ГОСТ 5949-2018; документ о качестве — п. 8.3.

## 7. Типовые ошибки проверки химсостава
- Сравнивать анализ **готового проката** с нормами ковшевой пробы без учёта допускаемых отклонений — или, наоборот, применять отклонения без пометки «в готовой продукции».
- Считать отклонением отсутствие Cr, Ni, Cu, As, N там, где ГОСТ 380 (п. 5.3) разрешает их не определять.
- Путать п. 4.2 ГОСТ 380 (снятие нижнего предела C и Mn) с отклонениями в готовой продукции (п. 4.8, табл. 2).
- Брать нормы ГОСТ 19281 по табл. 1, когда в заказе указана марка (и наоборот).
- Требовать Сэкв без ГС в заказе.
