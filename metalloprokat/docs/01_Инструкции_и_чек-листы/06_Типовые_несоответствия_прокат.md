# 06 — Типовые несоответствия в документах на металлопрокат: на что смотреть в первую очередь

> Перечень пополнять после каждой проверки (с датой и номером сертификата в разделе «Случаи»).

## 1. Заказ и сертификат расходятся по условному обозначению
- Другая категория (например, 10 вместо 9) — испытания на удар другого вида или при другой температуре.
- Другая группа качества поверхности (2ГП вместо 3ГП).
- Другая точность прокатки или класс кривизны; мерная длина вместо немерной или наоборот.
- Марка стали вместо класса прочности (или наоборот), класс прочности ниже заказанного.
- Нет ГС, УЗК, Z-свойств, заказанных в обозначении.

## 2. Не хватает сведений, которые требует НД на прокат
- Не указано состояние поставки, хотя заказ его не оговаривал (п. 5.1.4 ГОСТ 19281; п. 7.1.6 ГОСТ 14637; п. 7.1.5 ГОСТ 5520).
- Нет способа выплавки / внепечной обработки для стали по ГОСТ 1050 (п. 8.1.1) и ГОСТ 4543 (п. 8.3).
- Нет фактического Al для 09Г2С, 10ХСНД (примечание к табл. 7 ГОСТ 19281).
- Не указан тип образца на растяжение (п. 7.10 ГОСТ 19281).
- Для ГОСТ 5520 — нет категории, номеров листов при полистном контроле, результатов УЗК (п. 8.3).

## 3. Перенос данных вместо испытаний
- Механические свойства равны нормативным минимумам.
- Одинаковые значения у разных плавок.
- Одно значение ударной вязкости вместо двух / трёх образцов.
- Химсостав диапазоном или равен нормам марки.

## 4. Ошибки норм и пересчёта
- Нормы взяты не из той таблицы (табл. 1 вместо табл. 7 ГОСТ 19281; табл. 2 вместо табл. 9).
- Пересчёт из кгс/мм² с коэффициентом 10 вместо 9,80665.
- Механические свойства по ГОСТ 1050 без нормализации образцов (п. 7.1.17, 9.12.1).

## 5. Идентификация
- Плавка на бирке не совпадает с сертификатом.
- Сертификат на партию другого размера или на большее количество без указания поставленного.
- Копия, заверенная посредником, без привязки к поставке (накладной).
