## 1. Порядок проверки
1. Расшифруй условное обозначение (файл 01, раздел 2): точность по толщине (А / Б), плоскостность (ПО / ПВ / ПУ / ПН), кромка (О / НО), размеры — по ГОСТ 19903; НД на прокат, марка / класс прочности, категория, состояние поставки, ГС, УЗК (класс сплошности), Z-свойства — по НД на прокат.
2. Определи НД на прокат и исполнение (базовое / по требованию заказчика / по согласованию). От него зависит таблица норм.
3. Пройди пункты раздела 3; каждая составляющая обозначения — отдельная строка Справки.

## 4. Что НЕ является нарушением
- Отсутствие УЗК, ГС, Z-свойств, удара при других температурах, если их нет в заказе и НД не требует их для заказанной категории.
- Результат «+» без нормы (статистический набор) — значение с нормой не сравнивается; если категория заказана, результат должен быть в документе.
- Химсостав в готовом прокате в пределах допускаемых отклонений — только при пометке «в готовой продукции».
- Вид термомеханической / термической обработки, выбранный изготовителем, если заказ его не оговаривает и он указан в документе (п. 7.1.6 ГОСТ 14637-2024; п. 7.1.5 ГОСТ 5520-2017).
