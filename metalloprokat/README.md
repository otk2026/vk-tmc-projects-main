# ВК ТМЦ ➤ Металлопрокат

Материалы проекта входного контроля документов о качестве (сертификатов) на металлопрокат, поставляемый как самостоятельная продукция: сортовой прокат (круг, квадрат, шестигранник, полоса) и листовой / широкополосный прокат. Инструкции, чек-листы, принятые трактовки, правила оформления Акта и Справки ПК, шаблоны, тексты ГОСТ на прокат, сортамент, сталь и УЗК. Создан 20.11.2026 по образцу проектов `pipes` и `fittings-flanges`.

> Сертификат на прокат или лист как документ на заготовку для детали, фланца, заглушки или днища проверяется в `fittings-flanges` (файл 06 и чек-листы 05, 12, 13), трубы — в `pipes`.

- [`context.md`](context.md) — инструкции проекта (роль, задача, какой файл открывать, порядок работы, жёсткие правила, контроль перед выдачей).
- [`CHANGELOG.md`](CHANGELOG.md) — история изменений.
- `docs/` — Markdown-версии всех документов проекта, разложенные по темам.
- `originals/` — оригиналы НД (PDF) и шаблоны (docx, xlsx); полный список — [`originals/README.md`](originals/README.md).

## Условные обозначения в текстовых версиях НД

| Пометка | Значение |
|---|---|
| `<!-- стр. N -->` | Начало страницы N исходного PDF (в отображении GitHub не видна) — по ней ищется место в оригинале. |
| `[знак]` | В оригинале символ набран картинкой (≥, ≤, σт, KCV-20, части формул) — текстом не передан. Читать по оригиналу или по файлу 08. |
| `[Рисунок: …]` | Рисунок, формула или таблица-картинка (например, условные обозначения в приложении Г ГОСТ 19281). |

Тексты НД скопированы из проекта `fittings-flanges` без изменений (там же описано, как они получены).
