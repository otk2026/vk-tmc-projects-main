# 06 — Условные обозначения (единый словарь)

> Расшифровки обозначений берутся **только отсюда**, чтобы в разных справках одно обозначение расшифровывалось одинаково.
> В справку включаются только те обозначения, которые в ней используются.
> Если в исходных данных есть обозначение, которого нет в словаре, — взять расшифровку из исходного документа (КРК, протокол) и сообщить, чтобы добавить его сюда.
> Для ВИК набор обозначений зависит от вида изделия: фланец, переход, отвод, заглушка — см. соответствующий раздел.

## ДК — механические свойства и документы

| Обозначение | Расшифровка |
|---|---|
| σв | Временное сопротивление (предел прочности) при растяжении |
| σт | Предел текучести |
| δ (δ5) | Относительное удлинение после разрыва |
| ψ | Относительное сужение |
| KCV | Ударная вязкость на образцах с V-образным концентратором напряжений |
| KCU | Ударная вязкость на образцах с U-образным концентратором напряжений |
| № плавки | Номер плавки металла, из которого изготовлена партия заготовок/деталей |
| Pпр | Пробное давление, применяемое при испытании детали |
