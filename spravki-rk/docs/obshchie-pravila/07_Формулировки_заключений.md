# 07 — Формулировки заключений (единые для всех справок)

| Формулировка | Когда | Цвет ячейки |
|---|---|---|
| **Соответствует** | Значение в пределах нормы, без оговорок | 92D050 |
| **Соответствует с учётом погрешности** | Значение формально за пределом нормы, но в пределах погрешности метода / допускаемого отклонения — **только если это указано в исходном документе** | FFFF00 |
| **Частично (…)** | Требование выполнено не полностью; в скобках — что именно | FFFF00 |
| **Требует пояснения (…)** | Данные противоречивы или неполны, вывод сделать нельзя | FFFF00 |
| **Не соответствует** | Значение за пределами нормы | FF0000 |
| **Не подтверждено (…)** | Нет данных / документа для оценки (для справки ДК) | FF0000 |
| **Не проверялось (…)** / **Не измерялось** | Параметр не контролировался; в скобках — причина из источника | без заливки |
| **Оценка невозможна (…)** | Нет нормы или методика не позволяет измерить (например, «нет документации производителя») | без заливки |
| **—** | Параметр не применим | без заливки |

## Правила
- Пишется **«Не соответствует»** — раздельно.
- Заключение переносится из исходного документа дословно, если оно совпадает с формулировкой из таблицы; если в источнике другое слово (например, «годен», «норма») — переводи в формулировку из таблицы и укажи это в сообщении.
- Если заключения в источнике нет — сравни норму и факт; «Соответствует с учётом погрешности» ставится только при указании погрешности в источнике.
- Итоговая фраза раздела:
  - все параметры в норме → «По результатам [вида контроля] несоответствий не выявлено — все проверенные параметры по всем [N] изделиям соответствуют требованиям [НД из источника].»
  - есть несоответствия → «Выявлены несоответствия по [N] из [M] изделий. Ниже приведены несоответствующие параметры.»
- Строка о количестве: «ИЗМЕРЕНО [N] ШТ. ИЗ [M] ШТ. ПРЕДЪЯВЛЕННЫХ.» (ВИК) / «Проверено [N] из [M] образцов.» (ХА).
