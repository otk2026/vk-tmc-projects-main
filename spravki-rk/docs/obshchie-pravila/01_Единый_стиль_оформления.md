# 01 — Единый стиль оформления справок
**Обязателен для всех справок: ДК, ВИК, ХА, УЗТ**

## 1. Лист
| Параметр | Значение |
|---|---|
| Формат | А4 (21,0 × 29,7 см), книжная ориентация |
| Поля | левое 2,0 см; правое 1,0 см; верхнее 1,5 см; нижнее 1,5 см |
| Ширина таблиц | на всю ширину текста — 18,0 см |

## 2. Шрифт
Во всём документе — **Times New Roman**.

| Элемент | Размер | Начертание | Цвет | Выравнивание |
|---|---|---|---|---|
| Заголовок справки («СПРАВКА…», вид контроля, номенклатура) | 14 пт | полужирный, прописные | тёмно-синий **1F4E79** | по центру |
| Строка «Поставщик: …» | 12 пт | курсив | тёмно-синий 1F4E79 | по центру |
| Заголовки разделов («1. …», «1.1. …», «Условные обозначения параметров») | 12 пт | полужирный | тёмно-синий 1F4E79 | по левому краю |
| Основной текст | 12 пт | обычный | чёрный (авто) | по ширине |
| Текст в таблицах | 10 пт | обычный | чёрный | по левому краю; числа — по центру |
| Таблицы ХА (10 и более колонок) | 8 пт | обычный | чёрный | по центру |
| Примечания под таблицами («* …») | 10 пт | курсив | чёрный | по левому краю |

## 3. Таблицы
| Элемент | Оформление |
|---|---|
| Шапка (строка заголовков) | заливка **E8E8E8**, текст полужирный, по центру |
| Строка «Итого» / служебные строки | заливка **F2F2F2** |
| Границы | одинарные, тонкие (0,5 пт), чёрные, у всех ячеек |
| Одинаковые значения в первой колонке (номенклатура, объект) | объединяются по вертикали |

## 4. Цвета заключений
Заливкой выделяется **только ячейка графы заключения** («Заключение» / «Соответствие НТД» / «Оценка»). Текст в окрашенных ячейках — чёрный.

| Заключение | Заливка |
|---|---|
| Соответствует | зелёный **92D050** |
| Соответствует с учётом погрешности / Частично / Требует пояснения | жёлтый **FFFF00** |
| Не соответствует / Не подтверждено | красный **FF0000** |
| Не проверялось / Не измерялось / — | без заливки |

Полный список формулировок — файл 07.

## 5. Выделение значений
- Фактическое значение **вне нормы** (или на границе с учётом погрешности) в таблицах результатов — шрифт **красный C00000**, полужирный.
- Остальные значения — чёрные.

## 6. Структура любой справки
1. Заголовок: «СПРАВКА» (или «СВОДНАЯ СПРАВКА») + «ПО РЕЗУЛЬТАТАМ …» + номенклатура (если указывается в образце).
2. «Поставщик: …».
3. Перечень изделий / «Условные обозначения параметров» — если есть в шаблоне.
4. Разделы с результатами — нумерация «1.», «1.1.», «1.2.» …
5. Примечания под таблицами.
6. Подпись (если есть в шаблоне): «Справку составил: инженер ОТК ____ / ____ /», «Дата: ____».

## 7. Запрещено
- Менять формат листа, поля, шрифт и размеры.
- Использовать другие цвета (в т.ч. пастельные E2EFDA, FFF2CC, FCE4E4, D9D9D9).
- Выделять цветом ячейки, кроме графы заключения, шапки и строки «Итого».
- Писать «Несоответствует» слитно.
