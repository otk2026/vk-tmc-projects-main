# 02 — Справка по результатам контроля документов по качеству (ДК)
**Шаблон: Шаблон_Справка_ДК.docx. Оформление — файл 01.**

## Исходные данные (прикладываются в чат)
- Акты несоответствия ДК (xlsx) — номера актов, номенклатура, перечень несоответствий;
- Справки ПК (справки по несоответствиям) из проектов «ВК ТМЦ ➤ Фитинги и Фланцы» / «ВК ТМЦ ➤ Трубы» / «ВК ТМЦ ➤ Детали по ТУ и ОСТ» — формулировки несоответствий;
- заявка / КД — проекты применения (если не указаны в актах).

## Структура (строго по шаблону)
1. **Заголовок:** «СПРАВКА» / «ПО РЕЗУЛЬТАТАМ КОНТРОЛЯ ДОКУМЕНТОВ ПО КАЧЕСТВУ» / краткий перечень номенклатуры (через запятую, коротко: «Фланец приварной встык DN50 PN16, Переход П 426х12-273х10, …»).
2. «Поставщик: …» — из актов.
3. **Условные обозначения параметров** — вводная фраза + таблица «Обозначение | Расшифровка» (файл 06, раздел ДК). Включать только обозначения, которые встречаются в тексте справки.
4. **Проекты применения деталей** — таблица «Наименование детали | Проект применения».
5. **1. Несоответствия по документации (Акты ДК)** — таблица «Номенклатура | № Акта ДК | Несоответствия документации».

## Правила заполнения таблицы раздела 1
- Одна строка — одна позиция номенклатуры = один Акт ДК.
- «Номенклатура» — полное наименование из Акта (графа «Наименование ТМЦ»).
- «№ Акта ДК» — номер из Акта без изменений (с ведущими нулями).
- «Несоответствия документации» — нумерованный перечень «1) … 2) …», каждый пункт с новой строки в той же ячейке:
  **суть несоответствия — факт (номер документа, партия, значение) (ссылка на НД в скобках)** — формулировки берутся из Акта / справки по несоответствиям, по смыслу без изменений, можно сократить до одного-двух предложений.
- Порядок строк — как в перечне номенклатуры заголовка.
- Если по позиции Акта нет (несоответствий не выявлено) — строка остаётся: «№ Акта ДК» — «—», текст — «Несоответствий не выявлено».
- Заливка в этой справке не используется, кроме шапки таблиц (E8E8E8).
