# 04 — Сводная справка по результатам химического анализа (ХА)
**Шаблон: Шаблон_Справка_ХА.docx. Оформление — файл 01.**

## Исходные данные (прикладываются в чат)
- протоколы химического анализа испытательной лаборатории — номера образцов, марка стали, массовые доли элементов, заключение;
- заявка / перечень поставки — позиции и заявленная марка стали;
- **нормы химсостава** — из протокола (если лаборатория их указала) или из документа, который я приложу. Сам нормы по ГОСТ не подставляй.

## Структура (строго по шаблону)
1. **Заголовок:** «СВОДНАЯ СПРАВКА ПО РЕЗУЛЬТАТАМ» / «ХИМИЧЕСКОГО АНАЛИЗА».
2. «Поставщик: …».
3. **Условные обозначения параметров** — «Расшифровка сокращений, используемых в тексте и таблицах справки:» + таблица (файл 06, раздел ХА). Строки с НД на марку («ГОСТ 1050-2013 — …») — только если эта НД указана в протоколе / исходных данных.
4. **1. Результаты и несоответствия по результатам химического анализа.**
5. Для каждой позиции — подраздел:
   - «1.N. Позиция №N — [наименование] (заявлена сталь [марка])»;
   - «Протоколы №№[диапазон]. Проверено N из M образцов.»;
   - таблица: **Образец | Марка стали | C | Si | Mn | P | S | Cr | Ni | Cu | V | Al | Ti | Nb | As | Соответствие НТД**;
   - последняя строка таблицы — **норма** по НД из исходных данных (первая ячейка — обозначение НД, например «ГОСТ 1050-2013»). Если нормы в исходных данных нет — строку не добавлять и написать об этом в сообщении;
   - примечание «* …» под таблицей, если элементы не измерялись (текст причины — из протокола).

## Правила заполнения
- Значения — как в протоколе, без округления; «<0,002» и т.п. — без изменений; неизмеренный элемент — «—» и примечание «*».
- Набор колонок элементов одинаков во всех таблицах справки; если элемент не определялся ни в одном образце — всё равно оставить колонку с «—».
- Значение за пределом нормы (или на границе с учётом погрешности) — красный полужирный шрифт C00000.
- «Соответствие НТД»: «Соответствует» (92D050), «Соответствует с учётом погрешности» (FFFF00 — только если так указано в протоколе или погрешность метода дана в исходных данных), «Не соответствует» (FF0000).
- Таблицы — шрифт 8 пт (файл 01).
