# 03 — Справка по результатам визуально-измерительного контроля (ВИК)
**Шаблон: Шаблон_Справка_ВИК.docx. Оформление — файл 01.**

## Исходные данные (прикладываются в чат)
- КРК (карты результатов контроля) / протоколы ВИК — заводские номера, контролируемые параметры, **нормы** (номинал и допуск), фактические значения, заключения;
- заявка / перечень поставки — наименования и количество.
Нормы берутся **только из КРК / протокола**. Если нормы нет — «норма не указана в исходных данных».

## Структура (строго по шаблону)
1. **Заголовок:** «СПРАВКА» / «ПО РЕЗУЛЬТАТАМ ВИЗУАЛЬНО-ИЗМЕРИТЕЛЬНОГО КОНТРОЛЯ (ВИК)».
2. «Поставщик: …».
3. **Изделия, охваченные настоящей справкой:** маркированный список «Наименование, НД — N шт.».
4. **Условные обозначения параметров** — вводная фраза «Расшифровка буквенных обозначений, используемых в таблицах ниже, приведена на основании данных карт результатов контроля (КРК) и обозначений соответствующей НД на изделие.» + для каждого изделия подзаголовок «Наименование — НД» и таблица «Обозначение | Расшифровка» (файл 06, раздел ВИК для этого вида изделия).
5. **1. РЕЗУЛЬТАТЫ ВИК ПО НОМЕНКЛАТУРЕ.**
6. Для каждого изделия — подраздел **«1.N. НАИМЕНОВАНИЕ ПРОПИСНЫМИ, НД. ИЗМЕРЕНО N ШТ. ИЗ M ШТ. ПРЕДЪЯВЛЕННЫХ.»** и далее один из двух вариантов.

### Вариант А — несоответствий нет
- Фраза: «По результатам ВИК несоответствий не выявлено — все проверенные параметры по всем N изделиям соответствуют требованиям [НД из КРК]. Ниже приведены фактические значения.»
- Таблица: **Зав. № | Проверяемый параметр по НД | Фактическое значение | Заключение** — все параметры по всем изделиям.
- «Проверяемый параметр по НД» — обозначение + норма с допуском, как в КРК (например, «b 16 + 2 мм»).
- Ячейки «Зав. №» одного изделия объединяются по вертикали.

### Вариант Б — есть несоответствия
- Таблица: **Зав. № | Несоответствующие параметры | Фактические значения (норма → факт) | Заключение** — только изделия с несоответствиями.
- «Несоответствующие параметры» — перечень обозначений через запятую («D, С, С1»).
- «Фактические значения (норма → факт)» — по каждому параметру с новой строки: «D (норма 426 ± 3 мм) → факт 429,41 мм».
- Изделия без несоответствий — одной строкой после таблицы: «Остальные изделия (зав. № …) — несоответствий не выявлено.» (если это следует из КРК).

## Заключения и цвета
- «Соответствует» — 92D050; «Не соответствует» — FF0000; «Соответствует с учётом погрешности» — FFFF00 (только если так в КРК); см. файл 07.
- Фактическое значение за пределом нормы — красный полужирный шрифт C00000.
