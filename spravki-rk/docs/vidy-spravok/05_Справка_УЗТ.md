# 05 — Справка по результатам ультразвуковой толщинометрии (УЗТ)
**Шаблон: Шаблон_Справка_УЗТ.docx. Оформление — файл 01.**

## Исходные данные (прикладываются в чат)
- протоколы / замеры УЗТ — объект (изделие, номер образца), сечения, диапазон или значения толщины;
- **допуски толщины стенки** — из КРК, протокола или документа, который я приложу (формула допуска и НД). Сам по ГОСТ не рассчитывай.

## Структура (строго по шаблону)
1. **Заголовок:** «СПРАВКА» / «ПО РЕЗУЛЬТАТАМ СРАВНЕНИЯ ФАКТИЧЕСКИХ ЗНАЧЕНИЙ» / «УЛЬТРАЗВУКОВОЙ ТОЛЩИНОМЕТРИИ (УЗТ)» / перечень изделий прописными.
2. «Поставщик: …».
3. **1. ИСХОДНЫЕ ДАННЫЕ** — «Допустимые пределы толщины стенки …» + таблица **Параметр | Объект контроля / НТД | Формула допуска** (из исходных данных).
4. **2. СРАВНЕНИЕ ФАКТИЧЕСКИХ ЗНАЧЕНИЙ УЗТ С ТРЕБОВАНИЯМИ** — таблица **Наименование объекта | Контролируемое сечение / размер | Требование по НТД, мм | Разброс значений по УЗТ, мм | Соответствие НТД**.

## Правила заполнения
- «Наименование объекта» — изделие + номер образца в скобках («Отвод П90-57×5 (3.3-ИЛ5)»); ячейки одного объекта объединяются по вертикали.
- «Требование по НТД, мм» — диапазон, рассчитанный по формуле из раздела 1 (арифметика: T − 15 % и т.п.); показать как «4,25–6,5».
- «Разброс значений по УЗТ, мм» — min–max из замеров.
- Если требование определить нельзя (нет данных) — «Оценка невозможна (…)», в графе соответствия — «—» без заливки.
- «Соответствие НТД»: «Соответствует» (92D050); «Соответствует с учётом погрешности» (FFFF00 — только если погрешность прибора дана в исходных данных); «Не соответствует» (FF0000).
- Значение, выходящее за пределы требования, в графе «Разброс» — красный полужирный C00000.
