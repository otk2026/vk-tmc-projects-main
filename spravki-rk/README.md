# Справки по результатам контроля

Материалы Claude-проекта «Справки по результатам контроля»: правила оформления справок ОТК по результатам входного контроля (ДК, ВИК, ХА, УЗТ).

Дата выгрузки: 01.11.2026.

## Структура папки

```
spravki-po-rezultatam-kontrolya/
├── README.md                 — этот файл
├── context.md                — инструкции проекта (дословно)
├── docs/
│   ├── obshchie-pravila/     — общие правила для всех видов справок
│   └── vidy-spravok/         — правила для каждого вида справки
└── originals/                — исходные файлы (см. пояснение ниже)
```

## Об исходных файлах (originals/)

Все 7 документов проекта изначально хранились в Claude-проекте **в формате Markdown (.md)**. Файлов Word, PDF или Excel в проекте нет.
Поэтому версии в `docs/` — это сами исходные тексты, перенесённые без изменений, а не конвертация. Папка `originals/` оставлена пустой (только пояснение внутри), чтобы не создавать дубли или поддельные «оригиналы».
