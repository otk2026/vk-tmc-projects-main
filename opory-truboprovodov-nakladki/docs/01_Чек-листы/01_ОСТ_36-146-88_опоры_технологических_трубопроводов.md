# 01 — Чек-лист: опоры по ОСТ 36-146-88 «Опоры стальных технологических трубопроводов на Ру до 10 МПа. Технические условия» (с Изм. № 1)

> Оригинал — `originals/ОСТ 36-146-88.pdf` (41 стр.). Номера страниц — страницы этого PDF.
> **Сверено по оригиналу 11.11.2026:** табл. 11 и пример обозначения типа ТО (стр. 25–26), п. 2.4 схема обозначения и п. 3.1–3.5 (стр. 32), табл. 17–18, п. 3.5.1–3.7 (стр. 33), разд. 5–7 (стр. 37), приложение 2 — форма сертификата (стр. 40). Остальное — по текстовой версии.

> ОСТ — технические условия: технические требования, комплектность, приёмка, маркировка и форма сертификата — в самом стандарте. Гарантии, упаковка, транспортирование, хранение — по ГОСТ 22130-86 (п. 7.3, 9.1) — **текста ГОСТ 22130 в проекте нет**.

## 1. Область применения (стр. 1, 6)

- Подвижные и неподвижные опоры **стальных технологических трубопроводов на Ру до 10 МПа**, наружный диаметр 18–1420 мм, среда от 0 до 450 °С, температура окружающей среды до минус 70 °С (п. 2.1, стр. 6).
- **Не распространяется** на опоры трубопроводов с хладоагентами и хладоносителями, трубопроводов **электрических станций**, трубопроводов в вечномерзлых и пучинистых грунтах (стр. 1). Опоры трубопроводов ТЭС — ОСТ 34-10-616/617 (чек-лист 02).

## 2. Идентификация — БЛОКИРУЮЩИЙ шаг

**Схема обозначения** (п. 2.4, стр. 32, сверено): `Опора – Dн трубопровода – тип опоры – исполнение – материал – ОСТ 36-146-88`.
Пример типа ТО: **ОПОРА 219-ТО-A1-20 - ОСТ 36-146-88**; с отверстиями в плите — **ОПОРА 219-ТО-A10-20 - ОСТ 36-146-88** (стр. 26, сверено).

| Проверка | Как |
|---|---|
| Тип опоры | По табл. 1 (стр. 2–5): ТП, ТХ, КП, КХ, ТР, ШП, УП, ХБ, ТО, ВП, КН |
| Исполнение | По таблице типа (для ТО — табл. 11: A1, A2; с отверстиями в плите — A10, A20) |
| Материал | Марка стали — часть обозначения (п. 2.4). Если в номенклатуре заказчика марки нет — брать из КД / заказа; нет и там — неопределённость, запросить |
| Dн трубопровода | Есть ли строка для этого Dн в таблице типа |

**Тип ТО — опоры трубчатые крутоизогнутых отводов** (табл. 11, стр. 25–26, сверено). Значения для номенклатуры этого проекта:

| Dн | Исполнение | Масса, кг, не более | Допускаемые нагрузки, кН: вертикальная / осевая при Px = Pz / при Px = 0,5Pz |
|---|---|---|---|
| 325 | A1 | 20,1 | 25,0 / 25,0 / 30,0 |
| 325 | A2 | 22,0 | то же |
| 426 | A1 | 35,9 | 35,0 / 40 / 50 |
| 426 | A2 | 38,9 | то же |

> Обозначение «325-ТО-АI» / «426-ТО-АI» в номенклатуре заказчика — **исполнение A1** (цифра 1 записана латинской «I»). Это допущение — указывать в разделе допущений справки; в документе изготовителя должно быть «A1».

## 4. Комплектность (раздел 4, стр. 35–36)

- Поставка комплектно по рабочим чертежам (п. 4.1). Состав комплекта — **табл. 19** (стр. 36): для **ТП, ТР, ТО, ШП — корпус 1 шт.** (для ТО и ТР — корпус в сборе с опорной плитой), подушек, хомутов, болтов, гаек нет.
- Упоры — по согласованию (п. 4.3).

## 5. Приёмка (раздел 5, стр. 36–37, сверено)

- Приёмка техническим контролем изготовителя (п. 5.1).
- **Партия — детали одного типоразмера, не более 200 шт.** (п. 5.2.1).
- Выборка для контроля по п. 3.7.1, 3.8, 3.10, 3.12–3.16 — 3 % от партии, не менее 5 шт. (п. 5.3).

## 6. Документ о качестве — сертификат (п. 7.2, стр. 37; приложение 2, стр. 40–41, сверено)

**К каждой партии — сертификат, заполненный ОТК предприятия-изготовителя**; форма — рекомендуемое приложение 2. Поля формы:

| Поле | Обязательность при проверке |
|---|---|
| Наименование и адрес предприятия-изготовителя, товарный знак | Должно быть |
| Номер и дата сертификата | Должно быть |
| Заказчик, адрес заказчика, заказ-наряд, транспортный № | Желательно (форма рекомендуемая) |
| **Условное обозначение опор** (полное, по п. 2.4) | Должно быть — основа идентификации |
| **Номер партии** | Должно быть (п. 5.2) |
| Допускаемые нагрузки: вертикальная; осевая при Px = Pz и Px = 0,5Pz | Должны совпадать с таблицей типа |
| Количество, шт.; масса, кг | Масса — не более табличной |
| Комплектность (по табл. 19) | Должна быть |
| Штамп ОТК, подпись начальника ОТК | Должно быть |
| «Разрешение на изготовление № … выдано …» | Поле устаревшей формы — **отсутствие не нарушение** |

## 7. Маркировка (п. 7.1, стр. 37)

На наружной поверхности каждой опоры — условное обозначение без наименования и товарный знак изготовителя. Проверяется при ВИК; в документах — только если в сертификате приведена маркировка.

## 8. Что НЕ является нарушением

- Форма сертификата отличается от приложения 2 — форма **рекомендуемая**; нарушение — только отсутствие сведений, без которых нельзя идентифицировать продукцию и партию.
- Нет документа ТР ТС — **не требуется**: опорно-подвесные системы трубопроводов исключены из ТР ТС 032/2013 (п. 3 «ф») — файл 05.
- Нет протоколов механических испытаний опор — ОСТ их не требует; качество металла подтверждается сертификатом на материал (п. 3.3).
- Нет отметки о гидроиспытании — опоры давлением не испытываются.

## 9. Критические точки

1. Полное обозначение с маркой стали (п. 2.4) — в сертификате и (или) КД.
2. Марка стали по табл. 17 и её мин. температура против условий заказа.
3. Сертификат на материал (п. 3.3) или испытания (п. 3.4).
4. Номер партии; партия ≤ 200 шт. одного типоразмера.
5. Масса и допускаемые нагрузки — по таблице типа.
6. Подпись начальника ОТК, штамп ОТК.
