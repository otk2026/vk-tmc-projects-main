# ВК ТМЦ ➤ Опоры трубопроводов и накладки — материалы проекта

Проверка документов о качестве на **опоры и подвески трубопроводов и накладки**: Справка ПК — всегда, Акт несоответствия ДК — при браковочных признаках или неопределённостях. Главная инструкция — [`context.md`](context.md).

Не входят в проект: днища по ГОСТ 6533-78 (`fittings-flanges`); детали по ГОСТ 17375–17380 и фланцы (`fittings-flanges`); детали по ТУ и ОСТ 34 10.7xx-97 (`details-tu-ost`); трубы (`pipes`).

## Структура

