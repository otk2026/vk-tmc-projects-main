# Инструкция для ИИ-агента (ChatGPT, Codex, Claude и др.)

Это репозиторий **ВК ТМЦ** — материалы для входного контроля документов о качестве на продукцию (детали трубопроводов, фланцы, трубы), разработки и обработки карт результатов контроля (КРК) и справок для руководства. Пользователь — начальник ОТК. Отвечай по-русски.

## С чего начать — всегда

1. Прочитай **[`README.md`](README.md)** — оглавление: проекты, **автовыбор проекта по заданию**, сквозной порядок работы, правило имён выходных файлов.
2. Определи проект **сам** по разделу «Автовыбор проекта по заданию» — пользователь не обязан его называть. Если в задании есть ГОСТ / ТУ / ОСТ / АТК в обозначении позиций — проект определяется по ним.
3. Прочитай `context.md` выбранного проекта — это **главная инструкция**, выполняй её полностью и буквально. Затем `README.md` проекта (состав файлов, известные потери текста).
4. Выполни задачу **от начала до конца** по «Сквозному порядку работы» из `README.md` и сдай выходные файлы с именами по правилу.

## Обязательные правила

- Нормы — только из НД, которые есть в репозитории. Где лежит любой ГОСТ / ТУ / ОСТ — [`INDEX_НД.md`](INDEX_НД.md). Нет НД — так и напиши, не подставляй значения по памяти.
- Цифры, знаки, допуски и табличные значения сверяй по **PDF-оригиналу** (`originals/`), а не по текстовой версии `.md`. Пометку «сверено по оригиналу, стр. N» ставь только если действительно открыл эту страницу. Не можешь открыть PDF, .docx или .xlsx из репозитория — так и скажи пользователю, номер страницы не придумывай.
- Сокращения (ДК, Справка ПК, Справки РК, КРК, КИС, браковочный признак / неопределённость …) — в [`GLOSSARY.md`](GLOSSARY.md).
- Не выдумывай данные: поля без данных (код КИС, № заявки, ФИО, даты) оставляй пустыми и перечисляй в ответе.
- Не останавливайся на промежуточных списках: пользователь ждёт готовый результат (Акт, Справку ПК, КРК, Справку РК, Заключение о применимости ТР ТС).

## Если вносишь изменения в репозиторий

- Меняй файлы так, чтобы `context.md`, чек-листы и `README.md` оставались согласованы. Историю изменений дописывай в `CHANGELOG.md` проекта, а не в `README.md`.
- После правок запусти **`python3 tools/check_repo.py`** — должно быть «Замечаний нет». После добавления или удаления НД — `python3 tools/check_repo.py --index` (пересобирает `INDEX_НД.md`).
- Репозиторий приватный: тексты ГОСТ из «Техэксперта» и рабочие данные наружу не передавать.
