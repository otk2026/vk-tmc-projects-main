# krk-control-cards — карты результатов контроля (КРК)

Материалы Claude-проекта «Разработка карт результатов контроля»: составление и заполнение КРК для входного контроля деталей трубопроводов (отводы, тройники, переходы, заглушки), фланцев, труб и запорно-регулирующей арматуры (ЗРА) в ОТК АО «МОСГАЗ».

## Структура

```
krk-control-cards/
├── README.md        — этот файл: перечень документов, проверка ссылок, ограничения конвертации
├── context.md       — инструкции проекта (дословно)
├── docs/            — текстовые версии документов в Markdown, по темам
│   ├── 01_справочник-и-инструменты/
│   ├── 02_КРК-шаблон/
│   ├── 03_КРК-примеры-детали-трубы-фланцы/
│   ├── 04_КРК-примеры-ЗРА/
│   ├── 05_ГОСТ-детали-трубопроводов/
│   ├── 06_ГОСТ-трубы/
│   ├── 07_ГОСТ-фланцы/
│   └── 08_ГОСТ-допуски-и-посадки/
└── originals/       — исходные файлы проекта (PDF, XLSX, TXT, PY); имя = имя .md-версии
```

Как устроены .md-версии:

- **PDF (ГОСТы)** — полный текст с нумерацией пунктов; таблицы — в Markdown (объединённые ячейки оставлены пустыми, многострочные значения через `<br>`); символы и формулы, которые в PDF были картинками (D<sub>1</sub>, T<sub>в</sub>, σ<sub>в</sub>, R ≈ 1,5DN и т. п.), переписаны текстом; чертежи заменены пометками `[Рисунок: …]`; таблицы, которые в PDF были картинками, переписаны вручную и помечены цитатой «Таблица в PDF дана изображением…». Метка `<!-- стр. N -->` — начало страницы N оригинала. Колонтитулы «Техэксперт» убраны.
- **XLSX (КРК)** — все ячейки шапки с адресами объединений, таблица проверок (включая служебные столбцы X–AA), полный текст формулы заключения, проверка данных, условное форматирование, примечания к ячейкам, форматы ячеек и список объединённых ячеек. Изображения — пометками `[Рисунок: …]`.
- **TXT / PY** — содержимое без изменений (код — в блоке `python`).

## Ограничения конвертации — проверить вручную

Плохих сканов нет: у всех PDF есть текстовый слой, весь текст извлечён (контроль по словам: расхождение с текстом PDF меньше 0,5 %, в основном это разбиение на слова у «мм²/см²»). Потери и ручная работа сосредоточены в таких местах:

1. **ГОСТ 17379-2001** — табл. 1 и 2 (размеры заглушек, K, масса) в PDF только картинками; переписаны вручную. Сверить в первую очередь: в табл. 1 у DN 40/50 на картинке смещены границы ячеек массы.
2. **ГОСТ 33259-2015** — табл. 1 (применяемость типов фланцев по PN/DN) в PDF картинкой: отметки «x» считаны с изображения по сетке. Формы «Заявка» (прил. А) и «Паспорт» переписаны вручную. Схема обозначений по ГОСТ 12820/12821/12822 ↔ 33259 восстановлена по выносным линиям. Чертежи фланцев и уплотнительных поверхностей заменены описаниями; размеры с чертежей не переносились. В многостраничных размерных таблицах объединённые по вертикали ячейки (DN, PN) заполнены только в первой строке.
3. **ГОСТ 25346-2013** — рис. 1–9 и В.1 (схемы полей допусков) только описаны. На рис. 8–9 есть надписи и формулы (ES = EI + IT и т. п.), они перечислены в описании, но расположение на схеме не передано. Рис. 10–13 и С.1 (предпочтительные поля и посадки, матрица GPS) переписаны вручную, рамки «предпочтительных» переданы полужирным.
4. **ГОСТ 17380-2001** — табл. 6 (форма кромок): эскизы разделки в ячейках заменены описаниями. Рис. 1 (P, Q, U) и рис. 2 (волнистость) только описаны. В п. 5.1.7 (коэффициент γ<sub>n</sub>) текст в оригинале свёрстан в две колонки, поэтому строки вида «для DN от 400 до 500:» местами разорваны.
5. **ГОСТ 10706-76** — черт. 1 (разделка кромок) описан; маленькая таблица «Диаметр трубы / Размер A» с чертежа переписана вручную.
6. **ГОСТ 17375, 17376, 17378, 30753, 20295** — чертежи деталей и кромок (рис. 1, черт.) заменены описаниями. Строки таблиц, разорванные переносом страницы, собраны автоматически: стоит выборочно сверить строки на стыках страниц.
7. **Все ГОСТы** — около 280 символов и формул, которые в PDF были картинками, переписаны вручную (индексы через `<sub>`/`<sup>`). Возможны единичные ошибки в индексах. Степени в единицах вроде «Н/мм²» местами записаны как «Н/мм2».
8. **КРК (.xlsx)** — значения, формулы и правила перенесены полностью. Шрифты, ширины столбцов, высоты строк и границы ячеек в Markdown не передаются (они есть в оригиналах). Логотип и рисунки кранов из ОЛ заменены описаниями.

История изменений проекта — в [`CHANGELOG.md`](CHANGELOG.md).
