### Формулы столбца O «Заключение по результатам контроля»

Во всех строках 17–30 одна и та же формула (номер строки подставляется). Для строки 17:

```
=IF(TRIM(I17&"")="","",IF(AND(Y17="",Z17=""),IF(OR(ISNUMBER(SEARCH("не соотв",I17)),ISNUMBER(SEARCH("несоотв",I17))),"Не соответствует",IF(ISNUMBER(SEARCH("соответ",I17)),"Соответствует","Не соответствует")),IF(NOT(ISNUMBER(I17)),"Не соответствует",IF(AND(OR(Y17="",I17>=Y17-0.000001),OR(Z17="",I17<=Z17+0.000001)),"Соответствует","Не соответствует"))))
```

### Проверка данных (Data Validation)

- Диапазон `I19:I30`: тип `decimal`, оператор `between`, значение 1 `-1000000`, значение 2 `1000000`; сообщение об ошибке: «Нужно число» — «Введите измеренное значение числом (например 159,4).»
- Диапазон `I17:I18`: тип `list`, значение 1 `"Соответствует,Не соответствует"`; подсказка: «Качественный параметр» — «Выберите «Соответствует» или «Не соответствует» (можно дописать пояснение).»

### Условное форматирование

- `O17:Q30`: cellIs equal ['"Соответствует"'], заливка `FF92D050`
- `O17:Q30`: cellIs equal ['"Не соответствует"'], заливка `FFFFC7CE`, шрифт `FF9C0006`

### Примечания к ячейкам

- `Y15`: Границы допуска из графы «Проверяемый параметр». Пусто в обеих ячейках = качественный параметр (вводится «Соответствует» / «Не соответствует»).
