### Формулы столбца O «Заключение по результатам контроля»

Во всех строках 18–35 одна и та же формула (номер строки подставляется). Для строки 18:

```
=IF(TRIM(I18&"")="","",IF(AND(Y18="",Z18=""),IF(OR(ISNUMBER(SEARCH("не соотв",I18)),ISNUMBER(SEARCH("несоотв",I18))),"Не соответствует",IF(ISNUMBER(SEARCH("соответ",I18)),"Соответствует","Не соответствует")),IF(NOT(ISNUMBER(I18)),"Не соответствует",IF(AND(OR(Y18="",I18>=Y18-0.000001),OR(Z18="",I18<=Z18+0.000001)),"Соответствует","Не соответствует"))))
```

### Проверка данных (Data Validation)

- Диапазон `I24:I34`: тип `decimal`, оператор `between`, значение 1 `-1000000`, значение 2 `1000000`; сообщение об ошибке: «Нужно число» — «Введите измеренное значение числом (например 159,4).»
- Диапазон `I18:I23 I35`: тип `list`, значение 1 `"Соответствует,Не соответствует"`; подсказка: «Качественный параметр» — ««Соответствует» или «Не соответствует» (можно дописать пояснение).»
