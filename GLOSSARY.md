# Словарь терминов и сокращений

Термины, которые используются в инструкциях (`context.md`), чек-листах и выходных документах всех проектов репозитория.

## Организация работы

| Термин | Значение |
|---|---|
| **ОТК** | Отдел технического контроля. Пользователь — начальник ОТК; проверяет продукцию на соответствие требованиям НД и КД |
| **ВК** | Входной контроль — проверка поступившей продукции и документов о качестве до приёмки |
| **ТМЦ** | Товарно-материальные ценности — поставляемая продукция (детали трубопроводов, фланцы, трубы, арматура и т.п.) |
| **ДК** | Контроль документов (документов о качестве: паспортов, сертификатов, протоколов) |
| **Номенклатура** | Перечень позиций поставки, подлежащих проверке (обозначение, количество, код КИС) |
| **Код КИС, н/н** | Код позиции в корпоративной информационной системе (номенклатурный номер). Не выдумывать — если нет в данных, оставлять пустым |
| **Поставщик / изготовитель** | Поставщик — кто поставил продукцию; изготовитель — завод, выпустивший изделие. Могут не совпадать |

## Выходные документы

| Термин | Значение |
|---|---|
| **Акт несоответствия ДК** | Акт (Excel) по результатам контроля документов: перечень браковочных признаков и неопределённостей (требований представить документы). Делается при браковочных признаках или неопределённостях |
| **Справка ПК** | Справка **по поставщику** — справка по несоответствиям документов о качестве (Word). Делается всегда, автоматически вместе с Актом, в проектах `fittings-flanges`, `pipes`, `details-tu-ost` |
| **Справки РК** | Справки **для руководства** (РК — руководство): ДК, ВИК, ХА, УЗТ, УЗК, металлография, механические испытания. Делаются **только по прямому запросу** в проекте `spravki-rk` |
| **КРК** | Карта результатов контроля (Excel): перечень проверяемых параметров с нормами и результатами замеров. Разработка новой КРК — `krk-cards`, внесение замеров — `krk-processing` |
| **Заключение о применимости ТР ТС** | Документ (Word) проекта `tr-ts-applicability`: распространяется ли на позицию номенклатуры ТР ТС / ТР ЕАЭС и какой документ требовать (сертификат / декларация / не требуется) — по требованиям проекта |
| **Сводная справка** | **Не делается** в проектах проверки (решение 01.11.2026). Справка ДК для руководства — только в `spravki-rk` |

## Виды контроля (Справки РК)

| Сокращение | Значение |
|---|---|
| **ВИК** | Визуально-измерительный контроль |
| **ХА** | Химический анализ (спектральный, химсостав металла) |
| **УЗТ** | Ультразвуковая толщинометрия (измерение толщины стенки) |
| **УЗК** | Ультразвуковой контроль — дефектоскопия (поиск внутренних дефектов). **Не путать с УЗТ** |
| **МГ, металлография** | Металлографические исследования: микроструктура, балл зерна, неметаллические включения |
| **МИ, мехиспытания** | Механические испытания: растяжение (σв, σт, δ), ударная вязкость (KCU, KCV), твёрдость |

## Нормативные документы

| Сокращение | Значение |
|---|---|
| **НД** | Нормативный документ (ГОСТ, ОСТ, ТУ, ТР ТС, АТК и т.п.) |
| **Применимость ТР ТС** | Распространяется ли регламент на изделие с учётом его вида, параметров и назначения (область применения, исключения, пороги). Определяется в проекте `tr-ts-applicability` |
| **Категория оборудования** | Категория опасности по приложению 1 ТР ТС 032/2013 (1–4); 1–2 — декларирование, 3–4 — сертификация |
| **Группа рабочей среды** | По ТР ТС 032/2013: группа 1 — горючие, взрывчатые, токсичные и т. п. (природный газ); группа 2 — прочие (вода, пар, воздух) |
| **КД** | Конструкторская документация (чертёж, спецификация) |
| **ТТ заказчика** | Технические требования заказчика — дополнительные требования к поставке |
| **ГОСТ** | Межгосударственный / государственный стандарт |
| **ОСТ** | Отраслевой стандарт (например, ОСТ 34 10.7xx-97 — детали трубопроводов ТЭС) |
| **ТУ** | Технические условия изготовителя (например, ТУ 1469-016 ЗАО «ЛМК») |
| **ТР ТС** | Технический регламент Таможенного союза (ТР ТС 032/2013 — оборудование под давлением; 010/2011 — машины и оборудование; 012/2011 — взрывоопасные среды) |
| **ФНП** | Федеральные нормы и правила в области промышленной безопасности (ФНП 536 — оборудование под давлением, приказ Ростехнадзора от 15.12.2020 № 536) |
| **ОПО** | Опасный производственный объект (116-ФЗ) |
| **ЭПБ** | Экспертиза промышленной безопасности |
| **АТК** | Альбом типовых конструкций (АТК 24.200.02-90 — заглушки фланцевые) |
| **Полуфабрикат** | Металл, из которого изготовлена деталь: лист, труба, поковка, круг. Подтверждается сертификатом завода-поставщика металла |
| **Плавка** | Номер плавки металла — основа прослеживаемости «плавка → партия → деталь» |

## Классификация результатов проверки

| Термин | Значение | Куда |
|---|---|---|
| **Браковочный признак** | Прямое нарушение обязательного требования НД | Акт + Справка ПК |
| **Замечание** | Редакционный дефект, отклонение по несдаточной характеристике | Только Справка ПК |
| **Неопределённость** | Данных для оценки нет — нужен документ | Акт (как требование представить документ, без вывода о несоответствии) + Справка ПК |
| **Не соответствует** | Есть прямое отклонение от нормы | — |
| **Не подтверждено** | Отклонения нет, но и подтверждения нет | — |
| **Допущение** | Предположение, без которого оценка невозможна (вид заготовки, привязка к плавке и т.п.) — излагается открытым текстом в отдельном разделе справки | Справка ПК |

## Обозначения в документах

| Обозначение | Значение |
|---|---|
| **DN, Dу** | Номинальный (условный) диаметр, мм |
| **PN, Ру** | Номинальное (условное) давление, МПа или кгс/см² |
| **Рраб** | Рабочее давление |
| **Dн × S** | Наружный диаметр × толщина стенки, мм |
| **σв, σт (σ0,2), δ** | Временное сопротивление, предел текучести, относительное удлинение |
| **KCU, KCV** | Ударная вязкость на образцах с U- и V-образным надрезом, Дж/см² |
| **ТО** | Термическая обработка |
| **НК** | Неразрушающий контроль |
| **ТЭС** | Тепловая электростанция |

## Работа с файлами

| Термин | Значение |
|---|---|
| **Оригинал** | Исходный файл НД или шаблона в папке `originals/` проекта (PDF, Word, Excel). Нормы — по оригиналу |
| **Текстовая версия** | Markdown-копия НД в `docs/` — для поиска и чтения; знаки, индексы, таблицы могут быть искажены |
| **«По скану стр. N» / «по PDF, стр. N»** | Значение взято с изображения страницы оригинала, а не из текстовой версии |
| **OCR** | Распознанный текст скана — возможны ошибки в цифрах (I вместо 1, O вместо 0) |
