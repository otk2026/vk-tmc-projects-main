## Как сделаны текстовые версии

- **PDF (22 файла)** — у всех есть текстовый слой (это выгрузки ИС «Техэксперт», не сканы), поэтому распознавание (OCR) не применялось. Текст извлечён полностью, без пересказа.
- **Полнота** проверена автоматически: каждое слово текстового слоя PDF сверено со словами в .md (без учёта колонтитулов). Совпадение — 99,7–100 % по каждому файлу; расхождения — единичные слова, склеенные или разорванные иначе, чем в текстовом слое (например, переносы внутри ячеек таблиц).
- **Таблицы с линейками** переданы таблицами Markdown; переносы строк внутри ячейки — `<br>`. У таблиц, продолжающихся на следующей странице, первая строка продолжения стоит на месте заголовка таблицы (ограничение Markdown).
- **Таблицы без линеек** переданы строками, столбцы разделены ` | `.
- **Изображения.** В этих PDF формулы, часть символов (σв, ≤, ≥, Dн, степени ² и т. п.) и отдельные рисунки хранятся картинками, текста у них нет. Они отмечены на своём месте: `[Рисунок: символ]`, `[Рисунок: формула]`, `[Рисунок: формула или иллюстрация (крупное изображение)]`. Содержимое не восстанавливалось — сверенные формулы есть в файле 12.
- **Колонтитул** каждой страницы («Применяется с … взамен …», предупреждения «Техэксперт») приведён один раз в начале файла; границы страниц — комментарии `<!-- стр. N -->` (на GitHub не видны, нужны для ссылок «по скану стр. N»).
- **XLSX** — все значения ячеек перенесены; полужирный и подчёркнутый шрифт внутри ячеек сохранён. Вёрстка (объединения ячеек, ширины, логотип, настройки печати) в Markdown не передаётся — для работы использовать оригинал.

3. **Файл 07, п. 4 раздела 1:** «Допускаемые отклонения в готовой продукции (раздел 5)». В самом файле 07 раздел 5 — про ГОСТ 5632; отклонения описаны в разделах 2–5 по каждому стандарту. Вероятно, имелся в виду не раздел 5 файла 07 — уточнить формулировку.
