# 02 — Трубы бесшовные горячедеформированные: ГОСТ 8731-2025 / ГОСТ 8732-2025

> **Ударная вязкость:** если в КД / ТТ / заявке задано своё требование (вид, температура, норма) — проверять только по нему, нормы этого файла не применять (файл 09, решение от 25.09.2026).
**Чек-лист. Применяется вместе с файлом 01**

> Нормы сверены с текстами ГОСТ 8731-2025 и ГОСТ 8732-2025 (оба введены с 01.03.2026 взамен ГОСТ 8731-74 и ГОСТ 8732-78). Для труб, изготовленных по ГОСТ 8731-74 / 8732-78, — см. файл 09 (текстов старых редакций в базе нет).

## 1. Область и связь стандартов
- **ГОСТ 8731-2025** — технические условия на бесшовные горячедеформированные трубы круглого сечения общего назначения из нелегированной и легированной стали (разд. 1).
- **ГОСТ 8732-2025** — **только сортамент** (разд. 1). Размеры и длина труб по ГОСТ 8731 — по ГОСТ 8732 или ГОСТ 9567 (пп. 5.3, 5.4 ГОСТ 8731).
- В заказе указывают обозначение ГОСТ 8731 **и** стандарта на сортамент, марку стали (для групп А–Г), группу поставки, размеры, вид длины, для группы Д — испытательное давление (п. 5.6.1 ГОСТ 8731).

## 2. Группы поставки (п. 5.2 ГОСТ 8731-2025) — определяют, что нормируется

| Группа | Нормируется | Стали |
|---|---|---|
| **А** | механические свойства | спокойная по ГОСТ 380 |
| **Б** | химический состав | спокойная по ГОСТ 380, 1050; ГОСТ 4543, 19281 |
| **В** | механические свойства и химсостав | спокойная по ГОСТ 1050; ГОСТ 4543, 19281 |
| **Г** | механические свойства на термообработанных образцах и химсостав | спокойная по ГОСТ 1050; ГОСТ 4543, 34636 |
| **Д** | испытательное гидростатическое давление | любая (марка для группы Д не нормируется в партии, п. 8.1) |

Марки — по ГОСТ 380, 1050, 4543, 19281, 34636; другие — по согласованию (п. 5.1).

## 3. Порядок проверки

### Шаг 1. Идентификация и обозначение
НД с годом (ГОСТ 8731-2025 + ГОСТ 8732-2025 или 9567), D × S, точность (п — повышенная), вид длины, марка, **группа поставки**. Сверка с КД и заказом. Группа не указана → объём обязательных показателей не определён (неопределённость).

### Шаг 2. Партия (п. 8.1)
Один размер, одна группа поставки, одна марка стали (кроме группы Д), один вид термообработки (если применимо); по требованию — одна плавка.
Не более **400 шт.** (D < 76 мм) / **200 шт.** (D ≥ 76 мм); для партии одной плавки — до 600 / 400 шт.

### Шаг 3. Химический состав
- Группы **Б, В, Г** — по НД на марку (ГОСТ 380, 1050, 4543, 19281, 34636) (п. 6.2.1); контроль — 1 от плавки (табл. 4). Допускается приёмка по документу о качестве трубной заготовки (сноска к табл. 4).
- Группы **А и Д** — **не регламентируется**, если в заказе не согласовано иное (п. 6.2.2).
- Углеродный эквивалент — только если согласован в заказе (п. 6.2.3), формула — п. 9.2.1.
- Нормы и допустимые отклонения — файл 07.

### Шаг 4. Механические свойства (табл. 4 — 2 трубы от партии)
- **Группа А** — табл. 1 (σв / σт / δ5, не менее): Ст2сп 343 / 216 / 24; Ст4сп 412 / 245 / 20; Ст5сп 490 / 274 / 17; Ст6сп 588 / 304 / 14. **σт определяют по требованию заказчика** (сноска к табл. 1). Проверять по приложенному тексту.
- **Группы Б и Д** — механические свойства **не нормируют и не определяют** (п. 6.3.2).
- **Группа В** — табл. 2 (при S ≤ 45 мм): σв, σт, δ5. **ψ (при S > 7 мм) и твёрдость HB (при S > 10 мм) — по требованию заказчика** (сноска к табл. 2). Для 09Г2С σв ≥ 470, σт ≥ 345 — по требованию. Пример по табл. 2: сталь 20 — σв ≥ 412, σт ≥ 245, δ5 ≥ 21; 09Г2С — 430 / 265 / 21.
- **Группа Г** — по ГОСТ 1050, 4543, 34636 на термообработанных образцах; в документе должны быть и режим термообработки образцов (п. 6.3.4).
- Испытания на растяжение — на продольных образцах; допускается НК механических свойств по ГОСТ 30415 (п. 9.3).

### Шаг 5. Ударная вязкость
- **Группа Г** — испытание обязательно по табл. 4, но п. 6.3.4 устанавливает ударную вязкость «если применимо»: норма берётся из НД на марку (ГОСТ 1050, 4543, 34636). **Если НД на марку KCU не нормирует — требование не применяется.** Пример: ГОСТ 1050-2013 нормирует ударную вязкость только для марок 25–50 и 25Г–50Г (табл. 11); для стали 20 группы Г нормы нет.
- **Группа В — только по требованию заказчика**, для S ≥ 6 мм; тип образца, температура и норма согласуются в заказе (п. 6.3.3).
- Группы А, Б, Д — не нормируется.
- Значение — среднее по трём образцам; на одном образце допускается снижение на **30 %** от нормы (п. 9.5).

### Шаг 6. Технологические испытания и макроструктура
- Загиб, сплющивание, раздача, бортование — **по требованию заказчика** для групп А и В из Ст2сп, Ст4сп, 10, 20, 09Г2С, 10Г2, 15ХМ (п. 6.5.1, табл. 3); для других — по согласованию (п. 6.5.2). Нормы раздачи — табл. 5, сплющивания — формула п. 9.8.
- Макроструктура — по требованию для S ≥ 12 мм (п. 6.4).

### Шаг 7. Гидроиспытание и НК
- **Группа Д** — гидроиспытание **каждой трубы** давлением из заказа (п. 6.8.1, табл. 4).
- **Группы А и В** — **по требованию заказчика**, по ГОСТ 3845 (40 % мин. σв), до 20 МПа; способность выдерживать давление **может быть гарантирована изготовителем без испытаний** (п. 6.8.1).
- Контроль герметичности электромагнитным методом, НК продольных дефектов — по согласованию (пп. 6.8.2, 6.8.3); УЗК по ГОСТ 17410 с отражателем 10 % S — по требованию (п. 5.6.2 м).

### Шаг 8. Состояние поставки, поверхность, концы
- Поставка после горячей деформации или термообработки — **по выбору изготовителя**; термообработка — по согласованию (п. 6.1).
- Поверхность — п. 6.7; концы — под прямым углом, без заусенцев (п. 6.9.1); фаска по ГОСТ 34094 — по требованию (п. 6.9.2).

### Шаг 9. Длина (ГОСТ 8732-2025, разд. 6)
- Немерная — 4,0–12,5 м; мерная — в пределах немерной; кратная — в пределах немерной с припуском 5 мм на рез.
- В партии мерных труб допускается не более 5 % массы партии труб немерной длины.
- Предельные отклонения размеров и длины — разд. 7 ГОСТ 8732-2025.

### Шаг 10. Документ и маркировка
- Документ 3.1 / 3.2 по ГОСТ 31458 (п. 8.3 ГОСТ 8731-2025).
- Маркировка — по ГОСТ 10692 (п. 6.10).

## 5. Что НЕ является нарушением
- Отсутствие химсостава у групп **А и Д** (п. 6.2.2).
- Отсутствие механических свойств у групп **Б и Д** (п. 6.3.2).
- Отсутствие σт у группы А, ψ и HB у группы В — если не заказаны (сноски к табл. 1, 2).
- **Отсутствие ударной вязкости у группы В**, если не заказана (п. 6.3.3).
- Отсутствие гидроиспытания у групп А и В, если не заказано; гарантия изготовителя без испытаний (п. 6.8.1).
- Отсутствие технологических испытаний и макроструктуры, если не заказаны (пп. 6.4, 6.5.1).
- Поставка без термообработки (п. 6.1).
- Приёмка химсостава по документу на трубную заготовку (сноска к табл. 4).
- Снижение KCU/KCV на одном из трёх образцов до 30 % от нормы (п. 9.5).
