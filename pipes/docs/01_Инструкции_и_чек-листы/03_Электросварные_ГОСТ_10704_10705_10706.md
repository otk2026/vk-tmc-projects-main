# 03 — Трубы электросварные: ГОСТ 10704-91 / ГОСТ 10705-80 / ГОСТ 10706-76

> **Ударная вязкость:** если в КД / ТТ / заявке задано своё требование (вид, температура, норма) — проверять только по нему, нормы этого файла не применять (файл 09, решение от 25.09.2026).
**Чек-лист. Применяется вместе с файлом 01**

> Нормы сверены с текстами ГОСТ 10704-91 (Изм. 1–3), ГОСТ 10705-80 (Изм. 1–8), ГОСТ 10706-76 (Изм. 1–4). Числовые нормы брать из таблиц приложенных стандартов.

## 1. Связь стандартов
- **ГОСТ 10704-91** — сортамент электросварных прямошовных труб (п. 1); технические требования — по ГОСТ 10705 / 10706 и др. (п. 11).
- **ГОСТ 10705-80** — ТУ на электросварные трубы (размеры по ГОСТ 10704, п. 1.1). По табл. 1–3 и п. 2.2 — трубы Ø 10–630 мм.
- **ГОСТ 10706-76** — ТУ на прямошовные электросварные трубы общего назначения **диаметром 478–1420 мм** (вводная часть; размеры по ГОСТ 10704, п. 1.1), одно- и двухшовные (п. 1.7).

## 2. Группы — определяют, что нормируется

| Группа | ГОСТ 10705-80 (п. 2.2) | ГОСТ 10706-76 (п. 1.2) |
|---|---|---|
| **А** | механические свойства; Ст1–Ст4 по ГОСТ 380 | механические свойства; Ст2, Ст3 по ГОСТ 380, кат. 1 по ГОСТ 14637 |
| **Б** | химсостав; Ст1–Ст4, 08, 10, 15, 20, 08Ю, 22ГЮ, низколегированные (Сэкв ≤ 0,46 %, Ø 114–630) | химсостав; Ст2, Ст3 по ГОСТ 380 и 14637 |
| **В** | химсостав и механические свойства; те же марки | химсостав и механические свойства; Ст2, Ст3 (категории по ГОСТ 14637) и **низколегированные с Сэкв ≤ 0,48 %** |
| **Д** | испытательное гидродавление | без нормирования механических свойств и химсостава, с нормированием гидродавления |

**ГОСТ 10706-76 не предусматривает сталь 20** и другие качественные углеродистые стали (п. 1.2).

## 3. ГОСТ 10705-80 — порядок проверки

### 3.1 Партия (п. 3.1)
Один размер, одна марка, один вид термообработки, одна группа; один документ о качестве по ГОСТ 10692 + **химсостав по документу изготовителя заготовки**. Не более: 1000 шт. (Ø до 30), 600 (св. 30 до 76), 400 (св. 76 до 152), 200 (св. 152).

### 3.2 Термообработка (п. 2.3)
Термообработанные (по объёму или по сварному соединению), горячередуцированные или без термообработки; **вид термообработки выбирает изготовитель**. В документе — фактическое состояние, от него зависят нормы механических свойств.

### 3.3 Механические свойства основного металла
- Термообработанные и горячередуцированные, группы А и В — **табл. 1** (п. 2.4); по требованию — повышенные σт и δ (примечание к табл. 1).
- Без термообработки и с термообработкой сварного соединения — **табл. 2** (Ø 10–152) и **табл. 3** (Ø св. 152 до 630) (п. 2.5).
- **σт определяют по требованию заказчика** (п. 3.5).
- Испытания — 2 трубы от партии (п. 3.5); растяжение по ГОСТ 10006; допускается НК механических свойств (п. 4.7).

### 3.4 Ударная вязкость (п. 2.12, табл. 4)
- **Обязательна** для труб, **термообработанных по всему объёму**, групп А и В, с **S ≥ 6 мм** из Ст3сп, Ст3пс (кат. 3–5), 10, 15, 20 и низколегированных сталей.
- Нормы KCU (табл. 4): Ст3сп, Ст3пс, 10, 15, 20 — 78,4 Дж/см² при +20 °С; 39,2 — при −20 °С; 39,2 — после механического старения; низколегированные — 78,4 / 39,2 / не нормируется. **Температуру испытания указывает заказчик** (п. 4.5).
- 22ГЮ — по требованию, нормы по согласованию (п. 2.12).
- Среднее по трём образцам; на одном допускается снижение на 9,8 Дж/см² (1 кгс·м/см²) (п. 4.5).

### 3.5 Технологические испытания
- **Сплющивание** — для труб по п. 2.13 (термообработанные Ø до 152; горячередуцированные и без термообработки Ø св. 20 до 152 с S/D ≤ 0,06; с термообработкой сварного соединения).
- **Раздача** — для Ø до 108 мм из марок табл. 5 (п. 2.14), с исключениями.
- **Загиб, бортование, растяжение сварного соединения — только по требованию заказчика** (п. 2.15, Изм. № 8; пп. 2.16–2.18).
- Трубы, испытанные на сплющивание, на раздачу не испытывают (п. 3.5).

### 3.6 Гидроиспытание и НК
- Вид **I**: 6,0 МПа (Ø < 102) / 3,0 МПа (Ø ≥ 102); вид **II** — расчётное по ГОСТ 3845 (90 % σт, ≤ 20 МПа), по требованию заказчика (п. 2.11).
- **Сварные швы групп А, Б, В — 100 % НК** (п. 3.3а).
- При НК **по периметру всей трубы** гидроиспытание труб вида I допускается не проводить; при НК **только сварного шва** — дополнительное гидроиспытание 15 % труб партии или согласование об отказе от него (см. ниже). Взамен НК допускается повышенное гидродавление каждой трубы (п. 3.3а).
- ⚠️ К п. 3.3а в тексте есть примечание: по поправке ИУС № 5-2005 абзацы 8–10 п. 3.3а должны быть удалены. Какие именно абзацы — по электронному тексту не установить. Перед претензией по гидроиспытанию / НК сверять с официальным изданием.
- **Группа Д** — гидроиспытание или НК шва (п. 3.3а).
- При НК шва — дополнительное гидроиспытание **15 % труб** партии; по согласованию гидроиспытание может не проводиться (п. 3.3а).
- Места заварки швов — НК, отремонтированные трубы — гидроиспытание (п. 3.7).
- Методы НК шва — ультразвук, токовихревой, магнитный или рентгеновский (п. 4.14).

### 3.7 Поверхность, швы
- Не допускаются трещины, плены, закаты, рванины, риски; смещение кромок — до 10 % S; ремонт основного металла сваркой не допускается (п. 2.6).
- На трубах Ø ≥ 57 мм допускается один поперечный шов (п. 2.7).
- Наружный грат удалён (п. 2.8).

## 4. ГОСТ 10706-76 — порядок проверки

### 4.1 Партия (п. 2.1)
Один размер, одна марка, одна группа; один документ по ГОСТ 10692; **не более 100 шт.**

### 4.2 Механические свойства
- Основной металл — **табл. 2** (п. 1.4).
- **Растяжение сварного соединения для групп А и В — обязательно**; σв шва не ниже σв основного металла (п. 1.5).
- Отбор: две трубы (одношовные) / одна (двухшовные) от партии (п. 2.4).

### 4.3 Ударная вязкость
- Группа В — **по требованию потребителя**, нормы — табл. 3 (п. 1.6); для тепловых сетей — Ст3сп4, Ст3сп5 по табл. 3а.
- Три образца основного металла и три — сварного соединения; среднее; на одном допускается снижение на 4,9 Дж/см², **кроме труб для тепловых сетей** (п. 3.6).

### 4.4 Гидроиспытание и НК
- **Каждая труба** (пп. 1.13, 2.3): группа А — по ГОСТ 3845 при 0,5 σв min (по заказу — 0,85 σт); группа В — 0,9 σт min; группы Б и Д — не менее 2,5 МПа (для ряда размеров — 2,0 МПа).
- Выдержка не менее 10 с (п. 3.3).
- НК швов: для тепловых сетей — по всей длине; для группы В — по требованию (п. 1.14). Нормы дефектов — по НД (п. 3.8).

### 4.5 Химсостав (п. 2.5)
По документу изготовителя заготовки; при необходимости — проверка на одной трубе.

### 4.6 Конструкция шва (пп. 1.7–1.12)
Ø до 820 — не более одного продольного и одного поперечного шва; Ø ≥ 820 — два продольных и один поперечный; высота валика — табл. 4; фаска 25–30° (п. 1.10).

## 5. ГОСТ 10704-91 — сортамент и длина
- Размеры — табл. 1; теоретическая масса — **справочная** (п. 2).
- **Длина (п. 3):** немерная — не менее 2 м (Ø до 30), 3 м (св. 30 до 70), 4 м (св. 70 до 152), 5 м (св. 152). Мерная (по требованию, группы А и В по ГОСТ 10705): до 70 — 5–9 м; св. 70 до 219 — 6–9 м; св. 219 до 630 — 10–12 м; по согласованию — до 12 и 18 м. **Трубы Ø св. 630 мм — только немерной длины.**
- Классы точности по длине I и II (п. 3.1), отклонения — табл. 2, п. 3.3.
- Отклонения диаметра — табл. 3 (п. 4), стенки — п. 6.

## 7. Что НЕ является нарушением
- ГОСТ 10705: вид термообработки выбирает изготовитель (п. 2.3).
- ГОСТ 10705: отсутствие σт, если не заказан (п. 3.5).
- ГОСТ 10705: отсутствие загиба, бортования, растяжения сварного соединения, если не заказаны (п. 2.15).
- ГОСТ 10705: отсутствие KCU у труб без термообработки по всему объёму, с S < 6 мм или группы Б (п. 2.12).
- ГОСТ 10705: отсутствие гидроиспытания труб вида I при НК шва по всему периметру; отсутствие гидроиспытания по согласованию (п. 3.3а).
- ГОСТ 10705: смещение кромок до 10 % S; один поперечный шов на трубах Ø ≥ 57 мм (пп. 2.6, 2.7).
- ГОСТ 10706: отсутствие ударной вязкости у группы В, если не заказана (п. 1.6); отсутствие НК швов у группы В, если не заказан и трубы не для тепловых сетей (п. 1.14).
- Химсостав — по документу изготовителя заготовки (п. 3.1 ГОСТ 10705; п. 2.5 ГОСТ 10706).
- Теоретическая масса по табл. 1 ГОСТ 10704 — справочная.
