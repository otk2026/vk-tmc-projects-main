## 1. Область
Сварные прямошовные и спиральношовные трубы Ø 114–1420 мм для магистральных газонефтепроводов, нефтепродуктопроводов, **технологических и промысловых трубопроводов** (вводная часть).

**Типы (п. 1.1):** 1 — прямошовные Ø 114–630 мм, контактная сварка ТВЧ; 2 — спиральношовные Ø 159–1420 мм, электродуговая сварка; 3 — прямошовные Ø 530–1420 мм, электродуговая сварка, один или два продольных шва.
**Классы прочности (п. 1.2):** К34, К38, К42, К48, К50, К52, К54, К55, К56, К60.

## 2. Документ о качестве — обязательный состав (п. 3.1)
Партия сопровождается одним документом о качестве, содержащим:
1. наименование изготовителя и товарный знак;
2. **тип трубы**;
3. номинальные размеры;
4. **класс прочности и марку стали**;
5. номер партии; **номер трубы** — для Ø ≥ 530 мм из низколегированных сталей;
6. результаты механических испытаний **основного металла и сварного соединения**;
7. для низколегированных сталей — номер плавки, химсостав и **эквивалент по углероду** по данным изготовителя металла, обозначение НД на прокат;
8. для углеродистых сталей — номер плавки, химсостав по данным изготовителя металла, обозначение НД на сталь;
9. **эквивалентную фактическую величину гидравлического давления** без учёта осевого подпора;
10. **состояние металла** (термообработка по объёму / по шву / без термообработки);
11. **отметку о проведении неразрушающего контроля**;
12. обозначение ГОСТ 20295.

Отсутствие любого пункта — несоответствие п. 3.1 (для результатов испытаний и гидродавления — неопределённость по существу + несоответствие состава документа).

## 3. Порядок проверки

### Шаг 1. Идентификация
Тип, D × S, класс прочности, марка, партия, количество, НД — сверка с КД / заказом / проектом.

### Шаг 2. Партия (п. 3.1)
Один размер, одна марка стали, один класс прочности, один вид термообработки.

### Шаг 3. Сталь и химсостав (пп. 2.1, 2.2)
- Прокат (горячекатаный, термообработанный или после контролируемой прокатки) из спокойной / полуспокойной углеродистой стали с **C ≤ 0,24 %** или низколегированной с **Сэкв ≤ 0,46 %**; химсостав — по ГОСТ 380, 1050 (углеродистая), ГОСТ 19281 и др. НД (низколегированная).
- Если марка не указана в заказе — выбирает изготовитель с учётом табл. 5, 7, 8 (п. 2.2).
- Термообработка — по табл. 6 (п. 2.4).

### Шаг 4. Механические свойства
- Основной металл — **табл. 7** по классу прочности: σв, σт, δ5 (п. 2.5).
- Сварное соединение — σв не ниже табл. 7 (п. 2.7).
- Объём (п. 3.4): Ø < 530 (типы 1, 2) — две трубы от партии; Ø 530–1420 — две трубы **от каждой плавки** в партии; сварное соединение — две трубы от партии. Для типа 3 с двумя швами — два полуцилиндра от плавки + одна труба от партии.

### Шаг 5. Ударная вязкость
- **Основной металл — для труб Ø ≥ 219 мм и S ≥ 6 мм** (п. 2.6); нормы KCU/KCV и температуры — **табл. 8 с учётом сноски к ней** (п. 2.6.1).
- Сварное соединение Ø 530–1420: тип 3 — ≥ 19,6 Дж/см² при −40 °С; тип 2 — ≥ 29,4 Дж/см² при −40 и −60 °С (при −60 °С — по требованию); тип 1 Ø ≥ 530 — по согласованию ≥ 19,6 при −40 °С (п. 2.8).
- ИПГ (≥ 50 % вязкой составляющей при −5 °С) — для типа 2 Ø ≥ 820 К60 и типа 3 Ø ≥ 720, **по требованию потребителя** (п. 2.6.2).
- Среднее по трём образцам; на одном допускается снижение на 9,8 Дж/см² (п. 4.9).

### Шаг 6. Гидроиспытание и НК
- **Каждая труба** — гидроиспытание (пп. 2.16, 3.3): по ГОСТ 3845 с учётом осевого подпора, допускаемое напряжение 0,95 σт (табл. 7); для Ø ≤ 273 — не более 12 МПа. Выдержка ≥ 10 с (Ø < 530) / ≥ 20 с (Ø ≥ 530) (п. 4.15).
- **Каждый сварной шов** (продольный, спиральный, поперечный, кольцевой) — НК (пп. 2.14, 3.3); нормы — по НД.
- В документе — эквивалентное фактическое давление и отметка о НК (п. 3.1).

### Шаг 7. Швы и поверхность
- Не допускаются трещины, плены, рванины, расслоения, закаты; исправление основного металла сваркой не допускается (пп. 2.9, 2.10).
- Один поперечный шов стыка рулонов и один кольцевой — при условии НК (п. 2.11).
- Ремонт швов типов 2 и 3 — не более 10 % длины соединения (по требованию для типа 3 — 8 %) с НК и повторным гидроиспытанием (п. 2.12).

### Шаг 8. Длина (п. 1.4)
10,6–12,2 м; по согласованию — до 18,0 (тип 1), 13,7 (тип 2), 24,8 м (тип 3); для типов 1, 2 и экспандированных типа 3 — до 10 % по массе длиной не менее 8,0 м.

### Шаг 9. Маркировка (п. 5.1, при ВИК)
На каждой трубе в 100–1500 мм от конца (клеймо или несмываемая краска): изготовитель / товарный знак; марка стали или её обозначение и класс прочности; номер трубы или партии; клеймо ОТК; год изготовления. Для Ø ≥ 530 — дополнительно краской на внутренней поверхности: марка, класс, партия, номер трубы, размеры, фактическая длина.

## 5. Что НЕ является нарушением
- Марка стали, выбранная изготовителем, если не указана в заказе (п. 2.2) — при соблюдении C / Сэкв и класса прочности.
- Отсутствие ИПГ, если не заказано (п. 2.6.2).
- Отсутствие KCU сварного соединения типа 2 при −60 °С, если не заказано (п. 2.8).
- Отсутствие ударной вязкости у труб Ø < 219 мм или S < 6 мм (п. 2.6).
- Трубы, изготовленные стыковкой двух труб, прошедших гидроиспытание, повторно не испытывают (п. 4.15).
- До 10 % труб длиной не менее 8,0 м (п. 1.4).
