# 10 — Типовые несоответствия в документах на трубы

> Это перечень **типовых проблем**, на которые нужно смотреть, а не готовые оценки. Оценка каждого случая («Не соответствует» / «Не подтверждено» / замечание) — строго по файлу 09, раздел «Классификация отсутствующих результатов».

## 1. Документ о качестве
- Нет номера партии, группы поставки / изготовления, даты оформления, номера заказа, заказчика (п. А.1 приложения А ГОСТ 31458-2015).
- Документ 2.1 / 2.2 вместо 3.1 / 3.2; подпись лица, занятого в производстве, или без подписи (разд. 5 ГОСТ 31458).
- Копия посредника без заверения, с изменённым количеством, без реквизитов изготовителя (разд. 6 ГОСТ 31458).
- Одна партия — разные размеры / марки / плавки без разделения данных.
- Для ГОСТ 20295: нет Сэкв, фактического гидродавления, отметки о НК, состояния металла, механических свойств сварного соединения (п. 3.1).

## 2. Идентификация
- Марка записана как «Ст20» вместо «20»; поставлена Ст2пс вместо Ст3сп по ТТ.
- НД на трубу не совпадает с КД (ТУ вместо ГОСТ; лист по ТУ вместо ГОСТ по КД).
- Не указана группа (ГОСТ 8731, 10705, 10706) — объём нормируемых показателей не определён.
- Ссылка на заменённую редакцию (ГОСТ 8731-74 / 8732-78) в сертификате после 01.03.2026.

## 3. Марка стали не предусмотрена НД на трубу
- Сталь 20 по ГОСТ 10706 для групп А, Б, В (п. 1.2: только Ст2, Ст3 и низколегированные с Сэкв ≤ 0,48 %). Для группы Д марка не регламентируется — проверять соответствие КД.
- Марка не из допустимого перечня группы ГОСТ 8731 (п. 5.2) или ГОСТ 10705 (п. 2.2).

## 4. Химический состав
- Нормы (диапазоны) вместо фактического анализа плавки.
- Превышение нормы при записи «соответствует» (пример: P 0,038 % при норме 0,035 %) — проверять с учётом отклонений в готовой продукции (файл 07).
- Нет номера плавки.
- Не рассчитан / не указан Сэкв там, где он нормируется (ГОСТ 20295; низколегированные по ГОСТ 10705, 10706; заказ по ГОСТ 8731).

## 5. Механические свойства и испытания
- Одинаковые результаты у разных партий / плавок — перенос данных.
- Пересчёт из кгс/мм² с коэффициентом 10 вместо 9,80665.
- Нет результатов обязательных для группы испытаний (например, KCU по п. 2.12 ГОСТ 10705 для термообработанных труб S ≥ 6 мм; растяжение сварного соединения по п. 1.5 ГОСТ 10706; ударная вязкость группы Г ГОСТ 8731 — если её нормирует НД на марку). Оценка — «Не подтверждено» с требованием представить протокол (файл 09, «Классификация отсутствующих результатов»).
- Нет результатов сплющивания — проблема **только** там, где испытание обязательно по НД и группе (п. 2.13 ГОСТ 10705) или заказано; оценка — «Не подтверждено».
- Единичное значение ударной вязкости вместо среднего по трём образцам.

## 6. Гидроиспытание и НК
- Нет сведений о гидроиспытании там, где оно обязательно (ГОСТ 3262 без 100 % НК; ГОСТ 10706; ГОСТ 20295; группа Д ГОСТ 8731).
- Нет сведений об НК шва для групп А, Б, В ГОСТ 10705 (п. 3.3а) и для ГОСТ 20295 (п. 2.14).
- «УЗК 100 %» без НД, уровня и норм оценки.

## 7. Длина, масса, маркировка
- Мерная длина при Ø > 630 мм (п. 3 ГОСТ 10704 — только немерная).
- Длина вне диапазона НД (ГОСТ 8732-2025 разд. 6; ГОСТ 20295 п. 1.4).
- Расхождение массы (для ГОСТ 3262 — нормируется, п. 1.4; для остальных — теоретическая масса справочная).
- Маркировка не позволяет связать трубы с сертификатом.
