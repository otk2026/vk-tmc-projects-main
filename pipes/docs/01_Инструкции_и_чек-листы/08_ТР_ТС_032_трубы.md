# 08 — Подтверждение соответствия ТР ТС 032/2013 для труб

> Номера пунктов регламента сверять с приложенным текстом ТР ТС 032/2013.

## 1. Применимость
- **Применимость регламента к трубам определяется по параметрам конкретного проекта** (давление, среда, температура, назначение) — проверь по КД / проекту применения. Если параметры неизвестны — неопределённость: запросить у заказчика / проектировщика, вывод не делать.
- Исключения для газопроводов не распространяются на технологические трубопроводы.
- Если регламент применим — нужен документ о подтверждении соответствия; если не применим — отсутствие документа не несоответствие (укажи в справке основание).

## 2. Что проверять (если применим)

| № | Пункт | Что именно |
|---|---|---|
| 1 | Наличие документа | Приложена копия сертификата / декларации (номер в тексте сертификата качества — не документ) |
| 2 | Форма и схема | Сертификация или декларирование; схема — по регламенту для категории оборудования |
| 3 | Вид документа | Обязательный по ТР ТС, а не добровольный (ст. 21 ФЗ № 184-ФЗ — добровольная сертификация обязательную не заменяет) |
| 4 | Область распространения | Продукция (вид трубы, НД, размеры, давление) совпадает с поставкой |
| 5 | Изготовитель | Совпадает с изготовителем в сертификате качества |
| 6 | Срок действия | На дату изготовления / оформления сертификата качества и на текущую дату |
| 7 | Статус в реестре | Проверяется вручную (ФГИС Росаккредитации / Единый реестр ЕАЭС) — всегда указывать номер |

## 3. Как классифицировать
- Регламент применим, документ не представлен → **неопределённость**: в Акт как требование представить.
- Добровольный сертификат вместо обязательного; документ не распространяется на продукцию / НД; иной изготовитель; истёк срок → **браковочный признак**.
- Корректный документ есть, но в сертификате качества на него нет ссылки → **замечание**.
- Применимость не установлена (нет параметров проекта) → **неопределённость**, вывод не делать.
