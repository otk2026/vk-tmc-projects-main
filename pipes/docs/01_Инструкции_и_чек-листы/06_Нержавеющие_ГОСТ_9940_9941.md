# 06 — Трубы бесшовные из коррозионно-стойких сталей: ГОСТ 9940-81 / ГОСТ 9941-2022

> **Ударная вязкость:** если в КД / ТТ / заявке задано своё требование (вид, температура, норма) — проверять только по нему, нормы этого файла не применять (файл 09, решение от 25.09.2026).
**Чек-лист. Применяется вместе с файлом 01**

> Нормы сверены с текстами ГОСТ 9940-81 (Изм. 1–4) и ГОСТ 9941-2022. Химсостав марок — ГОСТ 5632-2014 (файл 07).

## 1. Область
- **ГОСТ 9940-81** — бесшовные **горячедеформированные** трубы из коррозионно-стойкой стали.
- **ГОСТ 9941-2022** — бесшовные **холоднодеформированные** трубы общего назначения из коррозионно-стойких высоколегированных сталей (разд. 1).

## 2. ГОСТ 9940-81

### 2.1 Марки и химсостав (п. 2.1)
Марки — по табл. 3; химсостав — по ГОСТ 5632; ограничения по диаметру для ряда марок — примечание 1 к табл. 1. Для труб под сварку (указывается в заказе) S ≤ 0,020 %. Трубы термообработанные или без термообработки — по заказу.

### 2.2 Партия (п. 3.1)
Один размер (D × S), одна марка, один вид термообработки; по требованию — одна плавка; **не более 200 шт.**; химсостав — по документу о качестве на трубную заготовку.

### 2.3 Механические свойства (п. 2.2, табл. 3)
- σв и δ — по табл. 3; для D/S ≤ 8 ряда аустенитных марок допускается снижение σв на 19,6 Н/мм² (примечание 1).
- σт — **по требованию потребителя** для 12Х18Н10Т, 12Х18Н12Т, 08Х18Н10Т; норма для 12Х18Н10Т — не менее 216 Н/мм²; для 12Х18Н12Т и 08Х18Н10Т — по согласованию (примечания 2–4).
- Растяжение при 350 °С — по требованию (п. 2.3).
- Две трубы на растяжение от партии (п. 3.3).

### 2.4 Дополнительные испытания — по требованию потребителя
- Сплющивание или раздача (на 10 %) — для аустенитных марок по п. 2.7.
- Стойкость к МКК — для марок по п. 2.8; метод АМ или АМУ по ГОСТ 6032, по согласованию — ПТ по ГОСТ 9.914 (п. 4.11).
- Гидродавление — по ГОСТ 3845 при 40 % σв (п. 2.6); **способность выдерживать давление обеспечивается технологией**; взамен допускается НК каждой трубы по ГОСТ 17410 (п. 4.9.1).
- УЗК — по требованию, размеры искусственного дефекта — по согласованию (п. 2.9).

### 2.5 Длина (пп. 1.2, 1.3)
Немерная 1,5–10 м (по согласованию — более 10 м); в партии немерных — до 15 % труб 0,75–1,5 м; мерная — +15 мм; кратная — минимум 300 мм, припуск 5 мм на рез; ограниченная — ±500 мм.

### 2.6 Размеры и форма
Отклонения — табл. 2 (обычная / высокая точность); кривизна на 1 м — 1,5 / 2 / 4 мм при S до 10 / св. 10 до 20 / св. 20 мм (п. 1.6).

## 3. ГОСТ 9941-2022

### 3.1 Марки и химсостав
Марки — п. 5.1.1; химсостав — по ГОСТ 5632 (п. 6.2.1); по требованию — S ≤ 0,02 %, P ≤ 0,035 %, Cu ≤ 0,30 % (п. 6.2.2). Контроль — 1 от плавки; допускается по документу на трубную заготовку (табл. 6 и сноска).

### 3.2 Состояние (п. 6.1)
Трубы **должны быть термообработаны** (вид и режим — выбирает изготовитель) и **протравлены**; без термообработки — только по требованию заказчика; травление допускается не проводить при термообработке в защитной атмосфере / вакууме или при поставке без термообработки.

### 3.3 Партия (п. 8.1)
Одна марка, один размер, один вид термообработки; по требованию — одна плавка; **не более 300 шт.**

### 3.4 Приёмо-сдаточные испытания (п. 8.2, табл. 6)
- **Основные (обязательные):** химсостав; растяжение при 20 °С термообработанных труб с D/S < 40 — нормы табл. 2 (п. 6.3.1); размеры, длина, прямолинейность, поверхность, отделка концов.
- **Дополнительные (по требованию / согласованию):** растяжение при 350 °С (п. 6.3.3); растяжение для D/S ≥ 40 и для труб без термообработки (пп. 6.3.2, 6.3.4); σт для 08Х18Н10Т, 12Х18Н10Т, 10Х17Н13М2Т, 12Х18Н12Т при D/S < 40 (п. 5.5.2 г, д); МКК (п. 6.4); сплющивание / раздача / загиб (п. 6.5); гидроиспытание (п. 6.8.1); НК (п. 6.8.2).
- Гидроиспытание: по ГОСТ 3845 при 40 % σв min (D/S < 40); изготовитель может **гарантировать без испытаний** (сноска к табл. 6).

### 3.5 Длина (п. 5.3.1)
Немерная 0,6–12,5 м; мерная — от 0,6 м до длины по табл. 1; кратная — с припуском 5 мм, минимум 0,3 м. Отклонение мерной и кратной — по п. 6.6.2.

### 3.6 Документ (п. 8.4)
3.1 или 3.2 по ГОСТ 31458.

## 5. Что НЕ является нарушением
- Отсутствие σт, МКК, сплющивания / раздачи, гидроиспытания, УЗК, растяжения при 350 °С — если не заказаны.
- ГОСТ 9940: гидродавление обеспечивается технологией (п. 2.6); НК взамен гидроиспытания (п. 4.9.1).
- ГОСТ 9941: гарантия гидродавления без испытаний (сноска к табл. 6); вид термообработки выбирает изготовитель (п. 6.1.2); без травления — при условиях п. 6.1.3.
- Химсостав — по документу на трубную заготовку.
- ГОСТ 9940: снижение σв на 19,6 Н/мм² для D/S ≤ 8 у марок по примечанию 1 к табл. 3.
