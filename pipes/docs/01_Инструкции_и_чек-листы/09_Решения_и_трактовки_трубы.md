# 09 — Принятые решения и трактовки (трубы)

> Имеют приоритет над общими рассуждениями и общими формулировками чек-листов 01–08. Дополнять после каждой нетиповой проверки: «Ситуация → Решение → Основание → Где возникло».

## Общие
- **Ударная вязкость — сначала требование КД / ТТ заказчика / заявки** (решение от 25.09.2026):
  - Если в КД, ТТ заказчика, заявке или условном обозначении по КД задано требование к ударной вязкости (вид KCU или KCV, температура испытания, норма; например «KCV(-40) > 29,5 Дж/см²»), проверять **только по этому требованию**: есть ли результат именно этого вида при этой температуре и выполняется ли эта норма. Ударную вязкость других видов и температур по общему правилу ГОСТ не требовать и в Акт не выносить — ни как несоответствие, ни как неопределённость.
  - Результат другого вида или при другой температуре (например, KCU при −60 °С вместо KCV при −40 °С) требование не подтверждает: «Не подтверждено», в Акт как требование представить результат по КД. Пересчёт KCU ↔ KCV не допускается.
  - Если требования к ударной вязкости в КД / ТТ / заявке нет — проверять по общему правилу стандарта (чек-лист вида продукции).
  - В справке указывать источник требования: «по КД …» или «по ГОСТ …».
- **Ру без единиц (например, «Ру16», «Ру40», «PN16») — это кгс/см²**: Ру16 = 16 кгс/см² = 1,6 МПа. Правило действует для всей номенклатуры. Двойную трактовку не показывать и в Акт не выносить; при записи Ру в МПа по НД (например, в обозначении по АТК) — пересчитать и указать, что Ру в документе без единиц (замечание, только в справку). (Решение от 24.09.2026.)
- Объём проверки — строго номенклатура из задания.
- Нормы берутся только из приложенных текстов стандартов.
- Испытания, которые НД проводит «по требованию заказчика» / «по согласованию», требуются только если они есть в заказе, КД или ТТ. Их отсутствие в сертификате без такого требования — не несоответствие.
- Документ о качестве на трубы — 3.1 или 3.2 по ГОСТ 31458 (п. 4.3 ГОСТ 10692-2015); минимальный состав сведений — п. А.1 приложения А ГОСТ 31458-2015.
- Документ посредника: оригинал без изменений или заверенная копия; при изменении характеристик (порезка) — новый документ посредника (разд. 6 ГОСТ 31458).

## Классификация отсутствующих результатов
- Результат **обязательного** испытания в сертификате отсутствует → «Не подтверждено» (неопределённость): в Акт — требование представить протокол / сведения, без вывода «не соответствует» по существу.
- Если НД на трубу **прямо устанавливает состав документа** (например, п. 3.1 ГОСТ 20295-85) и сведения отсутствуют → несоответствие документа (браковочный признак по составу документа) + «Не подтверждено» по существу показателя. Обе оценки указываются раздельно.
- «Не соответствует» — только при наличии фактического значения, выходящего за норму.
- **Прямая запись в документе о том, что обязательное испытание / контроль не проводились** («гидроиспытание не проводилось», «НК не проводился», «не испытывались») при отсутствии основания для освобождения (НД, заказ, согласование) → «Не соответствует»: это зафиксированный факт невыполнения обязательного требования, а не отсутствие данных. Если основание для освобождения может существовать (например, согласование по п. 3.3а ГОСТ 10705), но не приложено → «Не подтверждено» с требованием представить основание.

## НД на трубы
- ГОСТ 8732 — только сортамент (разд. 1 ГОСТ 8732-2025, с 01.03.2026 взамен ГОСТ 8732-78); технические требования — по ГОСТ 8731-2025 (с 01.03.2026 взамен ГОСТ 8731-74).
- ГОСТ 8731-2025: ударная вязкость группы В — только по требованию (п. 6.3.3); гидроиспытание групп А и В — только по требованию, допускается гарантия изготовителя (п. 6.8.1).
- ГОСТ 8731-2025, группа Г: ударная вязкость требуется, если НД на марку её нормирует (п. 6.3.4 «если применимо»). Для стали 20 по ГОСТ 1050-2013 нормы KCU нет (табл. 11 — только марки 25–50, 25Г–50Г) → требование не применяется.
- ГОСТ 10706-76: для группы Д марка стали не регламентируется (п. 1.2) — сталь 20 в группе Д формально не нарушение, но свойства не гарантированы; если КД требует сталь 20 для Ø 530 — НД на трубы должна быть ГОСТ 10705.
- ГОСТ 10705-80, п. 3.3а: различать НК по периметру всей трубы (гидроиспытание вида I можно не проводить) и НК только шва (нужно дополнительное гидроиспытание 15 % труб или согласование). Абзацы 8–10 п. 3.3а по поправке ИУС № 5-2005 подлежат удалению — сверять с официальным изданием.
- ГОСТ 10704-91: мерная длина при Ø св. 630 мм — несоответствие обозначения / документа; если фактическая длина укладывается в требования к немерной длине (п. 3), брака самих труб нет — указывать это в справке.
- ГОСТ 10706-76 (Ø 478–1420 мм): для групп А, Б, В сталь 20 не предусмотрена (п. 1.2).
- ГОСТ 10704-91: трубы Ø св. 630 мм — только немерной длины (п. 3).
- ГОСТ 3262-75: для труб общего назначения химсостав и механические свойства не нормируются (п. 2.1).
- ГОСТ 10705-80: загиб, бортование, растяжение сварного соединения — только по требованию заказчика (п. 2.15, Изм. № 8).

## Химсостав
- **Вид анализа в сертификате (ковшевая проба / готовая продукция) не указан** — не замечание и не требование в Акт; уточнять вид анализа у поставщика не нужно. Главное — фактический химсостав соответствует НД. Сравнивать с нормой марки (например, табл. 1 ГОСТ 1050-2013). Допускаемые отклонения для готовой продукции (п. 5.2, табл. 3 ГОСТ 1050; п. 4.8, табл. 2 ГОСТ 380; п. 5.1.2, табл. 8 ГОСТ 19281) применять **только если в сертификате прямо указано, что это анализ готовой продукции**. Значение выше нормы марки без такой пометки — «Не соответствует», в Акт. (Решение от 26.09.2026.)
- **Азот (N) для сталей по ГОСТ 1050-2013 (в т. ч. сталь 20)** — нормируется обязательно (п. 5.1.1): не более 0,006 / 0,008 % (кислородно-конвертерная без внепечной обработки), 0,010 % (с внепечной обработкой), 0,012 % (электропечь). **Не нормируется**, только если в документе о качестве указано: Al общий ≥ 0,020 % или кислоторастворимый ≥ 0,015 %, либо азотосвязывающие элементы (п. 5.1.1 — их содержание должно быть указано в документе). Оценка (решение от 26.09.2026):
  - N не указан и нет ни Al, ни азотосвязывающих элементов → **«Не подтверждено», в Акт** как требование представить содержание N (или Al / азотосвязывающих элементов) и способ выплавки.
  - N указан, способ выплавки не указан: N ≤ 0,006 % (для листа и ленты) / ≤ 0,008 % (прочая продукция) — «Соответствует» при любом способе; N выше этого, но ≤ 0,012 % — «Не подтверждено», в Акт как требование указать способ выплавки (п. 8.1.1 ГОСТ 1050 обязывает указывать его в документе о качестве); N > 0,012 % — «Не соответствует».
  - N выше предела для указанного способа выплавки → «Не соответствует», в Акт.
  - Для сталей по ГОСТ 380 правило другое: N допускается не определять при гарантии изготовителя (п. 5.3 ГОСТ 380).
- Отклонения химсостава в готовой продукции допускаются по п. 4.8 и табл. 2 ГОСТ 380-2005 и п. 5.2 и табл. 3 ГОСТ 1050-2013 — только если в сертификате указано, что это анализ готовой продукции (решение от 26.09.2026) (для ГОСТ 19281 — п. 5.1.2, табл. 8; для ГОСТ 5632 — п. 6.2, табл. 2). П. 4.2 ГОСТ 380 и пп. 5.1.5–5.1.6 ГОСТ 1050 — другое: снижение нижнего предела отдельных элементов при обеспечении механических свойств.
- ГОСТ 380: Cr, Ni, Cu, As, N допускается не определять при гарантии изготовителя (п. 5.3).

## Трубы по ТУ вместо ГОСТ
- Проверка ведётся по КД. Расхождение (ТУ вместо ГОСТ по КД) остаётся несоответствием, пока не оформлено решение (изменение КД или протокол применения). Довод о достаточной ударной вязкости — основание для такого решения, но не замена НД. (Случай ВМЗ.)

## ТР ТС 032/2013
- Применимость к трубам определяется по параметрам конкретного проекта.
- Исключения для газопроводов не касаются технологических трубопроводов.
- Ссылаться на ТР ТС 032 как на основание требования прослеживаемости некорректно.

## Открытые вопросы (требуют решения)
- **Трубы, изготовленные по ГОСТ 8731-74 / 8732-78 (до 01.03.2026):** проверять по редакции, указанной в сертификате; текстов старых редакций в базе нет. До решения — нормы по ним помечать как справочные, вывод о несоответствии по изменившимся пунктам не делать.
- **Сертификат с датой после 01.03.2026 со ссылкой на ГОСТ 8731-74 / 8732-78:** замечание или требование переоформить? До решения — выносить в справку как вопрос.
