# 04 — Трубы стальные водогазопроводные (ВГП): ГОСТ 3262-75

> **Ударная вязкость:** если в КД / ТТ / заявке задано своё требование (вид, температура, норма) — проверять только по нему, нормы этого файла не применять (файл 09, решение от 25.09.2026).
**Чек-лист. Применяется вместе с файлом 01**

> Нормы сверены с текстом ГОСТ 3262-75 (Изм. 1–6).

## 1. Назначение и обозначение
- Трубы обычной точности — для водопроводов, газопроводов и систем отопления; повышенной точности — для деталей водопроводных и газопроводных конструкций (примечание 2 к табл. 3).
- Серии: лёгкие, обыкновенные, усиленные (табл. 1); под накатку резьбы — табл. 2.
- Обозначение: Ду × S; буквы: Ц — оцинкованная, Р — с резьбой, М — с муфтой, Н — под накатку, Д — длинная резьба, П — повышенная точность (после Ду); длина — для мерных (примеры к п. 1.7).

## 2. Порядок проверки

### Шаг 1. Идентификация
Ду × S, серия (лёгкая / обыкновенная / усиленная), точность, покрытие (Ц), резьба, длина — сверка с КД и заказом. Трубы для деталей водо- и газопроводных конструкций — отдельная категория с дополнительными требованиями (пп. 2.1, 2.10, 3.1).

### Шаг 2. Марка стали и химсостав (п. 2.1)
- Трубы общего назначения — из сталей по ГОСТ 380 и ГОСТ 1050 **без нормирования механических свойств и химического состава**.
- Трубы для деталей водопроводных и газопроводных конструкций — **из стали по ГОСТ 1050**; химсостав и механические свойства — по документу о качестве изготовителя заготовки (п. 3.1).

### Шаг 3. Партия (п. 3.1)
Один размер, одна марка стали; один документ о качестве по ГОСТ 10692; **масса партии не более 60 т**.

### Шаг 4. Механические свойства
- По требованию потребителя — для труб деталей водо- и газопроводных конструкций по ГОСТ 1050 (п. 2.10).
- Испытания — не более 1 %, но не менее двух труб от партии (п. 3.3); допускается НК механических свойств вместо растяжения (п. 4.1).

### Шаг 5. Технологические испытания (п. 2.9)
- **Загиб — обязателен**: Ду до 40 мм — оправка радиусом 2,5 D; Ду 50 мм — 3,5 D.
- **Раздача** — по требованию: Ду 15–50 — не менее 7 %; Ду ≥ 65 — не менее 4 %.
- **Сплющивание** — по требованию: до 2/3 D.

### Шаг 6. Гидроиспытание и НК
- Давление (п. 2.8): **2,4 МПа** — обыкновенные и лёгкие; **3,1 МПа** — усиленные; **4,9 МПа** — по требованию.
- **Каждая труба** (п. 3.5), выдержка не менее 5 с (п. 4.3).
- При **100 % НК сварного шва** гидроиспытание допускается не проводить — способность выдерживать давление гарантируется (п. 3.5).
- НК сварных швов — по требованию потребителя (п. 2.16).

### Шаг 7. Размеры, масса, длина
- Отклонения: наружный диаметр — табл. 3 (Ду до 40: +0,4 мм обычной / ±0,4 повышенной точности; св. 40: +0,8 % / ±0,8 %); толщина стенки — −15 % обычной / −10 % повышенной точности (п. 1.3).
- Масса: **+8 %**; по требованию — +7,5 % на партию, +10 % на трубу (п. 1.4); контроль массы — все трубы (п. 3.4).
- Кривизна на 1 м: 2 мм (Ду до 20), 1,5 мм (Ду св. 20) (п. 1.5).
- Длина: **4–12 м**, мерная / кратная (припуск 5 мм на рез, +10 мм на всю длину) или немерная; по согласованию — до 5 % труб 1,5–4 м в партии немерных (п. 1.2).

### Шаг 8. Покрытие и резьба (для оцинкованных / резьбовых)
- Цинковое покрытие — сплошное, не менее **30 мкм** (п. 2.7); контроль — две трубы от партии (п. 3.6).
- Резьба — по ГОСТ 6357, класс В (п. 2.11); защищена смазкой (п. 5.1.1).

### Шаг 9. Документ и маркировка
Документ о качестве — по ГОСТ 10692 (п. 3.1); маркировка — по ГОСТ 10692 (п. 5.1).

## 4. Что НЕ является нарушением
- **Отсутствие химсостава и механических свойств** для труб общего назначения (п. 2.1).
- Отсутствие гидроиспытания при 100 % НК сварного шва (п. 3.5).
- Отсутствие раздачи, сплющивания, НК шва, если не заказаны (пп. 2.9, 2.16).
- Взамен растяжения — контроль механических свойств неразрушающими методами (п. 4.1).
- До 5 % труб 1,5–4 м в партии немерных — при согласовании (п. 1.2).
