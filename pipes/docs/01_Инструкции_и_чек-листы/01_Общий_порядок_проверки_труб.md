# 01 — Общий порядок проверки документов о качестве на трубы
**Применяется ко всем трубам вместе с чек-листом по НД на трубу (02–06)**

> Нормы сверены с текстами ГОСТ 10692-2015 (Изм. № 1) и ГОСТ 31458-2015 (Изм. № 1). Перед применением сверять с приложенным текстом.

## 1. Какие документы нужны для проверки
| Документ | Зачем |
|---|---|
| Сертификат (документ о качестве) на каждую партию | Основной объект проверки |
| Заказ / спецификация / договор | Определяет требования «по требованию заказчика»: группу, дополнительные испытания, длину, гидродавление |
| КД (чертёж, карта входного контроля) | НД на трубу, марка стали, группа — эталон для идентификации |
| ТТ заказчика | Дополнительные требования |
| Сертификат / декларация ТР ТС 032/2013 (если применимо) | Подтверждение соответствия — файл 08 |
| Текст НД на трубы (с годом редакции) | Первоисточник норм |

Без заказа и КД нельзя оценить требования, которые НД устанавливает «по требованию заказчика», — такие пункты оцениваются как «Не подтверждено (требуется заказ/КД)».

## 2. Определение НД, группы и марки (до всех проверок)
Для каждой позиции зафиксируй в справке:
- **НД на трубу**: ТУ + сортамент, с годом редакции (например, ГОСТ 8731-2025 / ГОСТ 8732-2025; ГОСТ 10705-80 / ГОСТ 10704-91);
- **группу**: поставки (ГОСТ 8731 — А, Б, В, Г, Д), изготовления (ГОСТ 10705 — А, Б, В, Д; ГОСТ 10706 — А, Б, В, Д), тип и класс прочности (ГОСТ 20295), вид по гидродавлению (ГОСТ 10705 — I, II);
- **марку стали** и НД на сталь;
- **размер** (D × S), вид длины, точность изготовления (если указана).

Эти параметры определяют, какие показатели обязательны. Группа не указана → идентификация неполная, объём обязательных испытаний не определён (неопределённость).

## 3. Идентификация (блокирующий шаг)
Сверь сертификат с поставкой, заказом и КД по всем признакам сразу: НД (с годом), D × S, марка стали, группа / класс прочности, номер партии, количество (шт., м, т), получатель / заказчик. Расхождение по одному признаку — повод проверить остальные. Сертификат на другую продукцию означает, что документа о качестве на поставку фактически нет.

## 4. Документ о качестве

### 4.1 Вид документа
- На принятую партию оформляют документ о приёмочном контроле **3.1 или 3.2** по ГОСТ 31458 (п. 4.3 ГОСТ 10692-2015; п. 8.3 ГОСТ 8731-2025; п. 8.4 ГОСТ 9941-2022).
- **3.1** — результаты специального контроля, подпись уполномоченного представителя изготовителя, **не занятого в производственном процессе** (п. 5.2 ГОСТ 31458-2015).
- **3.2** — то же + подпись представителя органов надзора и/или инспектирующей организации (п. 5.2).
- **2.1 / 2.2** — документы неспециального контроля (разд. 4 ГОСТ 31458); 2.1 не содержит результатов испытаний. Если НД требует 3.1/3.2, документ 2.1/2.2 требованиям не соответствует.
- Допускается один документ на несколько партий, отгружаемых одному заказчику в одном транспортном средстве, если в нём есть данные о каждой партии (п. 4.3 ГОСТ 10692-2015).

### 4.2 Минимальный перечень сведений (п. А.1 приложения А ГОСТ 31458-2015)
- товарный знак и/или наименование изготовителя;
- наименование заказчика;
- номер заказа;
- обозначение нормативной документации;
- размер труб;
- марка стали (если применимо);
- класс (группа) прочности (если применимо);
- номер партии и/или плавки;
- количество труб;
- результаты контроля и испытаний (если применимо);
- дата оформления документа.

Для ГОСТ 20295-85 — расширенный состав по п. 3.1 (см. файл 05).
Для труб, у которых химсостав принимается по документу изготовителя заготовки (ГОСТ 3262, 10705, 10706, 9940 и др.), в сертификате должны быть номер плавки и её фактический химический состав.

### 4.3 Оригинал и копии (разд. 6 ГОСТ 31458-2015)
- Изготовитель предоставляет **оригинал** документа (п. 6.1).
- Посредник (заказчик, не являющийся потребителем) передаёт оригинал **без изменений** либо **заверенную копию** (п. 6.2).
- Копия на часть поставки — с указанием **фактического количества** поставляемой продукции (п. 6.3).
- Если посредник изменил характеристики продукции (например, порезал трубы), он оформляет **новый** документ о приёмочном контроле (п. 6.3).
- К документу могут прилагаться документы об идентификации и прослеживаемости, результаты контроля, документы на заготовку (п. 6.1).

## 5. Партия
Правила комплектования и максимальный размер партии — по НД на трубу (таблица в каждом чек-листе 02–06). Проверь: один размер, одна марка, один вид термообработки, одна группа (если требует НД), номер партии указан. Разные партии без разделения данных в одном документе — несоответствие (кроме случая п. 4.3 ГОСТ 10692).

## 6. Повторные испытания
Если в сертификате отражены повторные испытания — проверь, что они проведены на удвоенной выборке и результаты распространяются на партию по правилам НД на трубу или п. 4.2 ГОСТ 10692-2015.

## 7. Маркировка (при ВИК)
- **ГОСТ 10692-2015, п. 5.2.1:** маркировка на поверхности каждой трубы наружным диаметром более 159 мм; остальные — на ярлыке к каждому пакету или бунту (допускается маркировка и на поверхности).
- **Содержание маркировки на поверхности (п. 5.2.4):** товарный знак и/или изготовитель; размеры; марка стали и/или класс (группа) прочности.
- **Содержание ярлыка (п. 5.2.5):** товарный знак и/или изготовитель; обозначение документа на трубы; размеры; марка стали и/или класс прочности; **дата приёмки**.
- Маркировка должна позволять связать трубы с сертификатом (партия/плавка). ГОСТ 20295 — собственные требования (п. 5.1, файл 05).

## 8. Проверка происхождения данных (обязательный раздел)

Наличие цифры в сертификате не равнозначно её подтверждению. Отвечай на вопрос: откуда взято каждое значение.

| Признак | Как трактовать |
|---|---|
| Химсостав дан диапазоном («C 0,17–0,24») или совпадает с нормами марки | Это нормы, а не фактический анализ. Химсостав не подтверждён |
| Одинаковые значения механических свойств у разных партий или плавок | Признак переноса данных. Требуй протоколы испытаний по каждой партии |
| Значения точно равны нормативному минимуму при высоких остальных показателях | Возможна подстановка норм вместо результатов. Уточнить у изготовителя |
| Результаты по показателю, который для данной группы не определяют (например, механические свойства для группы Б ГОСТ 8731) | Уточнить происхождение; сами по себе не нарушение |
| Единичное значение ударной вязкости там, где НД требует среднее по трём образцам | Не соответствует методу; проверить допускаемое снижение на одном образце по НД |
| Значения в кгс/мм² или пересчитаны с коэффициентом 10 | Пересчитать по 9,80665; браковочный признак — только если после корректного пересчёта ниже нормы |
| Документ посредника с изменённым количеством / без реквизитов изготовителя / без подписи | Нарушение разд. 6 ГОСТ 31458; требовать оригинал или заверенную копию |
| Формулировки «гарантируется», «соответствует ГОСТ» без значений там, где НД требует результат | Не подтверждение. Исключение — где НД прямо допускает гарантию изготовителя (см. «Что НЕ является нарушением» в чек-листах) |
| НК: «УЗК 100 %, годен» без метода, НД и норм оценки | Не подтверждение — требовать НД, уровень (настроечный отражатель), реквизиты протокола |
