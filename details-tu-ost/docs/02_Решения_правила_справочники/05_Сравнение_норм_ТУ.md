# 05 — Сравнение норм ТУ (шпаргалка, чтобы не перепутать)

> Справочный файл. При расхождении главнее чек-лист конкретных ТУ (01–04) и файл 10.

## Детали по ОСТ 34 10.7xx-97 (трубопроводы ТЭС) — чем отличаются от ТУ

- Чек-лист — файл 11. Область: Рраб ≤ 2,2 МПа, t ≤ 425 °С (ТЭС); тепловые сети — до 2,5 МПа, 200 °С. Давление в обозначении — **условное Ру** (0,4–4,0 МПа), а не рабочее.
- Обозначение — по **номеру в таблице ОСТ** (тройник 059, переход 27), а не по классу прочности / категории / m, как в ТУ.
- Собственных норм химсостава, механики, KCU и состава паспорта ОСТ не устанавливают: материал — по разделу ОСТ 34 10.747 (лист / трубы), нормы — по НД полуфабриката, гидроиспытание и ТО — по ТУ изготовителя (ОСТ 34 10.766).
- Марки: сталь 20, 20К, Ст3сп5 / Ст3Гпс4 (ограниченно), 17ГС, 17Г1С, 16ГС, 09Г2С, 10Г2С1 — не путать с классами прочности К… из ТУ.

## Трубы — ТУ 14-3Р-1128-2007 (файл 04)
- Марки 10, 20, 10Г2А, 09Г2С; классы К42, К48 (D 245–426).
- Cэ ≤ 0,43 (формула 1 для 10, 20; формула 2 для остальных).
- KCU / KCV — по заказу, нормы табл. 5; К42 / К48 — 49 / 40 Дж/см².
- Гидроиспытание **каждой трубы** (95 % σт, 20 с); D < 219 — замена НК с гарантией.
- НК каждой трубы по ГОСТ Р ИСО 10893.
