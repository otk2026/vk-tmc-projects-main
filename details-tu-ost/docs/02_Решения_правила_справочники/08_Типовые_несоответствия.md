# 08 — Типовые несоответствия (детали и трубы по ТУ)

## 1. Общие для всех ТУ
- Паспорт ссылается на ГОСТ 17380 вместо ТУ; нормы проверены по ГОСТ 17380 (KCU ≥ 39 / KCV ≥ 34, табл. 7, ψ) — ошибка НД / проверки.
- Обозначение неполное: нет класса прочности, давления, коэффициента m / категории, исполнения.
- Химсостав «соответствует» по марочной норме ГОСТ, хотя превышает норму ТУ (S, P, N).
- Приведена только KCU или только KCV, хотя ТУ требуют оба показателя; не указаны температура испытаний и тип образцов.
- Температура испытаний KCU / KCV не соответствует исполнению (У / УХЛ / ХЛ) или температуре в обозначении.
- Нет сведений о материале: № сертификата, плавка, НД на трубу / лист.
- Механика совпадает с сертификатом на трубу / лист (два и более показателя) — признак переписывания (файл 07).
- σт/σв выше допустимого для класса / вида стали и ТО.
- Нет записи о НК сварных швов или о гидроиспытании (гарантированном давлении).
- Нет углеродного эквивалента или он превышает предел ТУ; CE не совпадает с пересчётом по химсоставу.
- Один паспорт на партию, где ТУ требуют паспорт на каждую деталь (DN ≥ 500 / DN ≥ 200).

## 2. ТУ 1469-016-01395041-2008 (файл 01)
- Заготовка — спиральношовная или ТВЧ-труба (запрещено п. 1.2.2).
- S > 0,011 %, P > 0,020 %, N > 0,012 % (с доп. отклонениями, п. 1.2.10); V+Nb+Ti > 0,16 %.
- CE(IIW) > 0,45 или Pcm > 0,25.
- σв выше нормы более чем на 130 Н/мм²; σт/σв > 0,85 (К42, К48) / 0,90 (К52–К65); HV10 > 260 / 280.
- Нет KCU / KCV сварного соединения у сварных деталей.
- Сварная / холодноштампованная деталь «без термообработки».
- Лист без сплошности по классу 1 (11,8 МПа) / 2 (до 9,8 МПа).

## 3. ТУ 1469-006-82932963-2018 (файл 02)
- Нет водорода в документе о качестве (п. 9.2, примечание 1 к табл. 4).
- Нет номинальных D и S присоединяемых труб (п. 9.2).
- Нет отметки о гидроиспытании или гарантии.
- σт К52 сравнен с 320 вместо 353 (Изм. № 1).
- Класс изделия ниже класса присоединяемых труб (п. 4.2.1).
- Механика не от партии (табл. 21 — от каждой партии).

## 4. ТУ 102-488-05 (файл 03)
- Трубы с бором или с нормативным σв > 589 МПа как материал (п. 1.13.3).
- ТШ не из стали 20 / 09Г2С или не из труб ГОСТ 8731 гр. В / ТУ 14-3Р-55 / ТУ 14-3-1128 (п. 1.13.2).
- CE > 0,43.
- Отвод ОСС на давление выше 4,0 МПа или для нефтепровода.
- Нет KCV у деталей DN ≥ 500.
- Нет гарантированного пробного давления в паспорте.

## 5. Трубы ТУ 14-3Р-1128-2007 (файл 04)
- Нет температуры испытаний и типа образцов KCU / KCV в сертификате (п. 3.5).
- Cэ > 0,43 или не указан; формула не та (сталь 10, 20 — C + Mn/6).
- 09Г2С: σв выше нормы более чем на 118 Н/мм²; К42 / К48 — σв вне диапазона, σт/σв или HV10 выше нормы.
- Нет записи о гидроиспытании с давлением (или о замене НК с гарантией для D < 219).
- Нет записи о макроструктуре, НК (метод), намагниченности.
- Длина менее 7,0 м или более 10 % труб 7,0–8,0 м; трубы К42 / К48 D < 245 мм.
- Нет номеров труб (D > 168 мм), общей массы, длины, количества (п. 3.5, Изм. № 1).
- Сертификат по старой редакции без Изм. № 1 (сравнить нормы KCV для стали 20 и длины труб).
