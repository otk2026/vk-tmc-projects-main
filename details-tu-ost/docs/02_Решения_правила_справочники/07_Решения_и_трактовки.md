# 07 — Принятые решения и трактовки (проект «ВК — Детали по ТУ и ОСТ»)

> Имеют приоритет над общими рассуждениями и над общими формулировками чек-листов 01–06. Дополнять после каждой нетиповой проверки: «Ситуация → Решение → Основание → Дата».
> Общие решения перенесены из проекта «Входной контроль ТМЦ» (ныне «ВК ТМЦ ➤ Фитинги и Фланцы», папка `fittings-flanges`) (решения ОТК от 24.09–29.09.2026) и действуют здесь так же.

## Общие
- **Нормы — только из приложенных ТУ**, с учётом изменений (ТУ 1469-006 — Изм. № 1; ТУ 14-3Р-1128 — Изм. № 1). **Нормы ГОСТ 17380 к деталям по ТУ не применять**; ссылка в паспорте на ГОСТ 17380 вместо ТУ — несоответствие НД.
- **Объём проверки** — строго номенклатура из задания; остальные позиции документа не проверяются, но перечисляются в справке как не входившие в объём.
- **Идентификация изделия блокирует дальнейшую проверку.** Изделие по другим ТУ (или по другой части ТУ, текста которой нет) — сообщить, проверку не подгонять.
- **Ударная вязкость — сначала требование КД / ТТ заказчика / заявки** (решение от 25.09.2026):
  - Если в КД, ТТ, заявке или обозначении задано требование (вид KCU / KCV, температура, норма) — проверять **только его**; другие виды и температуры по ТУ не требовать и в Акт не выносить.
  - Результат другого вида или при другой температуре требование не подтверждает: «Не подтверждено», в Акт. Пересчёт KCU ↔ KCV не допускается.
  - Требования в КД нет — по ТУ (чек-листы 01–04).
  - В справке указывать источник требования: «по КД …» или «по ТУ …».
- **Ру без единиц (Ру16, PN16) = кгс/см²**: Ру16 = 1,6 МПа. Двойную трактовку не показывать. (Решение от 24.09.2026.)
- **Требование КД (ТТ, заявки)** — всегда **отдельная строка Акта**.
- **Одна причина — одна строка Акта**; отдельная строка — только при другом основании (файл 09).
- **Показатель, для которого в ТУ нет нормы при этом виде / температуре** — принимается как данные, с нормой не сравнивается: «Не оценивается», в Акт не идёт.
- **Подпись в паспорте контролёра / мастера ОТК вместо начальника ОТК** — замечание, только в справку («Подлежит исправлению (не браковочный признак)»), если КД / договор не требуют иного. Формы паспортов в ТУ — рекомендуемые. (Решение от 25.09.2026.)
- **Формы паспортов во всех трёх ТУ на детали — рекомендуемые**: отличие оформления не нарушение; отсутствие сведений, которые требуют ТУ, — неопределённость, в Акт.

## Происхождение данных (решения от 28.09.2026, адаптированы к ТУ)
- **Общий принцип.** Значения в документе о качестве на изделие считаются **подтверждёнными без протоколов испытаний**, если нет признаков переписывания. Значения сравниваются с нормой ТУ; вне нормы — «Не соответствует», отдельная строка Акта.
- **Признак переписывания механических свойств** (σт, σв, δ, KCU, KCV, твёрдость) — хотя бы одно:
  - **два и более** показателя совпадают цифра в цифру с сертификатом на трубу / лист (передельный материал);
  - **один** совпадает, и состояние металла разное (материал без термообработки, изделие после ТО).
  При признаке → «Не подтверждено», в Акт требование протоколов испытаний деталей.
- **Результаты периодических / типовых испытаний в паспорте** — **не нарушение и не признак переписывания** там, где ТУ это прямо допускают: ТУ 1469-016 (п. 2.5, 1.14.3), ТУ 102-488-05 (п. 2.4, 4.3) — механика определяется при периодических испытаниях с распространением на детали того же наименования, марки и толщины. Для ТУ 1469-006 механика — **от каждой партии** (табл. 21); для деталей DN 50–450 по ТУ 1469-016 и ТШ / ДШ DN 500 по ТУ 102-488-05 — **от каждой партии**.
- **Химсостав, CE, водород в паспорте совпадают с сертификатом на передельный материал / трубную заготовку** — **не признак переписывания**: так предписано ТУ (ТУ 1469-006 п. 9.2, табл. 21; ТУ 14-3Р-1128 примечание к табл. 6, п. 3.7). Проверяется совпадение плавки и соответствие нормам ТУ.

## Химсостав
- **Нормы химсостава — по ТУ**, если ТУ их устанавливают (ТУ 1469-016 п. 1.2.10; ТУ 1469-006 табл. 4; ТУ 14-3Р-1128 табл. 3 / 3а). Они строже марочных ГОСТ — сравнивать с ТУ.
- **Вид анализа не указан** (ковшевая / готовая продукция) — не замечание и не требование. Сравнивать с нормой ТУ / марки; допускаемые отклонения (ТУ 1469-016 «+…»; ТУ 1469-006 табл. 5; ТУ 14-3Р-1128 табл. 3б и п. 2.4.2) применять **только к анализу в материале / изделии / трубе**, если это указано. Для ТУ 1469-016 доп. отклонения записаны прямо в норме («0,010 ⁺⁰·⁰⁰¹») — применять всегда. (Решение от 26.09.2026, адаптировано.)
- **Азот**: если ТУ нормируют N (1469-016, 1469-006 для ряда марок, 14-3Р-1128) — N в документе обязателен; нет N → «Не подтверждено», в Акт. Для марок, где ТУ N не нормируют, — по правилу ГОСТ 1050 (решение от 26.09.2026): нет ни N, ни Al / азотосвязывающих элементов → «Не подтверждено».

## ТУ 1469-016-01395041-2008 (файл 01)

- Гидроиспытание — типовое (п. 2.6.2); в паспорте — гарантируемое давление. Протокол на каждую деталь не требовать.
