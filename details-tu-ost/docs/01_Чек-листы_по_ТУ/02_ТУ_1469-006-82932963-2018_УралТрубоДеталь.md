# 02 — Детали соединительные и узлы по ТУ 1469-006-82932963-2018 (ООО «УралТрубоДеталь»)
**Чек-лист входного контроля документов о качестве на детали магистральных и промысловых трубопроводов на Рр до 10 МПа**

> Составлен по тексту ТУ 1469-006-82932963-2018 «Детали соединительные и узлы для магистральных и промысловых трубопроводов на Рр до 10 МПа (100,0 кгс/см²). Технические условия», третье издание, держатель — ООО «УралТрубоДеталь», с **Изменением № 1** (извещение № 57/18 от 25.10.2018).
> Файл в базе — **скан с плохим текстовым слоем**. Цифры, знаки и таблицы — только по скану страницы («по скану стр. N»). Ключевые таблицы сверены — файл 10.
> Номер листа ТУ = номер страницы PDF.
> Роль, классификация и оформление — по Инструкциям проекта и файлам 07, 09. Решения файла 07 имеют приоритет. **Нормы ГОСТ 17380 к этим деталям не применять.**

## 1. Область (разд. 1, п. 4.1)
- Детали: **отводы секционные (ОСС)**, в т. ч. вальцованные; **тройники штампосварные (ТШС), с решётками (ТШСР / ТСР), сварные (ТС), сварные с усиливающими накладками (ТСН, ТСНР)**; **тройники штампованные (ТШ, ТШСР) DN 50–400**; **переходы штампосварные концентрические (ПШСК) и эксцентрические (ПШСЭ)**; **днища штампованные эллиптические (ДШ)**; **узлы трубопроводов** DN 200–1400; **детали с переходными кольцами (…-КП)**; **кольца переходные (КП)** (табл. 1).
- Основные детали — DN 500–1400 (тройники штампованные — DN 50–400).
- Среда: нефть, нефтепродукты, газ, пресная и подтоварная вода; рабочее давление **до 10 МПа**. Ряд давлений (п. 4.1.2): 1,6; 2,5; 4,0; 5,6; 6,3; 6,4; 7,5; 8,0; 8,5; 10,0 МПа.
- Исполнения (п. 4.1.3, 4.1.4): **У** — мин. температура стенки при эксплуатации −20 °С, при строительстве / монтаже / остановке −40 °С; **УХЛ** — −40 °С / −60 °С; **ХЛ** — −60 °С / −60 °С. Максимальная температура стенки — 350 °С.
- Коэффициент условий работы (п. 4.1.5): **m = 0,825** — категории I и II; **m = 0,66** — категория «В»; по согласованию — 0,75 / 0,6.
- Классы прочности (п. 4.1.6, 4.5.2): **К34–К60**; промежуточные и более низкие — по договорённости. Класс детали с кольцами = класс детали; у узлов класс не устанавливается.
- **Класс прочности изделия не ниже класса прочности присоединяемых труб**; марка стали изделия должна соответствовать марке стали линейной части (п. 4.2.1).

## 2. Условное обозначение (п. 1.6, 2.2)
Состав: наименование; буквенное обозначение; наружный(е) диаметр(ы) × толщина(ы) стенки; рабочее давление, МПа; коэффициент условий работы; угол (для отводов); марка стали; класс прочности; климатическое исполнение; обозначение ТУ; доп. испытания / требования при необходимости.
Примеры (дословно по п. 2.2):
- «Отвод ОСС 90гр. 1020х16-4,0-0,825-09Г2С-К50-УХЛ, ТУ 1469-006-82932963-2018»
- «Тройник ТШС 1020х16-720х14-7,5-0,66-09Г2С-К50-УХЛ, ТУ 1469-006-82932963-2018»
- «Переход ПШСК 1020х16-720х14-7,5-0,66-09Г2С-К50-УХЛ, ТУ 1469-006-82932963-2018»
- «Днище ДШ 1020х16-7,5-0,66-09Г2С-К50-УХЛ, ТУ 1469-006-82932963-2018»
- «Кольцо КП 1020х21-1020х16-6,4-0,66-09Г2С-К50-УХЛ, ТУ 1469-006-82932963-2018»
Детали с кольцами — к буквенному обозначению добавляется КП (ТШС-КП, ТШС-2КП…). Обозначение узлов — по проектным чертежам.
Обозначение без класса прочности, давления, коэффициента m, марки стали или исполнения — **неполное**, идентификация не пройдена.

## 3. Материалы и технология (п. 4.2, 4.8)
- **Допускаются** (п. 4.2.2, 4.8.1): трубные заготовки (вальцованные обечайки из листа); **бесшовные горячедеформированные трубы**; **прямошовные сварные трубы, сваренные под флюсом или ТВЧ**; листовой прокат. ⚠️ В отличие от ТУ 1469-016 (файл 01), **ТВЧ-трубы здесь разрешены**.
- Материал — с нормированными химсоставом, размерами, механическими свойствами и качеством поверхности; химсостав и свойства — не ниже требований этих ТУ (п. 4.8.2).
- Изготовитель обязан провести **входной контроль материала** (п. 4.8.7) — в паспорте на деталь должны быть ссылки на НД и сертификат на передельный материал (п. 9.2).
- Микроструктура (п. 4.6): зерно изделия не крупнее **№ 8** шкалы 1 ГОСТ 5639 (материала — № 9, п. 4.8.3); неметаллические включения — средний балл ≤ 2,5 (оксиды, силикаты, сульфиды), нитриды ≤ 1 (ГОСТ 1778) — **принимается по сертификату** изготовителя передельного материала; полосчатость ≤ 1,5 балла (изделие), ≤ 2,0 (материал).
- **Термообработка обязательна** для изделий (п. 4.2.3): по режимам, обеспечивающим механические свойства, снятие напряжений и однородную структуру; по технологии изготовителя, после устранения дефектов швов, у тройников с решёткой — после приварки решётки. **Сварные соединения узлов не термообрабатывают** (п. 4.2.4). Класс прочности достигается термообработкой (п. 4.5.3).

## 6. Сварные соединения и НК (п. 4.9, 4.10, 8.14–8.16)
- Смещение кромок: продольные ≤ 10 % толщины, ≤ 3 мм; кольцевые ≤ 20 %, ≤ 3 мм (п. 4.9.1); увод кромок f ≤ 0,1S + 3 мм, ≤ 5 мм (п. 4.9.2).
- Сварщики аттестованы; клеймо сварщика на каждом шве (п. 4.9.6, 4.9.7).
- **НК швов 100 % каждой детали — УЗК** по ГОСТ Р 55724-2013; **радиография — только по согласованию с заказчиком** (п. 8.14, в ред. Изм. № 1). Нормы — СТО Газпром 2-2.4-083-2006 или ВСН 012-88.
- Торцы — ПВК (ГОСТ 18442, класс 2) или МПД (ГОСТ Р 56512) (п. 8.16). Сплошность металла DN 500–1400 — как у исходного материала; несплошность на кромках и в зоне 25 мм от торца не допускается (п. 4.5.14).

## 11. Порядок проверки
1. **Идентификация** (блокирующий): обозначение по п. 2.2 — шифр, D×S, давление, m, марка, класс, исполнение, ТУ; сверка с КД / заданием; давление ≤ 10 МПа; класс изделия ≥ класса трубы (п. 4.2.1).
2. **Заготовка**: вид (бесшовная / SAW / ТВЧ / лист / обечайка); НД и сертификат на передельный материал; плавка.
3. **Химсостав** — по табл. 4 для марки, с отклонениями табл. 5 **только для анализа в материале / изделии** (решение о виде анализа — файл 07); **водород**; CE — наличие.
4. **Механика** по табл. 6 (σт для К52 — 353), σт/σв по табл. 7 с учётом вида ТО.
5. **KCU** основного металла и шва при −40 °С (У) / −60 °С (УХЛ) по табл. 8; **KCV** 34,3 при 0 °С (У) / −15 °С (УХЛ). Требование КД — приоритет (файл 07).
6. **Твёрдость** — наличие результата (норма в ТУ не установлена — сравнивать с КД, если есть).
7. **Гидроиспытание** — отметка или гарантия.
8. **НК швов** — УЗК 100 % (РК — если оговорено).
9. **Документ о качестве** — все сведения п. 9.2.
10. **ТР ТС 032/2013** — файл 06.
11. Маркировка, поверхность (п. 4.5.13), торцы — при ВИК.
