# 01 — Детали соединительные по ТУ 1469-016-01395041-2008 (Часть 1: ТУ 1469-016.1-01395041-2008)
**Чек-лист входного контроля паспортов на детали магистральных газопроводов и промысловых трубопроводов**

> Составлен по тексту ТУ 1469-016.1-01395041-2008 «Детали соединительные магистральных газопроводов на рабочее давление до 11,8 МПа и промысловых трубопроводов на рабочее давление до 16 МПа. Технические условия. Часть 1», держатель — ЗАО «Лискимонтажконструкция» (ЗАО «ЛМК»). В базе — только **Часть 1**. Лист регистрации изменений пуст.
> Файл в базе — PDF с хорошим текстовым слоем. Таблицы 2 и 3, формулы (1), (2) и форма паспорта (прил. Г1) сверены по скану — файл 10.
> Роль, общий порядок, классификация (браковочный признак / замечание / неопределённость) и оформление — по Инструкциям проекта и файлам 07, 09. Решения файла 07 имеют приоритет.
> **Это не ГОСТ 17380.** Нормы ГОСТ 17380 (табл. 7, п. 5.1.5, KCU ≥ 39 / KCV ≥ 34, форма паспорта прил. А) к деталям по этим ТУ **не применять**. Ссылка в паспорте на ГОСТ 17380 вместо ТУ — несоответствие НД.

## 1. Область (вводная часть, п. 1.1)
- Детали: **отводы крутоизогнутые (ОКШ), тройники штампованные (ТШ), штампосварные (ТШС, с решёткой ТШСР), сварные (ТС, с решёткой ТСР), переходы штампованные (ПШ), штампосварные (ПШС), сварные концентрические / эксцентрические (ПС / ЭПС), днища (заглушки) штампованные эллиптические / сферические (ДШ), кольца переходные (КП), детали с кольцами переходными** (табл. 1).
- **Промысловые трубопроводы:** DN 50–1000, рабочее давление до **16 МПа**. **Магистральные газопроводы:** DN 500–1400, до **11,8 МПа**. **Тройники сварные** — до **9,8 МПа**.
- Среда — некоррозионно-активный газ и газовый конденсат (объекты ОАО «Газпром» и др.).
- Исполнения (п. 1.1.2, 1.1.3): **УХЛ** — минимальная температура стенки при эксплуатации от −20 до −60 °С (по проекту), при строительстве / остановке — не ниже −60 °С; **У** — эксплуатация −5 °С, строительство / остановка — не ниже −40 °С. Максимальная температура стенки — +170 °С (без покрытия).
- Категория участка (п. 1.1.4): **Н, С, В**.

## 2. Условное обозначение (вводная часть, примеры дословно)
Состав: наименование; буквенное обозначение; угол (для отводов); наружный диаметр присоединяемой трубы; **толщина стенки и класс прочности присоединяемой трубы (в скобках)**; рабочее давление, МПа; категория участка; радиус для отводов, если ≠ 1,5DN; климатическое исполнение; длина КП, если > 250 мм; минимальная температура стенки при эксплуатации, если ниже −20 °С; обозначение ТУ.
Примеры:
- «ОКШ 90° 720(16К48)–12,5–В–УХЛ −40°С ТУ 1469-016.1-01395041-2008»
- «ПШ 530(16К60)–426(14К54)–14,0–С–У ТУ 1469-016.1-01395041-2008»
- «ДШ 530(12К48)–12,5–В–УХЛ ТУ 1469-016.1-01395041-2008»
- «ТШС 720(18К54)–12,5–С–УХЛ ТУ 1469-016.1-01395041-2008»
- «ТС 76(7К48)х57(5К48)–9,8–С–УХЛ −43°С ТУ 1469-016.1-01395041-2008»
- «КП (500) 1020(21х16К60)–10,0–С–УХЛ ТУ 1469-016.1-01395041-2008»

Обозначение без класса прочности трубы, давления, категории или исполнения — **неполное**, идентификация не пройдена.
**Температура стенки ниже −20 °С** должна быть в обозначении — от неё зависит температура испытания KCV (п. 1.3.5).

## 3. Материалы и заготовки (п. 1.2)
- **Допускаются** (п. 1.2.2): трубы прямошовные с одним или двумя швами, **дуговая сварка под флюсом**; бесшовные трубы; листовой прокат. **Не допускаются:** спиральношовные трубы и обечайки; трубы и обечайки, сваренные **индукционной сваркой, включая ТВЧ**. Сталь — только **спокойная** (полностью раскисленная), углеродистая или низколегированная.
- Лист (п. 1.2.3) — по ГОСТ 1050, ГОСТ 19281, ГОСТ 1577, ГОСТ 5520 или иной НД с требованиями не ниже.
- Трубы и материалы — по техническим требованиям «Бованенково-Ухта», СТО Газпром 2-2.1-131-2007 и иной НД, утверждённой ОАО «Газпром» (п. 1.2.1; тексты в базе отсутствуют).
- **Сплошность листа** (п. 1.2.4) — 100 % по ГОСТ 22727: **класс 1** — для деталей магистральных газопроводов на 11,8 МПа; **класс 2** — до 9,8 МПа и для промысловых. При классе 2 — дополнительный НК зон вытяжки и зон у сварных швов.

### Химический состав заготовок (п. 1.2.10)
| Элемент | Не более, % |
|---|---|
| S | **0,010** + 0,001 (доп. отклонение) |
| P | **0,015** + 0,005 (доп. отклонение) |
| N | **0,010** + 0,002 (доп. отклонение) |
| V + Nb + Ti | 0,16 (сумма) |
| Cr, Ni, Cu | верхний предел — в заказе |

⚠️ Нормы строже ГОСТ 1050 / ГОСТ 19281 (например, P ≤ 0,030). Сравнивать **с нормой ТУ**, а не марочной.

### Свариваемость (п. 1.2.11) — по скану, файл 10
- **CE(IIW) = C + Mn/6 + (Cr + Mo + V)/5 + (Cu + Ni)/15 ≤ 0,45**
- **Pcm = C + Si/30 + (Mn + Cu + Cr)/20 + Ni/60 + Mo/15 + V/10 + 5B ≤ 0,25** (B < 0,001 % не учитывается)
- Считаются по контрольному анализу основного металла деталей. Фактический CE должен быть в паспорте («Эквивалент по углероду») и в маркировке (п. 1.15.1). Проверять расчётом по химсоставу из паспорта; если элементов для расчёта не хватает — «Не подтверждено».

## 5. Термообработка (п. 1.13)
- **Обязательна** для: деталей холодной штамповки; вальцованных обечаек; сварных переходов; КП из вальцованных обечаек; **всех деталей, при изготовлении которых применялась сварка**. Также — для обеспечения свойств п. 1.3.1–1.3.5 и снятия сварочных напряжений.
- Виды: закалка + отпуск (термоупрочнение), нормализация, высокотемпературный отпуск. Режим — по технологии изготовителя.
- **Запись «Термообработка по технологии завода-изготовителя» предусмотрена рекомендуемой формой паспорта (прил. Г1)** — для деталей по этим ТУ сама по себе не нарушение (правило «термообработка только ссылкой = Не подтверждено» относится к ГОСТ 17380 и здесь не применяется). Но если деталь сварная или холодноштампованная и в паспорте прямо указано «без термообработки» — несоответствие п. 1.13.1.

## 6. Сварные соединения и НК (п. 1.11, 1.12, 3.6–3.9)
- НК сварных швов — **100 % каждой детали**: радиография (ГОСТ 7512, класс чувствительности 2) и УЗК (ГОСТ 14782). Стыковые — основной метод РК, угловые — УЗК. Сдаточный контроль — **после окончательной термообработки** и калибровки (п. 3.6.1).
- Нормы оценки — СТО Газпром 2-2.4-083-2006, табл. 2, **уровень качества А** (п. 1.12.2); УЗК — табл. 16 и п. 1.12.7.
- Кромки: УЗК зоны ≥ 50 мм от торцов на расслоения (п. 3.7, ГОСТ 22727, плоскодонное отверстие Ø6); расслоения на кромках — ПВК класс II (ГОСТ 18442) или МПД уровень Б (ГОСТ 21105), дефекты > 3,2 мм не допускаются (п. 3.8).
- Тройники: зона сопряжения — МПД / ПВК, не менее 2 деталей от партии (п. 3.9).
- **Сплошность основного металла** (п. 1.3.13): 11,8 МПа — класс 1 ГОСТ 22727; до 9,8 МПа и промысловые — класс 2.
- **Ремонт основного металла сваркой не допускается** (п. 1.3.15). Ремонт швов — до окончательной термообработки (п. 1.12.10).
- Остаточная магнитная индукция на торцах ≤ **2 мТл** (п. 1.3.18).

## 7. Гидроиспытание (п. 1.3.17, 2.6.2, 3.12)
- Пробное давление = заводское испытательное давление условной трубы того же диаметра и материала (тройник — по магистрали, переход — по большему диаметру); вода ≥ +5 °С, выдержка ≥ 10 мин.
- **Гидроиспытание проводится в составе типовых испытаний (п. 2.6.2), а не приёмо-сдаточных.** В рекомендуемой форме паспорта — строка **«Гарантируемое давление гидроиспытания ___ МПа»**. Поэтому отсутствие протокола гидроиспытания каждой детали — **не нарушение**; отсутствие в паспорте гарантируемого давления — замечание (справка).

## 8. Правила приёмки (разд. 2) — важно для оценки происхождения данных
- Детали **DN ≥ 500** — поштучно; **DN 50–450** — партиями (одна марка стали, один размер; не более 2000 шт. DN 50–80, 800 шт. DN 100–300, 400 шт. DN 350–450) (п. 2.3).
- **Приёмо-сдаточные испытания** (п. 2.4): 1 % партии (DN < 500) / не менее 3 шт. (DN 500–1400) — на соответствие чертежам, п. 1.3.7–1.3.16 и подразделам 1.4–1.15 (размеры, поверхность, сплошность, НК, маркировка). **Механические свойства и ударная вязкость (п. 1.3.1–1.3.6) в приёмо-сдаточные не входят.**
- **Периодические испытания** (п. 2.5): механические свойства — **раз в год**; для **DN 50–450 — от каждой партии**. Результаты допускается распространять на детали того же типа, марки стали и толщины стенки, той же технологии, разных диаметров (примечание к п. 2.5). Образцы — **из самой детали** (п. 2.5.1), места вырезки — п. 2.5.2–2.5.6.
- **В паспорт заносятся данные приёмо-сдаточных, периодических или типовых испытаний** (п. 1.14.3).
- Следствие для проверки: у деталей **DN ≥ 500** механические свойства в паспорте могут быть результатом периодических испытаний (другой детали того же типа, марки и толщины) — это **не нарушение**. Для **DN 50–450** — должны быть испытания от **этой партии**.
- Повторные испытания — на удвоенном числе образцов; при повторном неудовлетворительном результате деталь бракуется (п. 2.5.11, 2.5.12).

## 9. Паспорт (п. 1.14, прил. Г1)
- Комплект: деталь + паспорт (+ защитные кольца) (п. 1.14.1).
- **DN 50–450 — один паспорт на партию** (или на детали в один адрес); **каждая деталь DN ≥ 500 — свой паспорт** (п. 1.14.2).
- Форма — **рекомендуемая** (прил. Г1). Её графы: изготовитель, адрес; заказчик, накладная; наименование и обозначение детали; заводской номер, номер партии; рабочая среда; **эквивалент по углероду**; маркировка; **сведения о материалах (магистраль / ответвление / переходное кольцо): труба, ГОСТ / ТУ, № сертификата, плавка, марка стали, σв, σт, δ, KCU (основной металл и сварной шов, −60 °С), KCV (−20 °С)**; **химсостав** (C, Si, Mn, P, S, Al, Cu, Cr, Ni); сварщик, клеймо, вид сварки, сварочный материал; **НК сварных швов (РК 100 %, УЗК 100 %)**, заключение; сведения о термообработке; гарантируемое давление гидроиспытания; свидетельство о приёмке; гарантия **12 месяцев со дня отгрузки**; дата; **подписи начальника ОТК и мастера ОТК**, печать.
- Форма рекомендуемая — отличия оформления не нарушение; **отсутствие сведений, которые требуют ТУ** (CE, механика, KCU/KCV, НК швов, химсостав с S, P, N) — неопределённость в Акт.
- Подпись: по форме — начальник ОТК и мастер ОТК. Подпись контролёра ОТК вместо начальника ОТК — замечание (файл 07).

## 10. Маркировка (п. 1.15) — при ВИК
Товарный знак; условное обозначение без наименования и буквенного шифра; **фактический CE**; обозначение ТУ (допускается «ТУ 1469-016.1»); класс прочности; заводской номер детали / партии и год (2 цифры); масса; клеймо ОТК. DN 500–1400 — краской + дополнительно **ударным способом** (знак, номер, год) в рамке.

## 11. Порядок проверки
1. **Идентификация** (блокирующий): обозначение по разд. 2 — буквенный шифр, D(S К…), давление, категория, исполнение, температура (если ниже −20 °С), **ТУ 1469-016.1-01395041-2008**; сверка с КД и заданием. Давление и DN — в области ТУ (разд. 1).
2. **Заготовка**: вид (бесшовная / прямошовная SAW / лист); нет спиральношовных и ТВЧ; спокойная сталь; для листа — сплошность по классу (п. 1.2.4) — по сертификату на заготовку.
3. **Химсостав**: S, P, N по п. 1.2.10 (нормы ТУ строже марочных); V+Nb+Ti; **CE ≤ 0,45, Pcm ≤ 0,25** — пересчитать по паспорту.
4. **Класс прочности детали** по отношению к классу присоединяемой трубы (примечание 2 к табл. 2).
5. **Механика** по табл. 2; σв ≤ норма + 130; σт/σв; твёрдость HV10 (если приведена).
6. **Ударная вязкость**: KCV при температуре стенки эксплуатации и KCU при температуре монтажа, нормы табл. 3 по толщине; для сварных деталей — и по сварному соединению. Требование КД — приоритет (файл 07).
7. **Происхождение данных** — по файлу 07 (раздел «Происхождение данных»): значения паспорта принимаются без протоколов, если нет признаков переписывания; для DN ≥ 500 — допустимы результаты периодических испытаний (п. 2.5).
8. **Сварные детали**: НК швов 100 % (РК + УЗК), уровень А; загиб 120°; термообработка обязательна (п. 1.13.1).
9. **Гидроиспытание**: наличие гарантируемого давления (не протокола).
10. **Паспорт**: на деталь (DN ≥ 500) / на партию (DN 50–450); графы прил. Г1; подписи.
11. **ТР ТС 032/2013** — по файлу 06.
12. Маркировка, поверхность, торцы (п. 1.3.14, 1.15) — при ВИК.

## 13. Что НЕ является нарушением
- Нет протокола гидроиспытания каждой детали — гидроиспытание в составе типовых испытаний, в паспорте — гарантируемое давление (п. 2.6.2, прил. Г1).
- У деталей DN ≥ 500 механические свойства — по результатам периодических испытаний (п. 2.5, 1.14.3).
- Прочерк в ψ — ТУ ψ не нормируют.
- Запись «Термообработка по технологии завода-изготовителя» — предусмотрена формой прил. Г1 (кроме случая «без термообработки» у деталей, где она обязательна).
- Оформление паспорта не по прил. Г1 — форма рекомендуемая (при наличии всех требуемых сведений).
- Отсутствие KCU / KCV у деталей со стенкой менее 6 мм (п. 3.2).
- На одном образце KCU / KCV ниже нормы не более чем на 9,8 Дж/см² и не ниже 30 Дж/см² при среднем в норме (п. 3.2).

## 14. Типовые ошибки проверки
- Применять нормы ГОСТ 17380 (табл. 7, KCU ≥ 39, KCV ≥ 34, ψ) к деталям по этим ТУ.
- Сравнивать S и P с марочными нормами ГОСТ 1050 / 19281 вместо п. 1.2.10 ТУ.
- Проверять только KCU или только KCV — по ТУ нужны оба, при разных температурах.
- Требовать протоколы гидроиспытания и механических испытаний каждой детали DN ≥ 500.
- Пропускать запрет спиральношовных и ТВЧ-труб как заготовки.
