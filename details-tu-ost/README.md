# ВК ТМЦ ➤ Детали по ТУ и ОСТ

Материалы Claude-проекта «ВК ТМЦ ➤ Детали по ТУ и ОСТ» для входного контроля документов о качестве на соединительные детали и трубы, поставляемые по техническим условиям (ТУ) и отраслевым стандартам (ОСТ), и документов по ТР ТС 032/2013. Выгружено 01.11.2026.

## Структура

```
vk-tmc-detali-po-tu/
├── README.md                     — этот файл
├── context.md                    — инструкции проекта (дословно)
├── docs/
│   ├── 01_Чек-листы_по_ТУ/        — чек-листы 01–04 (по одному на ТУ) и 11 (ОСТ 34 10.7xx-97)
│   ├── 02_Решения_правила_справочники/ — файлы 05–10
│   ├── 03_Шаблоны_и_образцы/      — текстовые версии шаблона Акта и образцов справок
│   └── 04_Тексты_ТУ/              — текстовые версии PDF с текстами ТУ
└── originals/                    — исходные файлы (PDF, xlsx)
```

## Обязательное правило по ТУ 102-488-05

ТУ 102-488-05 — скан без текстового слоя, `.md` получен распознаванием с потерями. **Контроль по ТУ 102-488-05 — только по скану (страницам PDF в `originals/`)**, текстовая версия — только для поиска страницы. Правило записано в `context.md` и в чек-листе 03.

## Чего нет среди оригиналов

- **`Образец_Справка_детали.docx`** и **`Образец_Сводная_справка.docx`** — в Claude-проекте хранятся только как извлечённый текст (Markdown), исходных файлов Word там нет. Поддельные docx не создавались. В `docs/03_Шаблоны_и_образцы/` лежит этот текст дословно; оформление Word (поля, шрифты, цвет заголовков, заливка графы «Оценка», объединение ячеек) в нём не сохранилось. Если оригиналы docx есть у вас — положите их в `originals/` под теми же именами.
- **Файлы 01–10** исходно были Markdown — их оригиналом являются сами файлы в `docs/`, отдельных копий в `originals/` нет.
