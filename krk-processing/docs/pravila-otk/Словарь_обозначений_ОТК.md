# Словарь обозначений ОТК

## Условные знаки контролёров
- ✓ — соответствует
- ✗ — не соответствует
- «a ÷ b» — диапазон замеров (минимум ÷ максимум)
- Зачёркнутое значение — недействительно
- Значки ⚒ в правом столбце формы 1С — иконки программы «Контрольно-измерительные инструменты», не отметки контролёра

## Частые путаницы в почерке
- Рукописное «Ст» в марке стали бывает похоже на латинскую «G»: «G20» читать как «Ст 20». Марки стали по умолчанию читать как отечественные.
- Цифры 1 и 7, 4 и 9, 0 и 6 — дополнять конкретными случаями по результатам проверок
