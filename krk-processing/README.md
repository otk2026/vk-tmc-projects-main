# Обработка карт результатов контроля (КРК)

Материалы проекта Claude «Обработка карт результатов контроля»: помощник ОТК АО «МОСГАЗ» вносит результаты входного контроля в КРК по сканам, формам 1С, тексту или таблицам и выдаёт готовый .xlsx.

Выгрузка от 01.11.2026.

## Структура

```
obrabotka-krk/
├── README.md                     — этот файл
├── context.md                    — инструкции проекта (дословно)
├── docs/
│   ├── pravila-otk/              — правила и справочники ОТК
│   │   ├── Решения_ОТК.md
│   │   └── Словарь_обозначений_ОТК.md
│   ├── obrazcy-krk/              — готовые КРК (образцы)
│   │   └── КРК_Фланец_400-16-11-1-В_25_09_2026.md
│   └── skripty/                  — скрипты
│       └── krk_tools.md
└── originals/                    — исходные файлы
    ├── КРК_Фланец_400-16-11-1-В_25_09_2026.xlsx
    └── krk_tools.py
```

**Примечание 1.** «Решения ОТК» и «Словарь обозначений ОТК» хранятся в проекте только как текстовые документы Markdown — исходных Word/PDF-файлов в проекте нет. Поэтому в `originals/` их нет: .md-версия в `docs/` и есть полный оригинальный текст, перенесённый без изменений.

## Проверка ссылок

Сверены все файлы, на которые ссылаются инструкции (`context.md`), «Решения ОТК», «Словарь обозначений ОТК» и `krk_tools.py`. Отдельных чек-листов в проекте нет.

### Нет в проекте

| Ссылка | Где упоминается | Что не так |
|---|---|---|
| «КРК с примечаниями (образец)» — бланк для новой КРК | `context.md`: «Справочные файлы проекта», «Входные данные» | Файла нет. Без него нельзя выполнить сценарий «КРК не приложена — создай новую на бланке». |
| Эталонные пары «скан → КРК» | `context.md`: «Справочные файлы проекта» | Нет ни одного скана и ни одной пары. |
| Готовые КРК (во множественном числе) | `context.md`: «Справочные файлы проекта» | Есть только одна, и она заполнена частично (см. ниже). |

### Неверные или ненадёжные ссылки

| Ссылка | Где | Что не так |
|---|---|---|
| `sys.path.insert(0, "/mnt/project")` | `context.md`, шаг 4 | Путь привязан к среде Claude и доступен не всегда (в текущей сессии этой папки не было). В репозитории скрипт лежит в `originals/krk_tools.py` — путь в инструкции стоит сделать относительным или описать оба варианта. |
| «в сводке упомянуть … в разделе спорных прочтений» | `Решения_ОТК.md`, п. 1 | В сводке по шагу 5 инструкции такого раздела нет; ближайший — п. 3 «Спорные цифры, не влияющие на заключение». Стоит согласовать название. |
| Сотрудники ОТК, поставщик LD | `Словарь_обозначений_ОТК.md` | Заглушки: инициалы Воробьёва не подтверждены, полное наименование LD не вписано, остальные сотрудники не добавлены. Инструкция требует сверять с ними ФИО и поставщиков. |

### Расхождение внутри образца КРК

В `КРК_Фланец_400-16-11-1-В_25_09_2026` наименование — «Фланец 400-16-11-1-В-**09Г2С**…» (DN 400), а в строке маркировки (п. 9) — «**DN250**, … **сталь 20**». Похоже, норма маркировки перенесена из карты другого фланца. Так как файл служит образцом, это стоит проверить и исправить, иначе ошибка будет копироваться в новые КРК.

История изменений проекта — в [`CHANGELOG.md`](CHANGELOG.md).
