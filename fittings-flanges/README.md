# ВК ТМЦ ➤ Фитинги и Фланцы

Материалы проекта входного контроля документов о качестве на детали трубопроводов (отводы, переходы, тройники, заглушки), фланцы и заглушки фланцевые: инструкции, чек-листы, решения, шаблоны выходных документов и тексты нормативных документов в формате Markdown.

- [`context.md`](context.md) — инструкции проекта (роль, задача, порядок работы, жёсткие правила), перенесены дословно.
- `docs/` — Markdown-версии всех документов проекта, разложенные по темам.

## Условные обозначения в текстовых версиях НД

| Пометка | Значение |
|---|---|
| `<!-- стр. N -->` | Начало страницы N исходного PDF (в отображении GitHub не видна) — по ней удобно искать место в оригинале. |
| `[знак]` | В оригинале символ набран картинкой (DN, PN, α, ≥, ≤, верхние индексы, части формул) — текстом не передан. Читать по оригиналу или по `11_Уточнения_текстов_ГОСТ.md`. |
| `[Рисунок: …]` | Рисунок, чертёж или таблица-картинка. Если ниже есть блок «распознанный OCR» — это машинное распознавание, требует сверки. |
| «⚠️ Страница N — скан» | Страница без текстового слоя: текст получен OCR, возможны ошибки в цифрах и буквах. |

Колонтитулы «Техэксперт» (название документа, «Страница N», «Внимание! Документ включён…») удалены. Заголовки таблиц, набранные символами-картинками, могут быть пустыми — сверяйте шапки таблиц с оригиналом.
