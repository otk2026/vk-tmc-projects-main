# 07 — Марки стали и химический состав: как проверять
**ГОСТ 380-2005, ГОСТ 1050-2013, ГОСТ 19281-2014, ГОСТ 5632-2014**

> Нормы сверены с текстами стандартов. Нормы конкретной марки — брать из таблиц приложенного стандарта; здесь — где искать и как применять.

## 1. Общий порядок
1. Определи НД на сталь, по которой изготовлена труба (указывается в НД на трубу, в сертификате, в КД).
2. Возьми нормы марки по **ковшевой пробе** из таблицы НД на сталь.
3. Сравни с **фактическим анализом плавки** в сертификате. Диапазон или нормы вместо цифр — химсостав не подтверждён (файл 01 проекта «Трубы», раздел 8).
4. Допускаемые отклонения в готовой продукции (раздел 5) применяй **только если в сертификате прямо указано, что это анализ готовой продукции**. Вид анализа не указан — сравнивай с нормой марки; уточнять вид анализа не требуется (файл 09, решение от 26.09.2026).
5. Проверь элементы, которые НД на сталь требует ограничивать дополнительно (Cr, Ni, Cu, As, N) — и есть ли право их не определять. Для сталей по ГОСТ 1050 азот обязателен (п. 5.1.1), если в документе нет Al / азотосвязывающих элементов — порядок оценки в файле 09.

## 2. ГОСТ 380-2005 — углеродистая сталь обыкновенного качества (Ст0 … Ст6сп)
- Марки — п. 3.1; степень раскисления (кп, пс, сп), если не указана в заказе, устанавливает изготовитель (п. 3.4).
- Химсостав по ковшевой пробе — **табл. 1** (п. 4.1).
- **П. 4.2:** допускается сталь без ограничения нижнего предела C и Mn при обеспечении механических свойств (кроме судо- и вагоностроения); в Ст2кп, Ст3кп, Ст4кп для сортового и фасонного проката — Si до 0,07 %.
- П. 4.3: при раскислении без Si в полуспокойной стали — Si менее 0,05 %; способ раскисления указывают в документе о качестве.
- **П. 4.4:** Cr, Ni, Cu — не более 0,30 % каждого (кроме Ст0); при скрап-процессе — Cu до 0,40 %, Cr и Ni до 0,35 %, при этом в Ст3 — C не более 0,20 %.
- **П. 4.5:** S ≤ 0,050 %, P ≤ 0,040 % (кроме Ст0).
- **П. 4.6:** N ≤ 0,012 % (электропечь) / 0,010 % (мартен, конвертер); до 0,013 % — при снижении P.
- **П. 4.7:** As ≤ 0,080 % (кроме Ст0).
- **Отклонения в готовой продукции — п. 4.8, табл. 2** (для элементов, ограниченных только сверху, — только плюсовые отклонения).
- **П. 5.3:** Cr, Ni, Cu, As, N (в кипящей стали — и Si) **допускается не определять** при гарантии изготовителя → их отсутствие в сертификате не является нарушением.

## 3. ГОСТ 1050-2013 — нелегированная качественная и специальная сталь (08, 10, 15, 20 …)
- Химсостав по ковшевой пробе — **табл. 1 и 2** (п. 5.1). Пример — сталь 20 (табл. 1): C 0,17–0,24; Si 0,17–0,37; Mn 0,35–0,65; **P ≤ 0,030; S ≤ 0,035**; Cr ≤ 0,25; Ni ≤ 0,30; Cu ≤ 0,30.
- Для марок 05кп … 20пс стандарт распространяется **только в части химсостава** (разд. 1).
- **П. 5.1.1:** N — не более 0,006 / 0,008 % (конвертер без внепечной обработки), 0,010 % (с внепечной), 0,012 % (электропечь); не нормируется при достаточном содержании Al или азотосвязывающих элементов.
- Пп. 5.1.5–5.1.6: допускается снижение нижнего предела отдельных элементов при выполнении требований к механическим свойствам.
- П. 5.1.7: при выплавке с ломом — допускаются остаточные элементы до 0,40 % каждого с указанием фактических значений в документе о качестве.
- **П. 5.1.8:** As ≤ 0,08 % (марки табл. 1).
- **Отклонения в металлопродукции — п. 5.2, табл. 3** (например, C ±0,01; Mn ±0,03; Si ±0,02 для спокойной стали). При поставке без нормирования нижнего предела — только плюсовые отклонения (примечание к табл. 3).
- П. 8.3.3: при неудовлетворительном анализе ковшевой пробы химсостав может быть аттестован по анализу готовой продукции — с указанием в документе о качестве.

## 4. ГОСТ 19281-2014 — прокат повышенной прочности (09Г2С, 10Г2, 17ГС и др.)
- Распространяется на прокат; **в части химсостава** — также на заготовки, поковки и др. (разд. 1). Для труб применяется по химсоставу марки.
- Химсостав по ковшевой пробе — **табл. 1** (по классу прочности, п. 5.1.1) и **табл. 7** (по марке стали, п. 5.2.1.1).
- **П. 5.1.1.1:** As ≤ 0,08 %.
- **Отклонения в продукции — п. 5.1.2, табл. 8** (кроме N); для элементов, ограниченных только сверху, — только плюсовые.
- **Углеродный эквивалент** — формула п. 7.2 (по ковшевой пробе или по готовому прокату); ограничение для продукции с гарантией свариваемости — п. 5.2.1.2 (0,43 / 0,46 / 0,48 / 0,51 % по классам прочности).
- Для труб нормы Сэкв задаёт НД на трубу (ГОСТ 20295 — ≤ 0,46 %; ГОСТ 10705 — ≤ 0,46 %; ГОСТ 10706 — ≤ 0,48 %) или заказ (ГОСТ 8731 — п. 6.2.3, формула п. 9.2.1). Проверяй, по какой формуле посчитан Сэкв в сертификате.

## 4а. Формулы углеродного эквивалента
В текстах стандартов в базе формулы не читаются. Сверенные формулы (ГОСТ 20295, 10705, 10706, 8731, 19281) — в файле **12_Уточнения_текстов_ГОСТ_трубы.md** проекта «Трубы» (`pipes/docs/01_Инструкции_и_чек-листы/`); для деталей и фланцев — также `11_Уточнения_текстов_ГОСТ.md` этого проекта. Если в сертификате Сэкв посчитан по другой формуле — указать это, а не делать вывод. Расчёт Сэкв по химсоставу из сертификата — справочный: он не заменяет обязательную запись Сэкв в документе там, где её требует НД (п. 3.1 ГОСТ 20295).

## 5. ГОСТ 5632-2014 — нержавеющие стали и сплавы (08Х18Н10Т, 12Х18Н10Т …)
- Марки и химсостав по маркировочному анализу — **табл. 1** (п. 6.1).
- **Отклонения в готовой продукции — п. 6.2, табл. 2.**
- Остаточные элементы: Ti ≤ 0,20 % в не легированных Ti (с исключениями, п. 6.3); Cu ≤ 0,30 % в не легированных Cu, кроме аустенитных (п. 6.4); Ni, W, V, Mo — пп. 6.5–6.9.
- Для труб: ГОСТ 9940 (п. 2.1) и ГОСТ 9941 (п. 6.2.1) ссылаются на ГОСТ 5632.

## 6. ГОСТ 19903-2015
Сортамент листового проката. Для труб — справочно (размеры листа / рулона для сварных труб по ГОСТ 10705, 10706, 20295).

## 7. Типовые ошибки проверки химсостава
- Сравнивать фактический анализ **готовой трубы** с нормами ковшевой пробы без учёта допускаемых отклонений в готовой продукции.
- Считать отклонением отсутствие Cr, Ni, Cu, As, N там, где ГОСТ 380 (п. 5.3) разрешает их не определять при гарантии изготовителя.
- Путать п. 4.2 ГОСТ 380 (снятие нижнего предела C и Mn) с отклонениями в готовой продукции (п. 4.8, табл. 2).
- Применять ГОСТ 1050 к механическим свойствам труб: механические свойства труб нормирует НД на трубу, а не НД на сталь.
- Не проверять Сэкв там, где его нормирует НД на трубу (ГОСТ 20295, 10705, 10706) или заказ (ГОСТ 8731).
