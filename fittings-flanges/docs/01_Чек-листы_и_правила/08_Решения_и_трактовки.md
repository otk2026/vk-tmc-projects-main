# 08 — Принятые решения и трактовки

> Имеют приоритет над общими рассуждениями и над общими формулировками чек-листов 01–07. Дополнять после каждой нетиповой проверки: «Ситуация → Решение → Основание → Где возникло».

## Общие
- **Ударная вязкость — сначала требование КД / ТТ заказчика / заявки** (решение от 25.09.2026):
  - Если в КД, ТТ заказчика, заявке или условном обозначении по КД задано требование к ударной вязкости (вид KCU или KCV, температура испытания, норма; например «KCV(-40) > 29,5 Дж/см²»), проверять **только по этому требованию**: есть ли результат именно этого вида при этой температуре и выполняется ли эта норма. Ударную вязкость других видов и температур по общему правилу ГОСТ не требовать и в Акт не выносить — ни как несоответствие, ни как неопределённость.
  - Результат другого вида или при другой температуре (например, KCU при −60 °С вместо KCV при −40 °С) требование не подтверждает: «Не подтверждено», в Акт как требование представить результат по КД. Пересчёт KCU ↔ KCV не допускается.
  - Если требования к ударной вязкости в КД / ТТ / заявке нет — проверять по общему правилу стандарта (чек-лист вида продукции).
  - В справке указывать источник требования: «по КД …» или «по ГОСТ …».
- **Ру без единиц (например, «Ру16», «Ру40», «PN16») — это кгс/см²**: Ру16 = 16 кгс/см² = 1,6 МПа. Правило действует для всей номенклатуры. Двойную трактовку не показывать и в Акт не выносить; при записи Ру в МПа по НД (например, в обозначении по АТК) — пересчитать и указать, что Ру в документе без единиц (замечание, только в справку). (Решение от 24.09.2026.)
- Объём проверки — строго номенклатура из задания; остальные позиции паспорта не проверяются. Конкретный типоразмер в промт не закладывается.
- Идентификация изделия блокирует дальнейшую проверку. Если изделие по другому стандарту — проверка не подгоняется под задание.
- Нормы берутся только из приложенных текстов стандартов.
- Норма KCU 29 Дж/см² устарела; действуют KCU ≥ 39 / KCV ≥ 34 Дж/см² (ГОСТ 17380, изм. № 2).
- Разрешённое стандартом нарушением не считается:
  - распространение результатов испытаний по п. 6.6.4 ГОСТ 17380;
  - необязательный ψ;
  - режим термообработки, назначенный изготовителем, по п. 5.1.6.1 ГОСТ 17380.
- Если в паспорте нет плавок, привязка позиций к сертификатам восстанавливается расчётно — с явной оговоркой в справке.

## Происхождение данных и документы на поковки (решения от 28.09.2026)
- **Общий принцип.** Значения в документе о качестве на изделие (паспорт, сертификат на детали, фланцы, поковки, заглушки) считаются **подтверждёнными без протоколов испытаний**, если нет признаков переписывания. Такие значения сравниваются с нормой; значение вне нормы — «Не соответствует», **отдельная строка Акта**. Протоколы требовать только при признаке переписывания. Распространяется на детали по ГОСТ 17380, фланцы и заглушки.
- **Признак переписывания механических свойств** (σт, σв, δ, ψ, KCU, KCV, твёрдость) — выполнено хотя бы одно:
  - **два и более** показателя совпадают цифра в цифру с документом на полуфабрикат / прокат;
  - **один** показатель совпадает, и при этом состояние металла разное: полуфабрикат / прокат «без термообработки», а изделие после термообработки (или термообработка не указана при группе IV–V).
- **Поковки (фланцы ветви А, заготовки по ГОСТ 8479-70): признак переписывания механики** → «Механические свойства поковок не подтверждены», оценка в справке **НЕ СООТВЕТСТВУЕТ** (исключение из общего правила «Не соответствует — только при значении вне нормы»), **одна строка в Акт**. Требование — документ о качестве изготовителя поковок с результатами испытаний поковок (п. 3.3, табл. 2 ГОСТ 8479-70). В справке под строкой — таблица сравнения: показатель | документ на поковки | сертификат на прокат | совпадает.
  Пример формулировки для Акта:
  > <b><u>Механические свойства поковок не подтверждены — σт, σв, δ совпадают с сертификатом на круг без термообработки.</u></b>
  > <b>Требование:</b> п. 3.3, табл. 2 ГОСТ 8479-70 — результаты испытаний поковок группы IV КП 245.
  > <b>Факт:</b> сертификат № 95804 — σт 315, σв 465, δ 33 равны значениям сертификата ПАО «НМЗ» № 53/1965 на круг Ø300 без термообработки.
- **Детали по ГОСТ 17380 и фланцы ветви Б (точение из проката): признак переписывания механики** → «Не подтверждено», в Акт требование протоколов испытаний (п. 6.6 ГОСТ 17380 / табл. 13 ГОСТ 33259).
- **Плавка и химсостав поковки** совпадают с сертификатом на прокат — **это не признак переписывания** (п. 2.5 ГОСТ 8479-70: при изготовлении поковок из проката марка стали и химический состав устанавливаются документом о качестве изготовителя металла). Плавка и химсостав принимаются по документу на поковки, если выполнены все условия:
  1. плавка и марка стали в документе на поковки совпадают с сертификатом на прокат;
  2. химсостав соответствует марке стали;
  3. **геометрия проходит**: поковку можно получить из этого проката. Масса поковки оценочно 1,5–3 массы готового изделия; длина куска проката L = масса поковки / масса погонного метра проката; для осадки L / диаметр круга ≤ 2,5. Масса проката по сертификату (если указана) — не меньше суммарной массы поковок партии;
  4. даты логичны: сертификат на прокат выдан раньше документа на поковки.
  Для поковок, изготовленных объёмной штамповкой, состав документа о качестве устанавливается по соглашению изготовителя с потребителем (примечание к п. 3.3 ГОСТ 8479-70): требование полного перечня п. 3.3 к штамповкам — только при ссылке на договор / заказ. Требование результатов испытаний механических свойств по табл. 13 ГОСТ 33259 для фланцев действует независимо от вида заготовки.
  Хотя бы одно условие не выполнено → плавка и химсостав «Не подтверждено», в Акт требование документа изготовителя поковок с плавкой и химсоставом. Маркировку плавки на изделии как условие не требовать.
- **Кольцевые поковки, изготовленные раскаткой** (решение от 29.09.2026): примечание к табл. 3 ГОСТ 8479-70 цитировать дословно — «по нормам для предельных образцов»; результаты на тангенциальных образцах оценивать по нормам табл. 2 **без снижения** по табл. 3. Если способ изготовления или вид образцов не указан, а вывод от них зависит, — «Не подтверждено», отдельная строка Акта с требованием указать способ изготовления поковки и вид образцов. Эти сведения запрашивать у поставщика всегда (файл 05, шаги 4 и 6).
- **Показатель, для которого нет нормы при этом виде / температуре** (например, KCU при −60 °С, если норма KCU задана при +20 °С) — принимается как данные, с нормой не сравнивается: «Не оценивается», в Акт не идёт.
- **Требование КД (ТТ, заявки)** — всегда **отдельная строка Акта**, даже если материал или механика не подтверждены по другому основанию.

## Детали трубопроводов
- **Паспорт детали подписан контролёром ОТК, а не начальником ОТК** — **замечание, только в справку** (оценка жёлтая «Подлежит исправлению (не браковочный признак)»), в Акт не включается. Основание: форма паспорта по приложению А ГОСТ 17380-2001 рекомендуемая (п. 5.3). Исключение — если КД или договор прямо требуют подпись начальника ОТК: тогда несоответствие. (Решение от 25.09.2026.)
- **Деталь с индексом «П»: относительное сужение ψ не указано (прочерк)** — оценка **«Не подтверждено»** (красный), в Акт как требование представить результат испытания (п. 6.6.3 ГОСТ 17380-2001). Не оценивать как «Частично» и не называть «не браковочным признаком». (Решение от 24.09.2026.)
- **Деталь с индексом «П»: ψ указан, но ниже нормы табл. 7 ГОСТ 17380-2001** (например, 58 % при норме ≥ 60 % для К42) — **«Не соответствует»** (красный), браковочный признак, в Акт. Основание: для деталей с «П» ψ определяют обязательно (п. 6.6.3), поэтому к нему применяется норма табл. 7; ссылку на факультативность ψ (сноска к табл. 7) для деталей с «П» не применять. Для деталей без «П» и на Py ≤ 10 МПа ψ ниже нормы — замечание, только в справку. (Решение от 25.09.2026.)
- **Термообработка в паспорте указана только ссылкой (на НД, ТУ, «по технологии»), вид не назван** — оценка **«Не подтверждено»** (красный), в Акт как требование указать вид термообработки. Не оценивать как «Частично». (Решение от 24.09.2026.)
- Расхождение массы перехода с табл. 2 ГОСТ 17378 — справочное замечание, не брак.
- **Открытый вопрос:** отвод 2D (ГОСТ 30753) поставлен вместо 3D (ГОСТ 17375) — решение не принято. При повторении — выносить на моё решение, не делать вывод самостоятельно.

## Фланцы
- **Твёрдость группы IV–V, одинаковые значения у всех позиций (например, 255 НВ — вероятно, предельное по п. 7.1.16 ГОСТ 1050, а не измерение)** — **замечание, только в справку**: указать признак переноса данных и что поштучное измерение по табл. 13 не подтверждено. В Акт не включается (ни как несоответствие, ни как неопределённость), если КД не делает твёрдость сдаточной. (Решение от 25.09.2026.)
- Точение фланцев типа 11 из сортового проката допустимо по п. 7.9.2 ГОСТ 33259-2015 (Изм. № 1) **без дополнительных условий** — само по себе нарушением не является. Механические свойства при этом оцениваются по ветви Б (табл. 4 ГОСТ 1050-2013).
- Сплошность (УЗК) заготовок фланцев — по сноске к табл. 13: для PN 100 (10 МПа) и выше — обязательно, 100 %; ниже PN 100 — только по требованию заказчика. Правило одинаково для поковок, штамповок и проката. Если УЗК проводился — прокат по ГОСТ 21120 (1 группа качества), лист по ГОСТ 22727 (1 класс сплошности), поковки по ГОСТ 24507 (2n / 4n).
- Сварные плоские фланцы (типы 01–04) из частей — радиальные швы: 100 % РК или УЗК (п. 7.9.2).
- ГОСТ 8479 и требование КП применяются только к поковкам.
- Твёрдость для групп IV–V не является браковочным признаком, если КД не делает её сдаточной.
- Сначала определяется вид заготовки, потом оцениваются механические свойства. Для круга расчётное сечение = диаметр заготовки.
- Объединённый паспорт на фланцы и заглушки — отступление от п. 9.6 ГОСТ 33259.

## Заглушки фланцевые (АТК 24.200.02-90)
- **Паспорт заглушки ссылается на ГОСТ 17380-2001 (например, «Условия применения: по ГОСТ 17380-2001»)** — **неопределённость, в Акт**: условия применения по НД на изделие не установлены (ГОСТ 17380 на фланцевые заглушки не распространяется; область применения по ГОСТ 17380 и АТК различается). Требование — уточнённый паспорт с условиями применения по АТК 24.200.02-90. (Решение от 24.09.2026.)
- **ОСТ 26-291, на который ссылается АТК, заменён ГОСТ 34347-2017** — отсылки АТК к ОСТ 26-291 применять как к ГОСТ 34347-2017; пункты ГОСТ 34347 — только по приложенному тексту. (Решение от 25.09.2026.)
- Справка на заглушки фланцевые оформляется по **Образец_Справка_детали_docx.docx**. (Решение от 24.09.2026.)

## Полуфабрикат (трубы, лист) для деталей
- **Вид анализа в сертификате (ковшевая проба / готовая продукция) не указан** — не замечание и не требование в Акт; уточнять вид анализа у поставщика не нужно. Главное — фактический химсостав соответствует НД. Сравнивать с нормой марки (например, табл. 1 ГОСТ 1050-2013). Допускаемые отклонения для готовой продукции (п. 5.2, табл. 3 ГОСТ 1050; п. 4.8, табл. 2 ГОСТ 380; п. 5.1.2, табл. 8 ГОСТ 19281) применять **только если в сертификате прямо указано, что это анализ готовой продукции**. Значение выше нормы марки без такой пометки — «Не соответствует», в Акт. (Решение от 26.09.2026.)
- **Азот (N) для сталей по ГОСТ 1050-2013 (в т. ч. сталь 20)** — нормируется обязательно (п. 5.1.1): не более 0,006 / 0,008 % (кислородно-конвертерная без внепечной обработки), 0,010 % (с внепечной обработкой), 0,012 % (электропечь). **Не нормируется**, только если в документе о качестве указано: Al общий ≥ 0,020 % или кислоторастворимый ≥ 0,015 %, либо азотосвязывающие элементы (п. 5.1.1 — их содержание должно быть указано в документе). Оценка (решение от 26.09.2026):
  - N не указан и нет ни Al, ни азотосвязывающих элементов → **«Не подтверждено», в Акт** как требование представить содержание N (или Al / азотосвязывающих элементов) и способ выплавки.
  - N указан, способ выплавки не указан: N ≤ 0,006 % (для листа и ленты) / ≤ 0,008 % (прочая продукция) — «Соответствует» при любом способе; N выше этого, но ≤ 0,012 % — «Не подтверждено», в Акт как требование указать способ выплавки (п. 8.1.1 ГОСТ 1050 обязывает указывать его в документе о качестве); N > 0,012 % — «Не соответствует».
  - N выше предела для указанного способа выплавки → «Не соответствует», в Акт.
  - Для сталей по ГОСТ 380 правило другое: N допускается не определять при гарантии изготовителя (п. 5.3 ГОСТ 380).
- Трубы как самостоятельная поставка проверяются в проекте «ВК ТМЦ ➤ Трубы» (папка `pipes`); здесь сертификат на трубу / лист — только документ на полуфабрикат (файл 06).
- ГОСТ 8731-2025: ударная вязкость труб группы В — только по требованию заказчика (п. 6.3.3). Отсутствие KCU в сертификате на трубу — нормально. KCU в паспорте детали при этом принимается как подтверждённое значение детали (решение от 28.09.2026, раздел «Происхождение данных»), протокол не требуется; значение сравнивается с нормой п. 5.1.5 ГОСТ 17380.
- С 01.03.2026 ГОСТ 8731-74 / 8732-78 заменены на ГОСТ 8731-2025 / 8732-2025; сертификат на полуфабрикат, изготовленный ранее, по старой редакции — не нарушение.
- Отклонения химсостава в готовой продукции допускаются в пределах п. 4.8 и табл. 2 ГОСТ 380-2005 и п. 5.2 и табл. 3 ГОСТ 1050-2013 — только если в сертификате указано, что это анализ готовой продукции (решение от 26.09.2026) (для ГОСТ 19281 — п. 5.1.2, табл. 8). П. 4.2 ГОСТ 380 и пп. 5.1.5–5.1.6 ГОСТ 1050 — другое: снижение нижнего предела отдельных элементов при обеспечении механических свойств.
- «Нормализация образцов» в сертификате на прокат / трубу ≠ термообработка металла: состояние поставки металла оценивается отдельно.
- Лист или труба по ТУ вместо ГОСТ, указанного в КД: расхождение остаётся несоответствием, пока не оформлено решение (изменение КД или протокол применения).
