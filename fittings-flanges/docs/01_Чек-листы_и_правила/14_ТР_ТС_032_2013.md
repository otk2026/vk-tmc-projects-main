# 14 — Подтверждение соответствия ТР ТС 032/2013 (чек-лист для деталей трубопроводов, фланцев и заглушек)

> Источник норм — приложенный текст ТР ТС 032/2013. **Номера статей, приложений и таблиц регламента в этот файл не вписаны**: цитировать их только по приложенному тексту (формат «ст. N ТР ТС 032/2013», «приложение N»), иначе — «по приложенному тексту не проверено». Статус документа в реестре проверить нельзя — всегда добавлять пункт «проверить в реестре» с номером документа.

## 1. Что проверять по каждому документу (сертификат / декларация)
| № | Пункт | Что смотреть |
|---|---|---|
| 1 | Наличие | Копия приложена к комплекту. Номера, напечатанные только в колонтитуле паспорта без области распространения, — не подтверждение (файл 09, раздел 11) |
| 2 | Вид документа | Обязателен сертификат или декларация — по категории изделия (см. п. 2). Добровольный сертификат юридической силы не имеет (файл 08) |
| 3 | Номер, дата, срок действия | Действует на дату изготовления / поставки |
| 4 | Заявитель и изготовитель | Совпадают с изготовителем в паспорте детали |
| 5 | Область распространения | Наименование продукции, типоразмеры (DN, толщина), давление, марка стали — охватывают предъявленные детали |
| 6 | НД на изделие | НД в документе совпадает с НД изделия в КД и паспорте (например, сосед по серии стандартов вместо нужного — несоответствие) |
| 7 | Давление и параметры | Заявленное давление совместимо с НД на продукцию (пример нелепости: 50 МПа, файл 09) |
| 8 | Схема и форма оценки | Схема соответствует форме оценки и категории (по приложенному тексту регламента) |
| 9 | Реестр | Пункт «проверить в реестре» с номером |

## 2. Категория и форма подтверждения
- Для деталей трубопроводов **4-й категории** обязательна сертификация; схемы по тексту ТР ТС: 1с, 3с, 4с, 7с. Запись «схема 3д» ошибочна — 3д относится к декларированию (файл 08).
- Категорию изделия определять **по приложенному тексту регламента** и данным КД; по памяти категорию не называть. Не определена — «не подтверждено», вопрос ко мне.
- Исключения для газопроводов не касаются технологических трубопроводов (файл 08).

## 3. Что НЕ делать
- Не ссылаться на регламент как на основание требования прослеживаемости — такая ссылка снята (файл 08).
- Не делать вывод о «подлинности» документа: проверить в реестре не можешь.

## 4. Оценки
- Документ не приложен или не относится к продукции → «Не подтверждено», в Акт как требование представить.
- НД / параметры в документе противоречат изделию → «Не соответствует», строка Акта (с «Требование» и «Факт» по формуле файла 10).
- Вид документа не соответствует категории (добровольный сертификат, декларация вместо сертификата) → «Не соответствует».
