# 08 — Применимость ТР ТС 004/2011 «О безопасности низковольтного оборудования»

> Текст — `ТР ТС 004-2011.pdf` (с изменениями на 10.06.2022; изменения решением Совета ЕЭК № 90 действуют с 11.12.2022). Номера страниц — страницы этого PDF.
> **Сверено по оригиналу 09.11.2026:** ст. 7, п. 1–2 (стр. 6). Остальное — по текстовой версии (PDF с текстовым слоем).

## 1. Область применения (ст. 1, п. 1, стр. 2)

Электрическое оборудование для использования при номинальном напряжении **от 50 до 1000 В включительно переменного тока** и **от 75 до 1500 В включительно постоянного тока**.

## 2. Не распространяется (ст. 1, п. 2, стр. 2)

| Подпункт | Что исключено |
|---|---|
| «а» | Низковольтное оборудование, **входящее в область применения и подлежащее подтверждению соответствия по ТР ТС 010/2011, 011/2011 (лифты) или 012/2011, — за исключением кабелей, проводов, шнуров**; бывшее в употреблении; для воздушного, водного, наземного и подземного транспорта; для атомной энергетики; изготовленное для собственных нужд; управляющие устройства пастбищных изгородей |
| «б» | Медицинские изделия |
| «в» | Оборонная продукция |
| «г» | Составные части (узлы, комплектующие), поставляемые изготовителю оборудования по договору и не доступные потребителю иначе как встроенными |
| «д» | Составные части, безопасность которых определяется встраиванием (соединители, реле, печатные платы, конденсаторы и т. п.) |

**Важно:** если изделие (например, насос, компрессор, арматура с приводом) подлежит подтверждению по ТР ТС 010/2011 или 012/2011 — ТР ТС 004/2011 к нему **не применяется** (кроме кабелей, проводов, шнуров). Поэтому сначала решить по ТР ТС 010 (файл 03) и 012 (файл 04).

## 3. Форма подтверждения (ст. 7, стр. 6–7)

- Включено в **Перечень (приложение, стр. 13–15)** → **сертификация** (схемы 1с, 3с, 4с) (ст. 7, п. 2, стр. 6, сверено).
- **Не включено в Перечень** → **декларирование** (схемы 1д, 2д, 3д, 4д, 6д); по выбору заявителя возможна сертификация (ст. 7, п. 2, стр. 7).

### Перечень (приложение, стр. 13–15) — позиции, значимые для номенклатуры ВК ТМЦ

| Пункт | Продукция |
|---|---|
| 1 | Электрические аппараты и приборы бытового назначения (в т. ч. электронасосы бытовые, световое оборудование, изделия электроустановочные, удлинители, пульты и панели управления, контроллеры бытовые) |
| 6 | **Кабели, провода и шнуры** |
| 7 | **Выключатели автоматические, УЗО, плавкие предохранители, распределительные устройства, переключатели, контакторы, пускатели** |
| 2–5 | ПЭВМ, оргтехника, инструмент электронагревательный, электромузыкальные инструменты |

## 4. Как рассуждать

| Позиция | Вывод |
|---|---|
| Трубы, детали трубопроводов, фланцы, арматура без привода | «Не применим» — не электрическое оборудование (ст. 1, п. 1) |
| Арматура с электроприводом | Сначала ТР ТС 010 (арматура — прил. 3 ТР ТС 010, п. 59) и 012: если подлежит подтверждению по ним — ТР ТС 004 «Не применим» (ст. 1, п. 2 «а»). Электропривод, поставляемый **отдельной позицией**: сначала проверить, не указан ли он в приложении № 3 ТР ТС 010 (файл 03); если нет и напряжение 50–1000 В ~ / 75–1500 В = → «Применим», декларация (если не в Перечне) |
| Кабели, провода, шнуры | «Применим» — сертификат (Перечень, п. 6), даже если входят в изделие по 010 / 012 |
| Шкафы управления, щиты, автоматы, пускатели | «Применим» — сертификат (Перечень, п. 7) |
| Датчики, преобразователи на 24 В | «Не применим» — напряжение ниже 50 В ~ / 75 В = (ст. 1, п. 1). Проверить ТР ТС 020 (файл 09) |
| Напряжение в данных не указано | «Не определено» — запросить номинальное напряжение |
