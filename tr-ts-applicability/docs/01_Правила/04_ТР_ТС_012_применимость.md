# 04 — Применимость ТР ТС 012/2011 «О безопасности оборудования для работы во взрывоопасных средах»

> Текст — `ТР ТС 012-2011.pdf`. Номера страниц — страницы этого PDF.
> **Сверено по оригиналу 08.11.2026:** ст. 6 (стр. 9). Ст. 1 — по текстовой версии (стр. 1–2).

## 1. Область применения (ст. 1, стр. 1–2)

- Распространяется на **электрическое оборудование (включая Ex-компоненты) и неэлектрическое оборудование для работы во взрывоопасных средах** (ст. 1, п. 3).
- **Идентификационный признак** — наличие средств обеспечения взрывозащиты, указанных в технической документации изготовителя, и маркировки взрывозащиты на оборудовании и Ex-компонентах (ст. 1, п. 3).
- Не распространяется (ст. 1, п. 4, стр. 2): изделия медицинского назначения; оборудование, где опасность взрыва возникает только из-за взрывоопасных веществ и нестойких химических соединений; оборудование для бытового и непроизводственного применения, когда взрывоопасная среда образуется из-за непредвиденной утечки горючего газа; СИЗ; суда и плавучие платформы; транспорт общего пользования; ядерное оружие и др. — полный перечень по тексту.

## 2. Форма подтверждения (ст. 6, стр. 9, сверено)

- Подтверждение соответствия обязательно и осуществляется **только в форме сертификации** (ст. 6, п. 1). Декларация по ТР ТС 012 не предусмотрена.
- Схемы: 1с — серийное; 3с — партия; 4с — единица оборудования (ст. 6, п. 3).

## 3. Как рассуждать

| Позиция | Вывод |
|---|---|
| Трубы, детали трубопроводов, фланцы, арматура без привода и без средств взрывозащиты | «Не применим»: нет идентификационного признака (средств взрывозащиты и маркировки Ex), ст. 1, п. 3 |
| Арматура с электроприводом, датчиками, концевыми выключателями для взрывоопасной зоны | «Применим» к электроприводу / Ex-компонентам — сертификат ТР ТС 012. Если в проекте зона не указана — «Не определено», запросить классификацию зоны |
| Изделие с маркировкой Ex в обозначении или опросном листе | «Применим» — сертификат |
| Взрывоопасная зона в проекте не указана, а изделие может иметь электрооборудование | «Не определено» — запросить классификацию взрывоопасной зоны и исполнение |

Неэлектрическое оборудование подпадает под регламент, только если для взрывоопасной среды оно имеет собственные средства взрывозащиты (идентификационный признак). Сама по себе работа с горючим газом внутри трубопровода признаком не является.
