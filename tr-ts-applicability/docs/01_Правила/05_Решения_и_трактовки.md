# 05 — Решения и трактовки (приоритет над рассуждениями)

> Сюда вносятся решения пользователя (начальника ОТК) по спорным вопросам применимости — с датой. Решение действует для всех следующих заключений. Открытые вопросы ИИ не решает сам: вывод по ним — «Не определено» с формулировкой вопроса.

## Принятые решения

1. **Каждый регламент проверяется отдельно** (08.11.2026, при создании проекта). Неприменимость одного регламента не означает неприменимость другого; при применимости нескольких — нужны документы по каждому.
2. **Добровольный сертификат не заменяет обязательный** документ по ТР ТС (ст. 21 ФЗ № 184-ФЗ) — перенесено из проектов проверки документов о качестве.
3. **Исключения ТР ТС 032 для газопроводов (п. 3 «а», «б») не распространяются на технологические трубопроводы** — перенесено из проектов проверки документов о качестве (файлы ТР ТС 032 проектов `fittings-flanges`, `pipes`, `details-tu-ost`).
4. **Природный газ — рабочая среда группы 1** (горючий газ, п. 4 ТР ТС 032, стр. 5).
5. **Состав проекта закрыт** (09.11.2026): ТР ТС 032, 010, 012, 004, 020 и ФНП 536. Другие ТР ТС не рассматриваются.
6. **ФНП 536 на газопроводы не распространяются** — газопроводы не входят в перечень видов оборудования п. 3 ФНП (п. 5, абз. 1, стр. 3). Это не решает вопросы О-1 и О-2 по ТР ТС 032 — они остаются открытыми.

## Предварительные правила (приняты при создании проекта 08.11.2026 — подтвердить или изменить)

7. **Категория по ТР ТС 032 — по параметрам изделия** (PN, DN, вместимость), так как документ о подтверждении соответствия оформляется на изделие. Назначение и среда из требований проекта определяют исключения (п. 3) и группу среды. Если расчётное давление проекта выше PN изделия — это вопрос к проекту, в Заключении указать.
8. **Детали трубопроводов и фланцы — элементы / комплектующие (п. 2 «к»), 4-я категория (прил. 1, п. 1) → сертификация**, если применение не попадает в исключения п. 3. Совпадает с трактовкой проектов проверки документов о качестве («детали трубопроводов — 4-я категория, сертификация»).

## Открытые вопросы (до решения пользователя — «Не определено»)

| № | Вопрос | Почему спорно |
|---|---|---|
| О-1 | **ГРП, ГРПШ, ПРГ и их оборудование в составе сети газораспределения**: регламент не применяется по п. 3 «б» (сети газораспределения) или применяется по оговорке п. 3 «а» («за исключением оборудования, используемого на станциях регулирования давления»)? | Оговорка о станциях регулирования давления есть только в подпункте «а»; подпункт «б» оговорки не содержит |

| О-3 | **Трубы как самостоятельная поставка**: элемент оборудования (п. 2 «к») или материал / полуфабрикат (п. 45 «и», «к» — документы на материалы «при наличии»)? | В проекте `pipes` применимость определяется «по параметрам проекта», критерий не зафиксирован |
| О-4 | **Расчётное давление проекта ниже PN изделия** (например, сеть 0,3 МПа, кран PN16): категорию считать по PN изделия (правило 7) или по проекту? | Правило 7 предварительное |
