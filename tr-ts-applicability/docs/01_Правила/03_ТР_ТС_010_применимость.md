# 03 — Применимость ТР ТС 010/2011 «О безопасности машин и оборудования»

> Текст — `ТР ТС 010-2011.pdf` (редакция «Техэксперт» с изменениями на 13.03.2026; изменения решением Совета ЕЭК № 36 от 13.03.2026 действуют с 01.09.2026). Номера страниц — страницы этого PDF.
> **Сверено по оригиналу 08.11.2026:** ст. 7–8 (стр. 12), приложение 3, п. 59 перечня декларирования (стр. 49). Остальное — по текстовой версии.
> **Внимание:** с 01.04.2028 приложение № 3 будет изложено в новой редакции (решение Совета ЕЭК № 36 от 13.03.2026; пометка в тексте, стр. 45). Новой редакции в проекте нет. Для поставок после 01.04.2028 — сказать об этом и запросить новый текст.

## 1. Область применения (ст. 1, стр. 2–3)

- Регламент распространяется на машины и (или) оборудование, **указанные в приложении № 3** (ст. 1, п. 3, стр. 2). Нет в приложении № 3 — регламент не применяется.
- Распространяется в том числе на машины и оборудование для опасных производственных объектов (ст. 1, п. 5, стр. 3).
- Не распространяется (ст. 1, п. 4, стр. 2–3): медицинское оборудование в контакте с пациентом; оборудование, специально разработанное для атомной энергетики; колёсные ТС (ТР ТС 018/2011), суда, летательные аппараты, ж/д подвижной состав и инфраструктура, аттракционы, тракторы (ТР ТС 031/2012) — кроме установленных на них машин; поставки для национальной безопасности; буровые платформы (кроме машин на них); средства пожарной безопасности (ТР ЕАЭС 043/2017); электрооборудование по ТР ТС 004/2011, при эксплуатации которого возможны только электрические опасности (бытовые приборы, аудио-видео, офисная техника).
- Не подлежат подтверждению соответствия: машины и оборудование, бывшие в эксплуатации или изготовленные для собственных нужд изготовителя, а также **комплектующие изделия и запасные части для ремонта (технического обслуживания)** (ст. 7, п. 1, стр. 12).

## 2. Форма подтверждения (ст. 8, стр. 12–13)

- **Сертификация** — для продукции из перечня приложения № 3 «в форме сертификации» (ст. 8, п. 3).
- **Декларирование** — для продукции из перечня приложения № 3 «в форме декларирования» (ст. 8, п. 4). По решению заявителя вместо декларирования может быть проведена сертификация по эквивалентной схеме (ст. 8, п. 5) — сертификат вместо декларации допустим.

## 4. Как рассуждать

1. Найти вид изделия в приложении № 3 (по наименованию позиции перечня, а не по догадке).
2. Нашёлся — проверить исключения ст. 1, п. 4 и ст. 7, п. 1 (запчасти для ремонта и т. п.).
3. Вывод: «Применим — декларация» / «Применим — сертификат» / «Не применим — не указан в приложении № 3» / «Не определено» (вид изделия неясен или это комплектующее для ремонта — нужны данные).
4. Для арматуры ТР ТС 010 рассматривается **вместе** с ТР ТС 032: один регламент не заменяет другой.
