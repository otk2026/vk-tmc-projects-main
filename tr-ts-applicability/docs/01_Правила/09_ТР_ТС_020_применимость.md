# 09 — Применимость ТР ТС 020/2011 «Электромагнитная совместимость технических средств»

> Текст — `ТР ТС 020-2011.pdf` (с изменениями на 10.06.2022; изменения решением Совета ЕЭК № 91 действуют с 11.12.2022). Номера страниц — страницы этого PDF.
> **Сверено по оригиналу 09.11.2026:** ст. 7, п. 1–2 (стр. 6). Остальное — по текстовой версии (PDF с текстовым слоем).

## 1. Область применения (ст. 1, п. 1, стр. 2)

Технические средства, **способные создавать электромагнитные помехи и (или) качество функционирования которых зависит от внешних электромагнитных помех**. Порога по напряжению нет — регламент распространяется и на оборудование 24 В (датчики, контроллеры, электроника).

## 2. Не распространяется (ст. 1, п. 2, стр. 2)

- Технические средства, используемые изготовителями других технических средств **как составные части** и не предназначенные для самостоятельного применения конечным потребителем.
- Технические средства, **пассивные в отношении ЭМС** (определение — ст. 2, стр. 3; виды — **приложение 1**, стр. 13–14): провода, шнуры, кабели; изделия только с резистивной нагрузкой без автоматики; батареи и аккумуляторы без активной электроники; конденсаторы; **индукционные электродвигатели**; штепсели, розетки, предохранители и выключатели без активных электронных цепей; лампы накаливания и др.
- Для атомной энергетики; бывшие в эксплуатации; медицинские изделия; оборонная продукция.
- Если требования по ЭМС установлены другим вступившим в силу техническим регламентом — по нему (ст. 1, п. 2, последний абзац).

## 3. Форма подтверждения (ст. 7, стр. 6–7)

- Включено в **Перечень (приложение 3, стр. 15–16)** → **сертификация** (схемы 1с, 3с, 4с) (ст. 7, п. 2, стр. 6, сверено).
- **Не включено** → **декларирование** (схемы 1д, 2д, 3д, 4д, 6д); по выбору заявителя — сертификация.

Перечень приложения 3: бытовые электроприборы (в т. ч. электронасосы, световое оборудование, автоматические выключатели и УЗО с электронным управлением, оборудование дуговой сварки), ПЭВМ, оргтехника, электрифицированный инструмент, электромузыкальные инструменты.

## 4. ТР ТС 020 и ТР ТС 004 / 010

Исключения ТР ТС 004 по ТР ТС 010 / 012 (файл 08) **на ТР ТС 020 не распространяются**: ЭМС — отдельный регламент. Арматура с электроприводом, подлежащая ТР ТС 010, по ЭМС проверяется отдельно.

## 5. Как рассуждать

| Позиция | Вывод |
|---|---|
| Трубы, детали трубопроводов, фланцы, арматура без привода и электроники | «Не применим» — не техническое средство в смысле ЭМС (ст. 1, п. 1) |
| Арматура с электроприводом (с электронным блоком управления, частотным регулированием, позиционером) | «Применим» — декларация (не в Перечне) |
| Привод на индукционном двигателе без электроники | «Не применим» — пассивное в отношении ЭМС (прил. 1, п. 7*) — указать основание; при сомнении в составе привода — «Не определено», запросить состав |
| Датчики, преобразователи давления, контроллеры, шкафы автоматики | «Применим» — декларация (если не в Перечне) |
| Кабели, провода | «Не применим» — пассивные (прил. 1, п. 1) |
| Комплектующее, поставляемое изготовителю для встраивания | «Не применим» (ст. 1, п. 2) — при подтверждении назначения |
