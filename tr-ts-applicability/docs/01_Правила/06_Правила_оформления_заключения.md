# 06 — Правила оформления Заключения о применимости ТР ТС

## 1. Выходной документ

| Документ | Когда | Имя файла |
|---|---|---|
| **Заключение о применимости ТР ТС** (Word, .docx) | На каждый запрос (одни требования проекта + перечень номенклатуры) | `Заключение_ТР_ТС_<объект>_<дата>.docx` |

- `<объект>` — краткое название объекта / проекта из требований (пробелы → `-`, без кавычек); нет названия — номер заявки или поставщик.
- `<дата>` — дата оформления, `ДД.ММ.ГГГГ`. Совпадение имён в один день — суффикс `_2`, `_3`.
- Основа оформления — `originals/Шаблон_Заключение_ТР_ТС.docx` (заполненный образец; данные в нём условные).

## 2. Структура

1. **Заголовок** «ЗАКЛЮЧЕНИЕ / О ПРИМЕНИМОСТИ ТЕХНИЧЕСКИХ РЕГЛАМЕНТОВ» (2 строки) и подзаголовок — «ТР ТС 032/2013, 010/2011, 012/2011, 004/2011, 020/2011, ФНП 536».
2. **Шапка**: Объект / проект; Исходные данные (документ, номер, дата); Номенклатура (сколько позиций); Редакции регламентов (по PDF проекта); Дата.
3. **0. Исходные данные проекта** — таблица «Параметр | Значение | Источник»: объект и назначение, ОПО (да / нет), рабочая среда и группа, расчётное (максимальное) давление, расчётная (максимальная) температура, взрывоопасная зона, электрооборудование и напряжение, изготовление (завод / по месту эксплуатации); при необходимости — DN, вместимость. Нет данных — «не указано».
4. **1. Применимость по позициям** — **отдельная таблица на каждую позицию**, строка на каждый документ проекта в порядке: ТР ТС 032, 010, 012, 004, 020, ФНП 536. Колонки: «№ | Номенклатура | ТР ТС / ФНП | Основание (пункт, стр. PDF) | Вывод и требуемый документ | Оценка».
   - У позиции **без электрической части** (трубы, детали, фланцы, арматура без привода) ТР ТС 004 и 020 допускается дать одной строкой «ТР ТС 004/2011, 020/2011» с основанием «не электрическое оборудование / не техническое средство по ЭМС».
   - Строка ФНП 536: «Применим» — ФНП распространяются на оборудование, в составе которого применяется позиция (указать вид по п. 3 и категорию трубопровода Iэ–IVэ, если это трубопровод пара и горячей воды); в выводе — следствия для ВК (п. 138, 105; при отсутствии требований ТР — экспертиза промышленной безопасности, п. 467).
   - «Основание» — пункт регламента и страница PDF; пороговые сравнения — числами (P · DN = …).
   - «Вывод» — какой документ требовать (сертификат / декларация; схема — если следует из регламента) или «Документ не требуется», или «Вывод не сделан — нужно …».
5. **2. Допущения и открытые вопросы** — применённые предварительные правила и открытые вопросы файла 05.
6. **3. Недостающие данные** — что запросить и у кого.
7. **4. Итог** — по позициям: какие документы требовать от поставщика.
8. **5. Не проверено / ограничения** — неоткрытые файлы, отсутствующие редакции (новая редакция приложения № 3 ТР ТС 010 с 01.04.2028; ФНП 536 после 01.01.2027). Нет ограничений — «Ограничений нет». Регламенты вне состава проекта (файл 07) сюда не вносятся.
9. Подпись «Заключение составил: инженер ОТК ____ / ____ /», дата.

## 3. Оценка — текст и заливка ячейки «Оценка»

| Оценка | Заливка | Когда |
|---|---|---|
| Применим | DDEBF7 (голубой) | Регламент распространяется — документ требуется |
| Не применим | E2EFDA (светло-зелёный) | Не входит в область применения, попадает в исключение или не превышены пороги |
| Не определено | FFFF00 (жёлтый) | Не хватает данных или вопрос открыт (файл 05) |

## 4. Точные параметры оформления (сняты с шаблона 08.11.2026)

| Элемент | Параметры |
|---|---|
| Страница | A4 книжная; поля: левое 2,0 см, правое 1,0 см, верхнее 1,5 см, нижнее 1,5 см |
| Шрифт документа (стиль Normal) | Times New Roman 11 пт; интервал после абзаца 3 пт. **Задать в самом стиле Normal явно**, а не только у фрагментов текста |
| Заголовок | 2 абзаца, 14 пт, полужирный, цвет 1F4E79, по центру, интервал после 0 |
| Подзаголовок (перечень документов) | 11 пт, полужирный, по центру |
| Шапка | Подпись («Объект / проект:» и т. п.) — полужирная; значение — обычное; по ширине |
| Заголовки разделов 0–5 | 12 пт, полужирный, цвет 1F4E79, слева; интервал перед 10 пт, после 4 пт |
| Обычный текст | По ширине |
| Перечни | Начинаются с «– »; отступ слева 0,6 см, выступ первой строки 0,4 см |
| Таблицы — общее | Стиль Table Grid; ширина 18,0 см; по центру; макет фиксированный; строка заголовка повторяется на каждой странице; строки не разрываются между страницами |
| Шапка таблиц | Заливка E8E8E8; 9 пт, полужирный, по центру |
| Данные таблиц | 9 пт; выравнивание по верху; интервал после абзаца 0 |
| Таблица раздела 0 | Ширины колонок: 5,0 / 6,0 / 7,0 см |
| Таблицы раздела 1 | Ширины колонок: 0,7 / 3,0 / 2,2 / 5,2 / 4,5 / 2,4 см; «№» по центру; «Номенклатура» — полужирная, объединена по вертикали на все строки позиции; «Оценка» — заливка по разделу 3 (тип заливки clear). Между таблицами — пустой абзац |
| Подпись | Интервал перед 18 пт |
