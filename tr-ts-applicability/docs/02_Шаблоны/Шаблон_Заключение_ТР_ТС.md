# Шаблон — Заключение о применимости ТР ТС (текстовое описание)

> Оригинал — `originals/Шаблон_Заключение_ТР_ТС.docx`. Это **заполненный образец оформления** на условных данных (технологический газопровод котельной, 5 позиций). Данные образца в реальные заключения не переносить. Точные параметры оформления — файл `06_Правила_оформления_заключения.md`, раздел 4.

## Состав образца

- Заголовок: «ЗАКЛЮЧЕНИЕ / О ПРИМЕНИМОСТИ ТЕХНИЧЕСКИХ РЕГЛАМЕНТОВ»; подзаголовок «ТР ТС 032/2013, 010/2011, 012/2011, 004/2011, 020/2011, ФНП 536».
- Шапка: Объект / проект; Исходные данные; Номенклатура; Редакции документов; Дата.
- 0. Исходные данные проекта — таблица «Параметр | Значение | Источник» (в т. ч. ОПО, взрывоопасная зона, электрооборудование).
- 1. Применимость по позициям — по таблице на позицию, строки ТР ТС 032 / 010 / 012 / 004 и 020 (одной строкой для позиций без электрической части) / ФНП 536:
  - Отвод 90-219×6-20 ГОСТ 17375-2001 — 032: Применим (сертификат, элемент 4-й кат.); остальные: Не применим.
  - Кран шаровой DN200 PN16 — 032: Применим (декларация, 2-я кат. по табл. 6: P · DN = 320 ≤ 350); 010: Применим (декларация, прил. 3 п. 59); остальные: Не применим.
  - Фланец 1-200-16-01-1-B-Ст20 ГОСТ 33259-2015 — 032: Применим (сертификат); остальные: Не применим.
  - Труба 219×6 ГОСТ 10704-91 / В-20 ГОСТ 10705-80 — 032: Не определено (открытый вопрос О-3); остальные: Не применим.
  - Кран шаровой DN100 PN16 с электроприводом 380 В — 032: Применим (декларация, 2-я кат.: P · DN = 160 > 100, P > 1); 010: Применим (декларация); 012: Не применим (общепромышленное исполнение); 004: Не применим (подлежит ТР ТС 010, ст. 1 п. 2 «а»); 020: Применим (декларация, электронный блок управления).
  - ФНП 536 у всех позиций — Не применим: газопровод не входит в виды оборудования п. 3 ФНП.
- 2. Допущения и открытые вопросы; 3. Недостающие данные; 4. Итог — какие документы требовать; 5. Не проверено / ограничения (срок действия ФНП 536).
- Подпись «Заключение составил: инженер ОТК ____ / ____ /», дата.
