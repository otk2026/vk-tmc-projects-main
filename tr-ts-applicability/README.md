# ВК ТМЦ ➤ Применимость ТР ТС — материалы проекта

Самостоятельный проект: по требованиям проекта (объект, среда, давление, температура, DN) и перечню номенклатуры определить, **требуется ли вообще** подтверждение соответствия по ТР ТС, по какому регламенту и в какой форме (сертификат / декларация), а также распространяются ли на оборудование ФНП 536 (промышленная безопасность оборудования под давлением на ОПО).

Состав проекта закрыт: ТР ТС 032/2013, 010/2011, 012/2011, 004/2011, 020/2011 и ФНП 536 (решение пользователя 09.11.2026). Результат — **Заключение о применимости ТР ТС** (Word).

Проверка самих сертификатов и деклараций, поставленных с продукцией, — не здесь, а в проектах `fittings-flanges`, `pipes`, `details-tu-ost` (их правила по ТР ТС действуют без изменений).

Решения по спорным вопросам добавляются по мере поступления (файл 05).

## Известные потери текста

- ФНП 536: индексы категорий трубопроводов (Iэ–IVэ) и степени (кгс/см², м³) в текстовой версии пропущены — набраны в PDF картинками. Таблица категорий приведена сверенной в файле 10.
- В текстовых версиях таблицы приложения 1 ТР ТС 032 распались на строки, а знак «³» (м³) заменён меткой `[Рисунок: символ]`. Таблицы 6–9 приведены сверенными в файле 02; таблицы 1–5 брать по PDF (стр. 24–26).
